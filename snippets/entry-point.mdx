{/*
  The docs entry point: one line under the title, one link to the Start-here guide for the
  stack of the page it sits on. The wording lives here and nowhere else, so it changes in
  one place (task T-docs-entry.05).

  Props
    stack     a key of the guides map below. Leave it out when the page has no single stack,
              or when the platform has more than one product line and the page does not say
              which (a notifications page is read by both UI Kit and SDK users). The line
              then points at the page where a reader picks one.
    campaign  the docs section the page sits in. It becomes utm_campaign.

  The destination is derived from stack, never passed in. An href prop would be a second
  source of truth for the same fact, and when it was one the pair drifted on four of nine
  pages (reviewed on #585).

  A stack that is not in the map falls back to the chooser rather than throwing. A throw
  here would be a build failure, and a build failure in a table cell is what froze five
  React pages on live for six weeks, so this component does not add that risk.

  Every link carries utm_source=docs and utm_medium=entry, so a signup that starts on a
  docs page can be counted (task T-docs-entry.07). Tracking is built in one place below,
  so it comes out in one edit if that decision changes.

  JSX, not Markdown: inside an exported component, Markdown renders literally. The sentence
  stays on one line so the serialized .md output is one line too.
*/}

export const EntryPoint = ({ stack, campaign }) => {
  const guides = {
    "React": "/ui-kit/react/integration-react",
    "Next.js": "/ui-kit/react/integration-nextjs",
    "React Native": "/ui-kit/react-native/react-native-cli-integration",
    "Android": "/ui-kit/android/getting-started",
    "Android SDK": "/sdk/android/setup",
    "JavaScript SDK": "/sdk/javascript/overview",
  };
  const guide = stack ? guides[stack] : undefined;
  const [path, fragment] = (guide || "/chat-call").split("#");
  const tracking = `utm_source=docs&utm_medium=entry&utm_campaign=${encodeURIComponent(campaign)}`;
  const href = `${path}${path.includes("?") ? "&" : "?"}${tracking}${fragment ? `#${fragment}` : ""}`;
  return (
    <p>New to CometChat? <a href={href}>{guide ? `Start with the ${stack} integration guide` : "Pick your stack and start building"}</a>.</p>
  );
};
