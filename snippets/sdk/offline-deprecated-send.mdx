<Warning>
**Starting with v5.1.0, the `CallbackListener` overloads of {method} are deprecated.** Use `MessageSentListener` instead; it requires SDK 5.1.0 or later. On 5.0.x, keep using `CallbackListener` and handle the sent message in `onSuccess` where these examples use `onMessageSent`. With offline support off, it behaves exactly like the old callback: `onError` is unchanged, and the sent message arrives in `onMessageSent` instead of `onSuccess`. With offline support on, `onMessagePending` fires first, and a message sent without a connection is queued and sent when the connection returns. See [Send While Offline](/sdk/android/v5/offline-send).
</Warning>
