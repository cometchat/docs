<Warning>
**Starting with v5.1.0, the `CallbackListener` overload of {method} is deprecated.** Use {replacement} instead; it requires SDK 5.1.0 or later, so on 5.0.x keep using `CallbackListener`. With offline support off, it behaves exactly like the old callback: `onError` is unchanged, and the server result arrives in the `onServer…` callback instead of `onSuccess`. With offline support on, it also delivers the cached result first; the old overload keeps working but receives only the server result. See [Show Cached Data](/sdk/android/v5/offline-cached-data).
</Warning>
