<Warning>
**Starting with v5.1.0, the `CallbackListener` overload of {method} is deprecated.** Use {replacement} instead. With offline support off, it behaves exactly like the old callback: `onError` is unchanged, and the server result arrives in the `onServer…` callback instead of `onSuccess`. With offline support on, it also delivers the cached result first. See [Show Cached Data](/sdk/android/v5/offline-cached-data).
</Warning>
