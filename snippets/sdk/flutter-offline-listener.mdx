<Note>
**Starting with v5.1.0, {method} accepts a `listener:` parameter.** Pass a {listener} to receive the on-device cached result. The `listener:` parameter requires `cometchat_sdk` 5.1.0 or later, so on 5.0.x keep using `onSuccess`/`onError`. With offline support off, the listener behaves exactly like the callbacks: `onError` is unchanged, and the server result arrives in the `onServer…` callback instead of `onSuccess`. With offline support on, the listener also delivers the cached result first, then the server result. `onSuccess`/`onError` keep working and receive only the server result. See [Show Cached Data](/sdk/flutter/offline-cached-data).
</Note>
