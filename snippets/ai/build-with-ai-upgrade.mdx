  Props:
    kit        – e.g. "React UI Kit"
    version    – this page's version, e.g. "v6"
    current    – the current version, e.g. "v7"
    currentHref – the current version's overview, e.g. "/ui-kit/react/overview"
    prompt     – the upgrade request, e.g. "upgrade my CometChat React UI Kit from v6 to v7"
  The page owns the "## Build with AI" heading.
*/}

The CometChat Agent Skills build with the current {kit} ({current}). If your app is on {version}, your agent can upgrade it for you: it reads how your app uses CometChat, applies the breaking changes, and checks that the build still passes.

<Steps>
  <Step title="Install the skills in your app's folder">
    ```bash
    npx @cometchat/skills add
    ```
  </Step>
  <Step title="Ask your agent">
    ```text
    {prompt}
    ```
  </Step>
</Steps>

Starting a new app? Use the <a className="link" href={currentHref}>{kit} {current}</a> docs. The command installs the skills for Claude Code; for Cursor, GitHub Copilot, Codex and the other agents the installer supports, add `--ide`, for example `--ide cursor`. For the rest of the supported agents, see [Agent Skills](/agent-skills#supported-agents).
