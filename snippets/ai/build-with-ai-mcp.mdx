Connect your AI coding agent to the [CometChat MCP](/mcp-server) and it reads these docs as it works: it finds the right {platform} APIs and, once you sign in, fetches your app's credentials. In Claude Code:

```bash
claude mcp add --transport http cometchat https://mcp.cometchat.com/mcp
```

For Claude, Cursor, VS Code, Windsurf and other agents, see [Connect from your agent](/mcp-server#connect-from-your-agent). Building a chat UI instead? The UI Kits have [Agent Skills](/agent-skills) that add it for you: `npx @cometchat/skills add`.
