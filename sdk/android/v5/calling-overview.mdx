Voice and video calling on Android is provided by the CometChat Calls SDK, with incoming calls rung by the Push Notifications SDK. The Chat SDK is used for chat; it no longer takes part in calling.

<Warning>
**The Chat SDK's calling APIs are superseded.** `CometChat.initiateCall`, `acceptCall`, `rejectCall`, `endCall`, `startCall`, `getActiveCall`, `clearActiveCall`, `getCallParticipantCount`, `addCallListener` / `removeCallListener`, `CallListener`, `OngoingCallListener` and `CallSettings` still work, and a coming Chat SDK release marks them `@Deprecated`. Their replacement is the Calls SDK: `CometChatCalls.initiateCall`, `endCall(sessionId, status)`, `joinSession`, `CallSession.leave()` and `addIncomingCallListener`. Ringing the callee is done by the Push Notifications SDK calls module. See [Ringing](/calls/android/ringing) and [Migrating from Legacy Ringing](/calls/android/migrating-from-legacy-ringing).

Not deprecated: the `Call` message model and its getters, `CATEGORY_CALL`, the `CALL_STATUS_*` and `CALL_TYPE_*` constants, because call messages in a conversation's history still use them.
</Warning>

## Key Features

- **Voice & Video Calls** — High-quality 1-on-1 and group calling with adaptive bitrate
- **Screen Sharing** — Share your screen during calls for collaboration
- **Call Recording** — Record calls and access recordings later
- **Call Logs** — Track call history with detailed metadata
- **Ringing & Notifications** — Incoming calls ring through the Push Notifications SDK, with the app in any state
- **Customizable UI** — Presenter mode and video view customization
