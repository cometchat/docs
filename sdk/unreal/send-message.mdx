## Send a User Message

Send a text message to a specific user by their UID.

<Tabs>
<Tab title="Blueprint">
<Frame>
  <img src="/images/unreal-blueprints/SendMessageAsync.png" />
</Frame>

1. Get a reference to the **CometChat Subsystem**
2. Call the **Send Message Async** node
3. Wire the **On Success** and **On Failure** pins

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| Receiver Uid | `FString` | The UID of the user to send the message to |
| Text | `FString` | The message body |

**On Success** returns an `FCometChatMessage` with the sent message details (including the server-assigned `Id` and `SentAt` timestamp).
</Tab>
<Tab title="C++">
```cpp
#include "AsyncActions/CometChatSendMessageAction.h"

void AMyActor::SendDirectMessage()
{
    auto* Action = UCometChatSendMessageAction::SendMessageAsync(
        this,
        TEXT("cometchat-uid-2"),   // Receiver UID
        TEXT("Hey, want to play?") // Message text
    );
    Action->OnSuccess.AddDynamic(this, &AMyActor::OnMessageSent);
    Action->OnFailure.AddDynamic(this, &AMyActor::OnMessageFailed);
    Action->Activate();
}

void AMyActor::OnMessageSent(const FCometChatMessage& Message)
{
    UE_LOG(LogTemp, Log, TEXT("Message sent! ID: %s"), *Message.Id);
}

void AMyActor::OnMessageFailed(const FString& Error)
{
    UE_LOG(LogTemp, Error, TEXT("Send failed: %s"), *Error);
}
```
</Tab>
</Tabs>

## Send a Group Message

Send a text message to a group by its GUID.

<Tabs>
<Tab title="Blueprint">
<Frame>
  <img src="/images/unreal-blueprints/SendGroupMessageAsync.png" />
</Frame>

Call the **Send Group Message Async** node.

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| Guid | `FString` | The unique identifier of the target group |
| Text | `FString` | The message body |

**On Success** returns an `FCometChatMessage`.
</Tab>
<Tab title="C++">
```cpp
#include "AsyncActions/CometChatSendGroupMessageAction.h"

void AMyActor::SendToGroup()
{
    auto* Action = UCometChatSendGroupMessageAction::SendGroupMessageAsync(
        this,
        TEXT("group-abc-123"),       // Group GUID
        TEXT("Team, ready up!")      // Message text
    );
    Action->OnSuccess.AddDynamic(this, &AMyActor::OnGroupMessageSent);
    Action->OnFailure.AddDynamic(this, &AMyActor::OnGroupMessageFailed);
    Action->Activate();
}

void AMyActor::OnGroupMessageSent(const FCometChatMessage& Message)
{
    UE_LOG(LogTemp, Log, TEXT("Group message sent! ID: %s"), *Message.Id);
}

void AMyActor::OnGroupMessageFailed(const FString& Error)
{
    UE_LOG(LogTemp, Error, TEXT("Group send failed: %s"), *Error);
}
```
</Tab>
</Tabs>

## The FCometChatMessage Struct

Both send operations return an `FCometChatMessage` on success. Here's a quick reference of the key fields:

| Property | Type | Description |
| -------- | ---- | ----------- |
| `Id` | `FString` | Server-assigned unique message ID |
| `SenderUid` | `FString` | UID of the sender (the logged-in user) |
| `ReceiverUid` | `FString` | UID of the receiver (user UID or group GUID) |
| `Text` | `FString` | The message body |
| `SentAt` | `int64` | Unix timestamp when the message was sent |
| `Type` | `FString` | `text` for text messages |
| `ReceiverType` | `FString` | `user` for 1:1, `group` for group messages |
| `ConversationId` | `FString` | Unique conversation identifier |

For the full struct definition, see [Key Concepts → FCometChatMessage](/sdk/unreal/key-concepts#fchatmessage).

## Reactions

Users can react to any message (1:1 or group) with an emoji.

<Tabs>
<Tab title="Blueprint">
Call the **Add Reaction Async** node with the message's `Id` (as `int64`) and a `Reaction` string (an emoji). Use **Remove Reaction Async** with the same parameters to un-react.
</Tab>
<Tab title="C++">
```cpp
#include "AsyncActions/CometChatAddReactionAction.h"
#include "AsyncActions/CometChatRemoveReactionAction.h"

void AMyActor::ReactToMessage(int64 MessageId, const FString& Emoji)
{
    auto* Action = UCometChatAddReactionAction::AddReactionAsync(this, MessageId, Emoji);
    Action->OnSuccess.AddDynamic(this, &AMyActor::OnReactionAdded);
    Action->OnFailure.AddDynamic(this, &AMyActor::OnReactionFailed);
    Action->Activate();
}

void AMyActor::OnReactionAdded(const FCometChatMessage& Message)
{
    // Message.Reactions (TArray<FCometChatReactionCount>) now reflects the new totals
    for (const FCometChatReactionCount& RC : Message.Reactions)
    {
        UE_LOG(LogTemp, Log, TEXT("%s x%d (mine: %d)"), *RC.Reaction, RC.Count, RC.bReactedByMe);
    }
}
```
</Tab>
</Tabs>

`FCometChatMessage.Reactions` is a `TArray<FCometChatReactionCount>` — a per-emoji summary (the emoji, total count, and whether the logged-in user reacted). That's enough to render reaction pills below a message bubble without an extra fetch. Use **Fetch Reactions Async** only if you need the list of individual users who reacted (e.g., a "seen by" tooltip):

```cpp
#include "AsyncActions/CometChatFetchReactionsAction.h"

void AMyActor::FetchWhoReacted(int64 MessageId, const FString& Emoji)
{
    FCometChatReactionsRequest Request;
    Request.MessageId = MessageId;
    Request.Reaction = Emoji;

    auto* Action = UCometChatFetchReactionsAction::FetchReactionsAsync(this, Request);
    Action->OnSuccess.AddDynamic(this, &AMyActor::OnReactorsFetched);
    Action->Activate();
}

void AMyActor::OnReactorsFetched(const TArray<FCometChatReaction>& Reactions)
{
    for (const FCometChatReaction& R : Reactions)
    {
        UE_LOG(LogTemp, Log, TEXT("%s reacted with %s"), *R.ReactedBy.Name, *R.Reaction);
    }
}
```

<Info>
Bind `OnMessageReactionAdded` / `OnMessageReactionRemoved` on the subsystem to keep reaction pills in sync in real time when other users react — see [Real-Time Events](/sdk/unreal/real-time-events).
</Info>

<Tip>
**Color emoji rendering**: Unreal's default UI font has no emoji glyphs, so reaction text renders as blank boxes unless you assign an emoji-capable font (e.g., Noto Color Emoji) to the `UTextBlock` displaying the reaction. Keep the emoji glyph's text color at pure white — Slate multiplies a color-emoji glyph by the text tint, so any other tint darkens it toward invisible. Render the emoji and the reaction count as separate `UTextBlock`s: most emoji fonts have no digit glyphs, so a combined "😀 3" string in one block will drop the digits or the emoji depending on which font wins.
</Tip>
