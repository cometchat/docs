<Accordion title="AI Integration Quick Reference">

| Field | Value |
| --- | --- |
| Package | `@cometchat/chat-sdk-react-native` (4.2.0 or later) |
| Config class | `CometChat.OfflineConfig` — `new CometChat.OfflineConfig({ enabled: true })` |
| Attach to | `new CometChat.AppSettingsBuilder().setOfflineConfig(config)` (or the `.offline(true)` shorthand) |
| Install (peers) | `@op-engineering/op-sqlite` 9.0.0+ (required), `react-native-fs`, `react-native-keychain` |
| Verify | `CometChat.isOfflineEnabled()` → `boolean` |
| Constraints | Off by default. Not available in Expo Go — use a development build or `expo prebuild`. |

```typescript
const offlineConfig = new CometChat.OfflineConfig({ enabled: true });

const appSettings = new CometChat.AppSettingsBuilder()
  .setRegion("REGION")
  .setOfflineConfig(offlineConfig) // explicit config; its `enabled` wins
  // .offline(true)                // shorthand: enable with all defaults
  .build();

await CometChat.init("APP_ID", appSettings);

const active: boolean = CometChat.isOfflineEnabled();
```

</Accordion>

Offline support is **off by default**. You turn it on once, at initialization, by attaching an `OfflineConfig` to your `AppSettings`. Until you do, the SDK behaves exactly as before: no local store is opened and no native module is loaded. This page covers the minimal setup; for every tunable option see the [Configuration & API Reference](/sdk/react-native/offline-reference).

<Steps>

<Step title="Requirements">
Offline support requires CometChat React Native Chat SDK **4.2.0** or later.

The local database is provided by a native module that you install in your app. It is an optional peer dependency of the SDK, so installing the SDK never requires it:

| Package | Needed for |
| --- | --- |
| `@op-engineering/op-sqlite` (9.0.0 or later) | The local store. **Required for offline.** Without it the SDK runs online-only. |
| `react-native-fs` | Media caching and durable media sends. |
| `react-native-keychain` | Storing the encryption key, only with [encryption](/sdk/react-native/offline-encryption). |

```bash
npm install @op-engineering/op-sqlite react-native-fs
```

<Note>
`@op-engineering/op-sqlite` is a native module. In Expo, use a development build or `expo prebuild` — offline does not run in Expo Go (the SDK then runs online-only). Pick an `op-sqlite` release that supports your React Native version.
</Note>

If you are new to the SDK, complete the [standard setup](/sdk/react-native/setup-sdk) first; the steps below only add offline configuration to your existing `init`.
</Step>

<Step title="Build an OfflineConfig">
Construct an `OfflineConfig` and set `enabled: true`. Every other option has a sensible default, so set only what you need. Invalid values are normalised to the default; they are never rejected.

<Tabs>
<Tab title="TypeScript">
```typescript
const offlineConfig: CometChat.OfflineConfig = new CometChat.OfflineConfig({
  enabled: true,
});
```
</Tab>
<Tab title="JavaScript">
```javascript
const offlineConfig = new CometChat.OfflineConfig({
  enabled: true,
});
```
</Tab>
</Tabs>
</Step>

<Step title="Attach it to AppSettings">
Pass the config to `AppSettingsBuilder.setOfflineConfig(...)`. To enable with all defaults instead of building a config, use the `offline(boolean)` shorthand.

<Tabs>
<Tab title="TypeScript">
```typescript
const appSettings: CometChat.AppSettings = new CometChat.AppSettingsBuilder()
  .setRegion("REGION")
  .setOfflineConfig(offlineConfig) // explicit config
  // .offline(true)                // shorthand: enable with defaults
  .build();
```
</Tab>
<Tab title="JavaScript">
```javascript
const appSettings = new CometChat.AppSettingsBuilder()
  .setRegion("REGION")
  .setOfflineConfig(offlineConfig) // explicit config
  // .offline(true)                // shorthand: enable with defaults
  .build();
```
</Tab>
</Tabs>

<Note>
If you call both `setOfflineConfig(...)` and `offline(boolean)`, the explicit `OfflineConfig` wins — its `enabled` value is authoritative.
</Note>
</Step>

<Step title="Initialize the SDK">
Pass the settings to `CometChat.init(...)` as you do today. No other call changes.

<Tabs>
<Tab title="TypeScript">
```typescript
CometChat.init("APP_ID", appSettings).then(
  () => {
    console.log("Initialization completed successfully");
  },
  (error: CometChat.CometChatException) => {
    console.log("Initialization failed with error:", error);
  }
);
```
</Tab>
<Tab title="JavaScript">
```javascript
CometChat.init("APP_ID", appSettings).then(
  () => {
    console.log("Initialization completed successfully");
  },
  (error) => {
    console.log("Initialization failed with error:", error);
  }
);
```
</Tab>
</Tabs>
</Step>

<Step title="Verify it is active">
Call `CometChat.isOfflineEnabled()`. It returns `true` only while offline support is actually active for the logged-in user — so it is `false` before anyone logs in, even when you enabled it in `AppSettings`. It is also `false` if the native store could not open or if CometChat has switched offline off for your app. Read it at the moment of each decision and keep no copy of the result.

<Tabs>
<Tab title="TypeScript">
```typescript
const active: boolean = CometChat.isOfflineEnabled();
console.log("Offline support active:", active);
```
</Tab>
<Tab title="JavaScript">
```javascript
const active = CometChat.isOfflineEnabled();
console.log("Offline support active:", active);
```
</Tab>
</Tabs>
</Step>

</Steps>

## Enable from a settings file

If you initialize with `CometChat.initFromSettings(settings)`, pass your parsed `cometchat-settings.json` object and add an `offline` key under `chatSDK`. It accepts a boolean shorthand or a full configuration object.

<Note>
In the object form, `enabled` is `false` unless you set it to `true` — passing other options alone does not turn offline on.
</Note>

```json cometchat-settings.json
{
  "appId": "APP_ID",
  "region": "REGION",
  "chatSDK": {
    "offline": true
  }
}
```

<Tabs>
<Tab title="TypeScript">
```typescript
import settings from "./cometchat-settings.json";

CometChat.initFromSettings(settings).then(
  () => console.log("Initialization completed successfully"),
  (error: CometChat.CometChatException) => console.log("Initialization failed with error:", error)
);
```
</Tab>
<Tab title="JavaScript">
```javascript
import settings from "./cometchat-settings.json";

CometChat.initFromSettings(settings).then(
  () => console.log("Initialization completed successfully"),
  (error) => console.log("Initialization failed with error:", error)
);
```
</Tab>
</Tabs>
