## Overview

Secure Media Access provides enhanced security for file transfers in CometChat by transmitting the File Access Token (FAT) via HTTP headers instead of URL query parameters. This prevents token exposure in server logs, browser history, and network monitoring tools.

By default, CometChat uses the `embedded` mode, which appends the FAT token to media URLs as a query parameter (`?fat=xxx`). While functional, this approach can expose tokens in logs and browser history. The `headerBased` mode offers a more secure alternative by transmitting the token via HTTP headers instead.

<Note>
If you're using CometChat UIKit, no action is required. The UIKit handles secure media automatically.
</Note>

## Requirements

- iOS SDK v4.1.0+
- Backend support for secure media access

---

## Choose Your Approach

There are two ways to load media securely. Choose the one that fits your use case:

| Approach | Best For | Method |
| -------- | -------- | ------ |
| **Approach A: Header-Based Requests** | URLSession, custom networking | `createHeaderBasedMediaRequest(for:)` |
| **Approach B: Presigned URLs** | Third-party libraries (Kingfisher, SDWebImage, Nuke) | `fetchPresignedUrl(for:onSuccess:onError:)` |

<Warning>
Pick ONE approach and use it consistently throughout your app. Do not mix both approaches for the same media type.
</Warning>

---

## Approach A: Header-Based Requests

Use this approach when you have direct control over the network request (e.g., using `URLSession`). The SDK injects the FAT token into the HTTP headers automatically.

### Step 1: Enable Header-Based Mode

Add `.setSecureMediaMode(.headerBased)` during SDK initialization:

<Tabs>
<Tab title="Swift">
```swift
let appSettings = AppSettings.AppSettingsBuilder()
    .setSecureMediaMode(.headerBased)  // Enable header-based mode
    .setRegion(region: "us")
    .build()

CometChat.init(appId: "YOUR_APP_ID", appSettings: appSettings, onSuccess: { _ in
    print("CometChat initialized with secure media")
}, onError: { error in
    print("Initialization failed: \(error.errorDescription)")
})
```
</Tab>
</Tabs>

### Step 2: Load Media Using Header-Based Requests

Use `createHeaderBasedMediaRequest(for:)` to create a `URLRequest` with the FAT header injected:

<Tabs>
<Tab title="Swift">
```swift
// Load an image
func loadImage(from urlString: String, into imageView: UIImageView) {
    guard let url = URL(string: urlString) else { return }
    
    // Create request with FAT header
    let request = CometChat.createHeaderBasedMediaRequest(for: url)
    
    URLSession.shared.dataTask(with: request) { data, _, error in
        if let data = data, let image = UIImage(data: data) {
            DispatchQueue.main.async {
                imageView.image = image
            }
        }
    }.resume()
}

// Usage
loadImage(from: mediaMessage.attachment?.fileUrl ?? "", into: myImageView)
```
</Tab>
</Tabs>

### Step 3: Handle Video/Audio with AVPlayer

For AVPlayer, you need to manually inject the FAT header:

<Tabs>
<Tab title="Swift">
```swift
func playVideo(from url: URL, in viewController: UIViewController) {
    var headers: [String: String] = [:]
    
    // Check if FAT header injection is needed
    if Utils.shared.shouldInjectFatHeader(for: url), let fat = CometChat.getFat() {
        headers["fat"] = fat.removingPercentEncoding ?? fat
    }
    
    // Create asset with headers
    let asset = AVURLAsset(url: url, options: ["AVURLAssetHTTPHeaderFieldsKey": headers])
    let player = AVPlayer(playerItem: AVPlayerItem(asset: asset))
    
    let playerVC = AVPlayerViewController()
    playerVC.player = player
    
    viewController.present(playerVC, animated: true) {
        player.play()
    }
}
```
</Tab>
</Tabs>

## Approach B: Presigned URLs

Use this approach when working with third-party image loading libraries like Kingfisher, SDWebImage, or Nuke. These libraries don't support custom headers easily, so you fetch a temporary presigned URL instead.

<Warning>
Presigned URLs expire after approximately 5 minutes. Always fetch a fresh URL before each load. Never cache presigned URLs.
</Warning>

### Step 1: Initialize SDK (No Special Mode Required)

Presigned URLs work regardless of the secure media mode setting:

<Tabs>
<Tab title="Swift">
```swift
let appSettings = AppSettings.AppSettingsBuilder()
    .setRegion(region: "us")
    .build()

CometChat.init(appId: "YOUR_APP_ID", appSettings: appSettings, onSuccess: { _ in
    print("CometChat initialized")
}, onError: { error in
    print("Initialization failed: \(error.errorDescription)")
})
```
</Tab>
</Tabs>

### Step 2: Fetch Presigned URL and Load Media

Use `fetchPresignedUrl(for:onSuccess:onError:)` to get a temporary URL, then pass it to your image library:

<Tabs>
<Tab title="Swift">
```swift
// With Kingfisher
func loadImageWithKingfisher(from urlString: String, into imageView: UIImageView) {
    CometChat.fetchPresignedUrl(
        for: urlString,
        onSuccess: { presignedUrl in
            // Use the presigned URL with Kingfisher
            imageView.kf.setImage(with: URL(string: presignedUrl))
        },
        onError: { error in
            print("Failed to get presigned URL: \(error.errorDescription)")
        }
    )
}

// With SDWebImage
func loadImageWithSDWebImage(from urlString: String, into imageView: UIImageView) {
    CometChat.fetchPresignedUrl(
        for: urlString,
        onSuccess: { presignedUrl in
            // Use the presigned URL with SDWebImage
            imageView.sd_setImage(with: URL(string: presignedUrl))
        },
        onError: { error in
            print("Failed to get presigned URL: \(error.errorDescription)")
        }
    )
}

// Usage
loadImageWithKingfisher(from: mediaMessage.attachment?.fileUrl ?? "", into: myImageView)
```
</Tab>
</Tabs>

### Step 3: Handle URL Expiry with Retry Logic

Since presigned URLs expire, implement retry logic for 403 errors:

<Tabs>
<Tab title="Swift">
```swift
func loadImageWithRetry(url: String, imageView: UIImageView, retryCount: Int = 0) {
    CometChat.fetchPresignedUrl(
        for: url,
        onSuccess: { presignedUrl in
            URLSession.shared.dataTask(with: URL(string: presignedUrl)!) { data, response, _ in
                // Check for expiry (403 Forbidden)
                if let httpResponse = response as? HTTPURLResponse,
                   httpResponse.statusCode == 403,
                   retryCount < 1 {
                    // Retry with fresh URL
                    self.loadImageWithRetry(url: url, imageView: imageView, retryCount: 1)
                    return
                }
                
                if let data = data, let image = UIImage(data: data) {
                    DispatchQueue.main.async {
                        imageView.image = image
                    }
                }
            }.resume()
        },
        onError: { error in
            print("Error: \(error.errorDescription)")
        }
    )
}
```
</Tab>
</Tabs>

## Methods and Enums

### SecureMediaMode Enum

<Tabs>
<Tab title="Swift">
```swift
@objc public enum SecureMediaMode: Int {
    case embedded = 0     // FAT in URL as ?fat=xxx (default)
    case headerBased = 1  // FAT sent via HTTP header (secure)
}
```
</Tab>
</Tabs>

| Mode | Value | Description |
| ---- | ----- | ----------- |
| `embedded` | 0 | Token appended to URL as `?fat=xxx` (default behavior) |
| `headerBased` | 1 | Token sent via HTTP `fat` header (more secure) |

---

### createHeaderBasedMediaRequest(for:)

Creates a `URLRequest` with the FAT token injected as an HTTP header.

<Tabs>
<Tab title="Swift">
```swift
@objc public static func createHeaderBasedMediaRequest(for url: URL) -> URLRequest
```
</Tab>
</Tabs>

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| url | `URL` | The media URL to request |

**Returns:** `URLRequest` with FAT header if in header-based mode.

**Behavior:**
- Strips existing `?fat=` query parameter from URL
- Adds FAT header if URL requires secure access
- Decodes percent-encoded FAT token before adding

---

### fetchPresignedUrl(for:onSuccess:onError:)

Fetches a temporary presigned URL for CometChat media. Works regardless of `SecureMediaMode`.

<Tabs>
<Tab title="Swift">
```swift
@objc public static func fetchPresignedUrl(
    for url: String,
    onSuccess: @escaping (String) -> Void,
    onError: @escaping (CometChatException) -> Void
)
```
</Tab>
</Tabs>

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| url | `String` | CometChat media URL (attachment, avatar, group icon) |
| onSuccess | `(String) -> Void` | Callback with presigned URL string |
| onError | `(CometChatException) -> Void` | Callback with error |

**Error Codes:**

| Code | Description |
| ---- | ----------- |
| `ERR_NOT_LOGGED_IN` | User must be logged in |
| `ERR_INVALID_URL` | Invalid CometChat media URL |
| `ERR_NETWORK` | Network request failed |
| `ERR_INVALID_RESPONSE` | Invalid server response |

## Additional Examples

### Download File (Approach A)

<Tabs>
<Tab title="Swift">
```swift
func downloadFile(from urlString: String, completion: @escaping (URL?) -> Void) {
    guard let url = URL(string: urlString) else {
        completion(nil)
        return
    }
    
    let request = CometChat.createHeaderBasedMediaRequest(for: url)
    
    URLSession.shared.downloadTask(with: request) { tempURL, _, error in
        guard let tempURL = tempURL else {
            completion(nil)
            return
        }
        
        let documentsPath = FileManager.default.urls(for: .documentDirectory, in: .userDomainMask)[0]
        let destinationURL = documentsPath.appendingPathComponent(url.lastPathComponent)
        
        try? FileManager.default.removeItem(at: destinationURL)
        try? FileManager.default.moveItem(at: tempURL, to: destinationURL)
        
        completion(destinationURL)
    }.resume()
}
```
</Tab>
</Tabs>

## Troubleshooting

### 401 Unauthorized

| Cause | Solution |
| ----- | -------- |
| User not logged in | Ensure login completes before loading media |
| FAT not included | Use `createHeaderBasedMediaRequest()` or `fetchPresignedUrl()` |
| Wrong mode | Verify `setSecureMediaMode(.headerBased)` was called (Approach A only) |

### Images Not Loading

Debug with:

<Tabs>
<Tab title="Swift">
```swift
print("Header mode enabled: \(Utils.shared.isHeaderModeEnabled())")
print("FAT available: \(CometChat.getFat() != nil)")
print("Secure host: \(Utils.shared.getSecureMediaHost() ?? "nil")")
```
</Tab>
</Tabs>

### Video Won't Play

<Tabs>
<Tab title="Swift">
```swift
// ❌ Wrong - no FAT header
let player = AVPlayer(url: videoURL)

// ✅ Correct - FAT header injected
let headers = ["fat": CometChat.getFat()?.removingPercentEncoding ?? ""]
let asset = AVURLAsset(url: videoURL, options: ["AVURLAssetHTTPHeaderFieldsKey": headers])
let player = AVPlayer(playerItem: AVPlayerItem(asset: asset))
```
</Tab>
</Tabs>

### Presigned URL Expired (403)

Always fetch a fresh presigned URL before each load:

<Tabs>
<Tab title="Swift">
```swift
// ❌ Wrong - caching presigned URL
let cachedUrl = presignedUrl  // Don't do this!

// ✅ Correct - fetch fresh each time
CometChat.fetchPresignedUrl(for: originalUrl, onSuccess: { freshUrl in
    // Use immediately
}, onError: { _ in })
```
</Tab>
</Tabs>

## Migration Guide

### Upgrading from Embedded to Header-Based Mode

If you're currently using the default `embedded` mode and want to switch to `headerBased`:

#### 1. Update Initialization

<Tabs>
<Tab title="Swift">
```swift
// Before (embedded mode - default)
let appSettings = AppSettings.AppSettingsBuilder()
    .setRegion(region: "us")
    .build()

// After (header-based mode)
let appSettings = AppSettings.AppSettingsBuilder()
    .setSecureMediaMode(.headerBased)  // Add this line
    .setRegion(region: "us")
    .build()
```
</Tab>
</Tabs>

#### 2. Update Media Loading Code

<Tabs>
<Tab title="Swift">
```swift
// Before
URLSession.shared.dataTask(with: url) { data, _, _ in
    // ...
}

// After
let request = CometChat.createHeaderBasedMediaRequest(for: url)
URLSession.shared.dataTask(with: request) { data, _, _ in
    // ...
}
```
</Tab>
</Tabs>

#### 3. Update AVPlayer Code

<Tabs>
<Tab title="Swift">
```swift
// Before
let player = AVPlayer(url: videoURL)

// After
let headers = ["fat": CometChat.getFat()?.removingPercentEncoding ?? ""]
let asset = AVURLAsset(url: videoURL, options: ["AVURLAssetHTTPHeaderFieldsKey": headers])
let player = AVPlayer(playerItem: AVPlayerItem(asset: asset))
```
</Tab>
</Tabs>
