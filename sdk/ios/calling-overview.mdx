Voice and video calling on iOS is provided by the CometChat Calls SDK, with incoming calls rung by the Push Notifications SDK through PushKit and CallKit. The Chat SDK is used for chat; it no longer takes part in calling.

<Warning>
**The Chat SDK's calling APIs are superseded.** `CometChat.initiateCall`, `acceptCall`, `rejectCall`, `endCall`, `startCall`, `getActiveCall`, `clearActiveCall`, `getCallParticipantCount`, `addCallListener` / `removeCallListener`, `CometChat.calldelegate`, `CometChatCallDelegate` and `CallSettings` still work, and a coming Chat SDK release marks them deprecated. Their replacement is the Calls SDK: `CometChatCalls.initiateCall`, `endCall(sessionID:status:)`, `joinSession`, `CallSession.shared.leave()` and `addIncomingCallListener`. Ringing the callee is done by the Push Notifications SDK's Calls product. See [Ringing](/calls/ios/ringing) and [Migrating from Legacy Ringing](/calls/ios/migrating-from-legacy-ringing).

Not deprecated: the `Call` message model and its properties, and the `CometChat.callStatus` and `CometChat.CallType` values, because call messages in a conversation's history still use them.
</Warning>

## Key Features

- **Voice & Video Calls** — High-quality 1-on-1 and group calling with adaptive bitrate
- **Screen Sharing** — Share your screen during calls for collaboration
- **Call Recording** — Record calls and access recordings later
- **Call Logs** — Track call history with detailed metadata
- **Ringing & Notifications** — Incoming calls ring through the Push Notifications SDK and CallKit, with the app in any state
- **Customizable UI** — Presenter mode and video view customization
