Handle call session events to build responsive UIs. The SDK provides five session listener protocols to monitor session status, participant activities, media changes, button clicks, and layout changes, plus two global listeners for incoming calls and login state. The SDK holds every listener weakly and removes none of them for you, so keep a strong reference to each listener object and remove it when your screen goes away.

## Get CallSession Instance

The `CallSession` is a singleton that manages the active call. All event listener registrations and session control methods are accessed through this instance.

<Tabs>
<Tab title="Swift">
```swift
let callSession = CallSession.shared
```
</Tab>
<Tab title="Objective-C">
```objectivec
CallSession *callSession = [CallSession shared];
```
</Tab>
</Tabs>

`CallSession.shared` always exists, so listeners registered on it work before any session does. To ask whether there is a session right now, use `CometChatCalls.getActiveSession()`:

<Tabs>
<Tab title="Swift">
```swift
// nil when no session is prepared or joined
if let session = CometChatCalls.getActiveSession() {
    print("Live session \(session.sessionId ?? "")")
}
```
</Tab>
<Tab title="Objective-C">
```objectivec
CallSession *session = [CometChatCalls getActiveSession];   // nil when no session is prepared or joined
```
</Tab>
</Tabs>

`getActiveSession()` returns `CallSession.shared` as soon as a session is **prepared**, which is what `CometChatCalls.initiateCall` does on the caller and what the Push SDK's ring does on the callee, before anyone joins. That is what lets a caller listen for "ringing" and "answered" without joining (see [Ringing](/calls/ios/ringing)). Before a session is prepared or joined it returns nil, so code that registers through it (`getActiveSession()?.addSessionStatusListener(self)`) registers nothing; register on `CallSession.shared` instead.

<Note>
Remember to remove listeners when your view controller is deallocated to prevent memory leaks. Use `removeSessionStatusListener`, `removeParticipantEventListener`, etc.
</Note>

## Session Events

Monitor the call session lifecycle including join/leave events and connection status.

<Tabs>
<Tab title="Swift">
```swift
class CallViewController: UIViewController, SessionStatusListener {
    
    override func viewDidLoad() {
        super.viewDidLoad()
        CallSession.shared.addSessionStatusListener(self)
    }
    
    deinit {
        CallSession.shared.removeSessionStatusListener(self)
    }
    
    func onConnected() {
        // A prepared session is connected (signalling only): the join will be near-instant
    }

    func onSessionJoined() {
        // Successfully connected to the session
    }

    func onSessionLeft() {
        // Left the session
        navigationController?.popViewController(animated: true)
    }

    func onSessionTimedOut() {
        // Session ended due to inactivity
        navigationController?.popViewController(animated: true)
    }

    func onConnectionLost() {
        // Network interrupted, attempting reconnection
    }

    func onConnectionRestored() {
        // Connection restored after being lost
    }

    func onConnectionClosed() {
        // Connection permanently closed. On a session that was only prepared
        // (an outgoing call still ringing), this means the call ended before anyone joined.
        navigationController?.popViewController(animated: true)
    }
}
```
</Tab>
<Tab title="Objective-C">
```objectivec
@interface CallViewController () <SessionStatusListener>
@end

@implementation CallViewController

- (void)viewDidLoad {
    [super viewDidLoad];
    [[CallSession shared] addSessionStatusListener:self];
}

- (void)dealloc {
    [[CallSession shared] removeSessionStatusListener:self];
}

- (void)onConnected {
    // A prepared session is connected (signalling only): the join will be near-instant
}

- (void)onSessionJoined {
    // Successfully connected to the session
}

- (void)onSessionLeft {
    // Left the session
    [self.navigationController popViewControllerAnimated:YES];
}

- (void)onSessionTimedOut {
    // Session ended due to inactivity
    [self.navigationController popViewControllerAnimated:YES];
}

- (void)onConnectionLost {
    // Network interrupted, attempting reconnection
}

- (void)onConnectionRestored {
    // Connection restored after being lost
}

- (void)onConnectionClosed {
    // Connection permanently closed. On a session that was only prepared
    // (an outgoing call still ringing), this means the call ended before anyone joined.
    [self.navigationController popViewControllerAnimated:YES];
}

@end
```
</Tab>
</Tabs>

| Event | Description |
|-------|-------------|
| `onConnected()` | A prepared session connected: signalling only, no media, and other participants do not see you yet. Fires once per prepare (`initiateCall` on the caller, the Push SDK's ring on the callee); the media join is `onSessionJoined()` |
| `onSessionJoined()` | Successfully connected and joined the session |
| `onSessionLeft()` | Left the session via `leave()` or was removed |
| `onSessionTimedOut()` | Session ended due to inactivity timeout. Not used on a prepared session: one nobody joins within 5 minutes reports `onConnectionClosed()` |
| `onConnectionLost()` | Network interrupted, SDK attempting reconnection |
| `onConnectionRestored()` | Connection restored after being lost |
| `onConnectionClosed()` | Connection permanently closed, cannot reconnect. On a prepared session: the call ended before anyone joined (declined, busy, rung out, cancelled, the room went away, or nobody joined within 5 minutes) |

## Participant Events

Monitor participant activities including join/leave, audio/video state, hand raise, screen sharing, and recording.

<Tabs>
<Tab title="Swift">
```swift
class CallViewController: UIViewController, ParticipantEventListener {
    
    override func viewDidLoad() {
        super.viewDidLoad()
        CallSession.shared.addParticipantEventListener(self)
    }
    
    deinit {
        CallSession.shared.removeParticipantEventListener(self)
    }
    
    func onParticipantConnected(participant: Participant) {
        // A participant's device prepared the session but has not joined yet.
        // On an outgoing call: the callee's phone is ringing.
    }

    func onParticipantJoined(participant: Participant) {
        // A participant joined the call. On an outgoing call: the callee answered.
    }

    func onParticipantLeft(participant: Participant) {
        // A participant left the call
    }

    func onParticipantListChanged(participants: [Participant]) {
        // Participant list updated
    }

    func onParticipantAudioMuted(participant: Participant) {}
    func onParticipantAudioUnmuted(participant: Participant) {}
    func onParticipantVideoPaused(participant: Participant) {}
    func onParticipantVideoResumed(participant: Participant) {}
    func onParticipantHandRaised(participant: Participant) {}
    func onParticipantHandLowered(participant: Participant) {}
    func onParticipantStartedScreenShare(participant: Participant) {}
    func onParticipantStoppedScreenShare(participant: Participant) {}
    func onParticipantStartedRecording(participant: Participant) {}
    func onParticipantStoppedRecording(participant: Participant) {}
    func onDominantSpeakerChanged(participant: Participant) {}
}
```
</Tab>
<Tab title="Objective-C">
```objectivec

@end

    [super viewDidLoad];

    // A participant's device prepared the session but has not joined yet.
    // On an outgoing call: the callee's phone is ringing.

- (void)onParticipantJoinedWithParticipant:(Participant *)participant {

- (void)onParticipantLeftWithParticipant:(Participant *)participant {

}

- (void)onParticipantListChangedWithParticipants:(NSArray<Participant *> *)participants {
    // Participant list updated
}

// Other callbacks...

@end
```
</Tab>
</Tabs>

| Event | Parameter | Description |
|-------|-----------|-------------|
| `onParticipantConnected` | `Participant` | A remote participant's device prepared the session without joining. On the caller's prepared session this is the callee ringing |
| `onParticipantJoined` | `Participant` | A participant joined the call. On the caller's prepared session this is the callee answering: join now |
| `onParticipantLeft` | `Participant` | A participant disconnected from the call |
| `onParticipantListChanged` | `[Participant]` | Participant list updated |
| `onParticipantAudioMuted` | `Participant` | A participant muted their microphone |
| `onParticipantAudioUnmuted` | `Participant` | A participant unmuted their microphone |
| `onParticipantVideoPaused` | `Participant` | A participant turned off their camera |
| `onParticipantVideoResumed` | `Participant` | A participant turned on their camera |
| `onParticipantHandRaised` | `Participant` | A participant raised their hand |
| `onParticipantHandLowered` | `Participant` | A participant lowered their hand |
| `onParticipantStartedScreenShare` | `Participant` | A participant started screen sharing |
| `onParticipantStoppedScreenShare` | `Participant` | A participant stopped screen sharing |
| `onParticipantStartedRecording` | `Participant` | A participant started recording |
| `onParticipantStoppedRecording` | `Participant` | A participant stopped recording |
| `onDominantSpeakerChanged` | `Participant` | The active speaker changed |

<Tabs>

| Event | Parameter | Description |
|-------|-----------|-------------|
| `onAudioMuted` | - | Your microphone was muted |
| `onAudioUnMuted` | - | Your microphone was unmuted |
| `onVideoPaused` | - | Your camera was turned off |

<Note>
  `MediaEventsListener` has **no** screen-share callback. Screen sharing is observed on
  [`ParticipantEventListener`](#participant-events) via `onParticipantStartedScreenShare` /
  `onParticipantStoppedScreenShare` — and on iOS those are **receive-only**: the SDK reports a share
  started from another client, but cannot start one locally (that needs a Broadcast Upload Extension).
</Note>

| Value | Description |

| `.bluetooth` | Audio routed through connected Bluetooth device |
| `.headphones` | Audio routed through wired headphones |
</Accordion>

<Accordion title="CameraFacing Values">
| Value | Description |
|-------|-------------|
| `.FRONT` | Front-facing (selfie) camera is active |

## Incoming Call Events

`CometChatCalls.addIncomingCallListener` is a global listener, not tied to a session. It reports a call ringing on this device and the end of that ring, whether the call arrived by VoIP push while the app was killed or while it was running. The Push Notifications SDK feeds it; it reports incoming calls only, not the end of your own outgoing call.

<Tabs>
<Tab title="Swift">
```swift
final class CallEvents: NSObject, CometChatIncomingCallListener {
    func onIncomingCallReceived(call: CometChatIncomingCall) {
        // A call for this user is ringing (CallKit already shows it)
    }

    func onIncomingCallEnded(call: CometChatIncomingCall, reason: String) {
        // The ring ended: "cancelled", "ongoing", "unanswered", "rejected", "busy", "ended"
    }
}

let callEvents = CallEvents()   // held weakly by the SDK: keep this reference
CometChatCalls.addIncomingCallListener("my-screen", callEvents)

CometChatCalls.removeIncomingCallListener("my-screen")
```
</Tab>
<Tab title="Objective-C">
```objectivec
@interface CallEvents : NSObject <CometChatIncomingCallListener>
@end

@implementation CallEvents
- (void)onIncomingCallReceivedWithCall:(CometChatIncomingCall *)call {
    // A call for this user is ringing (CallKit already shows it)
}
- (void)onIncomingCallEndedWithCall:(CometChatIncomingCall *)call reason:(NSString *)reason {
    // The ring ended
}
@end

self.callEvents = [[CallEvents alloc] init];   // held weakly by the SDK: keep this reference
[CometChatCalls addIncomingCallListener:@"my-screen" :self.callEvents];

[CometChatCalls removeIncomingCallListener:@"my-screen"];
```
</Tab>
</Tabs>

| Event | Parameters | Description |
|-------|------------|-------------|
| `onIncomingCallReceived` | `CometChatIncomingCall` | A call for the logged-in user is ringing on this device |
| `onIncomingCallEnded` | `CometChatIncomingCall`, `reason` | The call ended before it was answered here, once per call: `cancelled` (the caller gave up), `ongoing` (answered on another device), `unanswered`, `rejected` / `busy`, or `ended` (the session prepared for it closed before the answer). Treat any other reason as "the ring is over". A decline or ring-out on this device is reported to the Push SDK delegate's `callDidEnd(_:reason:)` instead |

`CometChatIncomingCall` carries `sessionId`, `callerUid`, `callerName`, `callerAvatarUrl`, `callType`, `receiverType`, `receiverUid`, `conversationId`, `initiatedAt` (milliseconds), `isVideo` and `isPeerCall`.

<Note>
Listener ids are keys: registering the same id twice replaces the earlier listener. Do not use the id `cometchat-push-notifications`, which the Push SDK registers under.
</Note>

## Login Events

`CometChatCalls.addLoginListener` reports the Calls SDK login state. The Push SDK uses it to register and unregister the push tokens and to stop a ring when the user logs out; your app can use it to gate call UI.

<Tabs>
<Tab title="Swift">
```swift
import CometChatCallsSDK

// Qualify the protocol if your app also imports the Chat SDK, which has its own CometChatLoginDelegate.
final class CallsLoginEvents: NSObject, CometChatCallsSDK.CometChatLoginDelegate {
    func onLoginSuccess(user: CallsUser) {}
    func onLoginFailed(error: CometChatCallException?) {}
    func onLogoutSuccess() {}
    func onLogoutFailed(error: CometChatCallException?) {}
}

let loginEvents = CallsLoginEvents()   // held weakly by the SDK: keep this reference
CometChatCalls.addLoginListener("my-app", loginEvents)

CometChatCalls.removeLoginListener("my-app")
```
</Tab>
<Tab title="Objective-C">
```objectivec
// self adopts the Calls SDK's CometChatLoginDelegate
- (void)onLoginSuccessWithUser:(CallsSDKUser *)user {}
- (void)onLoginFailedWithError:(CometChatCallException *)error {}
- (void)onLogoutSuccess {}
- (void)onLogoutFailedWithError:(CometChatCallException *)error {}

[CometChatCalls addLoginListener:@"my-app" :self];

[CometChatCalls removeLoginListener:@"my-app"];
```
</Tab>
</Tabs>

| Event | Description |
|-------|-------------|
| `onLoginSuccess(user:)` | A user logged in to the Calls SDK |
| `onLoginFailed(error:)` | A login failed |
| `onLogoutSuccess()` | The user logged out |
| `onLogoutFailed(error:)` | A logout failed |

<Note>
Login listener ids are keys too: registering the same id twice replaces the earlier listener. Do not use the id `cometchat-push-notifications-calls`, which the Push SDK registers under.
</Note>
