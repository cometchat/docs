Share your own screen during a call, and view screen shares started by other participants.

<Note>
Starting a screen share from Flutter requires `cometchat_calls_sdk` 5.0.7 or later. On earlier
versions Flutter participants could only view shares started from other clients.
</Note>

## How It Works

When any participant starts screen sharing:
1. The SDK publishes or receives the screen share stream
2. The call layout automatically adjusts to display the shared screen prominently
3. Every participant in the session can view the shared content

## Start and Stop Screen Sharing

`CallSession` exposes the screen-share controls directly, so a custom control panel can drive
them without the SDK's built-in button:

```dart
CallSession? callSession = CallSession.getInstance();

// Start sharing the local screen
await callSession?.startScreenShare();

// Stop sharing
await callSession?.stopScreenShare();

// Or flip the current state
await callSession?.toggleScreenShare();

// Read the current state to drive your button's appearance
final bool sharing = callSession?.isScreenSharing ?? false;
```

On web this triggers the browser's screen picker (`getDisplayMedia`). On Android and iOS it
invokes the platform screen-share flow, which shows the system's own permission prompt.

<Note>
These methods throw `CometChatCallsException` if the screen share cannot be started — for
example when the user dismisses the system permission prompt. Wrap the call in a `try`/`catch`
if you surface errors in your UI.
</Note>

## Listen for Screen Share Events

Monitor when participants start or stop screen sharing:

```dart
class _ParticipantEventListener extends ParticipantEventListeners {
  @override
  void onParticipantStartedScreenShare(Participant participant) {
    debugPrint("${participant.name} started screen sharing");
    // Layout automatically adjusts to show shared screen
  }

  @override
  void onParticipantStoppedScreenShare(Participant participant) {
    debugPrint("${participant.name} stopped screen sharing");
    // Layout returns to normal view
  }
  // every other callback already defaults to a no-op on the abstract class —
  // override only what you need (onParticipantJoined, onParticipantLeft, onParticipantListChanged, onParticipantAudioMuted, …).
}

CallSession? callSession = CallSession.getInstance();

final screenShareListener = _ParticipantEventListener();
callSession?.addParticipantEventListener(screenShareListener);
```

<Note>
Flutter listeners are not lifecycle-aware, and `removeParticipantEventListener` matches on the
instance you passed in. Keep the listener in a field — a listener constructed inline can never
be removed — and call `callSession?.removeParticipantEventListener(screenShareListener)` from
your widget's `dispose()`.
</Note>

## Check Screen Share Status

`Participant` carries no screen-share flag. Track who is presenting yourself, by recording the
`mid` of whoever started sharing and clearing it when they stop:

```dart
class _PresenterTracker extends ParticipantEventListeners {
  String? presenterMid;
  String? presenterName;

  @override
  void onParticipantStartedScreenShare(Participant participant) {
    presenterMid = participant.mid;
    presenterName = participant.name;
  }

  @override
  void onParticipantStoppedScreenShare(Participant participant) {
    if (participant.mid == presenterMid) {
      presenterMid = null;
      presenterName = null;
    }
  }

  @override
  void onParticipantLeft(Participant participant) {
    if (participant.mid == presenterMid) {
      presenterMid = null;
      presenterName = null;
    }
  }
}

CallSession? callSession = CallSession.getInstance();

final presenterTracker = _PresenterTracker();
callSession?.addParticipantEventListener(presenterTracker);

// Later
if (presenterTracker.presenterMid != null) {
  debugPrint("${presenterTracker.presenterName} is currently sharing their screen");
}

// In dispose()
callSession?.removeParticipantEventListener(presenterTracker);
```

For your own screen share, read `callSession.isScreenSharing` rather than tracking events.
