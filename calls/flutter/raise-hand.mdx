Allow participants to raise their hand to get attention during calls. This feature is useful for large meetings, webinars, or any scenario where participants need to signal they want to speak.

## Raise Hand

Signal that you want to speak or get attention:

```dart
await CallSession.getInstance()?.raiseHand();
```

## Lower Hand

Remove the raised hand indicator:

```dart
await CallSession.getInstance()?.lowerHand();
```

## Listen for Raise Hand Events

Monitor when participants raise or lower their hands using `ParticipantEventListeners`:

```dart
class _ParticipantEventListener extends ParticipantEventListeners {
  @override
  void onParticipantHandRaised(Participant participant) {
    debugPrint("${participant.name} raised their hand");
    // Show notification or visual indicator
    showHandRaisedNotification(participant);
  }

  @override
  void onParticipantHandLowered(Participant participant) {
    debugPrint("${participant.name} lowered their hand");
    // Remove notification or visual indicator
    hideHandRaisedIndicator(participant);
  }
  // every other callback already defaults to a no-op on the abstract class —
  // override only what you need (onParticipantJoined, onParticipantLeft, onParticipantListChanged, onParticipantAudioMuted, …).
}

CallSession? callSession = CallSession.getInstance();

final handListener = _ParticipantEventListener();
callSession?.addParticipantEventListener(handListener);
```

<Note>
Flutter listeners are not lifecycle-aware, and `removeParticipantEventListener` matches on the
instance you passed in. Keep the listener in a field — a listener constructed inline can never
be removed — and call `callSession?.removeParticipantEventListener(handListener)` from your
widget's `dispose()`.
</Note>

## Check Raised Hand Status

`Participant` carries no raised-hand flag or timestamp. Build the raised-hand queue yourself
from the hand-raised and hand-lowered events, stamping the time as each hand goes up:

```dart
class _RaisedHandsTracker extends ParticipantEventListeners {
  /// Raise time in millis, keyed by participant `mid`.
  final Map<String, int> raisedAt = {};
  final Map<String, Participant> participants = {};

  @override
  void onParticipantHandRaised(Participant participant) {
    final mid = participant.mid;
    if (mid == null) return;
    raisedAt[mid] = DateTime.now().millisecondsSinceEpoch;
    participants[mid] = participant;
    updateRaisedHandsList(ordered);
  }

  @override
  void onParticipantHandLowered(Participant participant) {
    final mid = participant.mid;
    if (mid == null) return;
    raisedAt.remove(mid);
    participants.remove(mid);
    updateRaisedHandsList(ordered);
  }

  @override
  void onParticipantLeft(Participant participant) {
    final mid = participant.mid;
    if (mid == null) return;
    raisedAt.remove(mid);
    participants.remove(mid);
    updateRaisedHandsList(ordered);
  }

  /// Participants with a raised hand, oldest first.
  List<Participant> get ordered {
    final mids = raisedAt.keys.toList()
      ..sort((a, b) => raisedAt[a]!.compareTo(raisedAt[b]!));
    return mids.map((mid) => participants[mid]!).toList();
  }
}

CallSession? callSession = CallSession.getInstance();

final raisedHandsTracker = _RaisedHandsTracker();
callSession?.addParticipantEventListener(raisedHandsTracker);

// In dispose()
callSession?.removeParticipantEventListener(raisedHandsTracker);
```

<Note>
For the local user, read `callSession?.isHandRaised` instead of tracking events.
</Note>

## Hide Raise Hand Button

To disable the raise hand feature, hide the button in the call UI:

```dart
SessionSettings sessionSettings = SessionSettingsBuilder()
    .hideRaiseHandButton(true)
    .build();
```
