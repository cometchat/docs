CometChat publishes **product-scoped LLM docs indexes** — one per UI Kit, SDK, and product. Each is a
compact routing index of that area's docs pages (with the `.md`-twin convention) so an AI coding agent
can load only what's relevant instead of the entire site-wide corpus.

<Note>
This page is the **directory** of those scoped indexes. It is intentionally separate from the two
Mintlify-generated, site-wide files:
- **[/docs/llms.txt](https://www.cometchat.com/docs/llms.txt)** — the auto-generated index of *every*
  page across all products.
- **[/docs/llms-full.txt](https://www.cometchat.com/docs/llms-full.txt)** — the full concatenated
  corpus.

Use a scoped index below when you're building on one product; use `llms.txt` / `llms-full.txt` when
you need everything. Append `.md` to any docs page URL to get its clean Markdown twin.
</Note>
