*Learn how to integrate stickers by Stipop in your app.*

Stipop is the world's trendiest sticker platform and creator community.

## Before you begin

<Steps>
  <Step title="Create a Stipop account">
    Sign up at [Stipop](https://stipop.io/).
  </Step>
  <Step title="Complete your app details">
    Provide your application name, website, category, sub-category, region, and app MAU.
  </Step>
  <Step title="Get your credentials">
    Click **Get Started**, then copy the API Key from the dashboard. In **Settings** → **Application**, copy the Application ID.
  </Step>
</Steps>

## Extension settings

<Steps>
  <Step title="Open your CometChat app">
    Login to [CometChat](https://app.cometchat.com/login) and select your app.
  </Step>
  <Step title="Enable Stipop">
    Go to **Extensions** and enable the **Stipop** extension.
  </Step>
  <Step title="Add credentials">
    Open the settings and enter your Stipop Application ID and API Key.
  </Step>
  <Step title="Save settings">
    Save your configuration to activate the extension.
  </Step>
</Steps>

## How does it work?

The extension provides the following functionalities:

<CardGroup cols={2}>
  <Card title="Get trending stickers">
    Fetch current trending stickers from Stipop.
  </Card>
  <Card title="Search stickers">
    Search stickers using a phrase or keyword.
  </Card>
</CardGroup>

This extension uses the `callExtension` method provided by the CometChat SDK.

### Get trending stickers

The API call requires the following Query Parameters:

|             |        |                                                                                                                                 |
| ----------- | ------ | ------------------------------------------------------------------------------------------------------------------------------- |
| lang        | string | Specify default language for regional stickers. Use a 2-letter ISO 639-1 language code. **Default Value: en**                   |
| limit       | int    | The maximum number of stickers per page. Use pageNumber accordingly for optimized sticker view. **Default Value: 20 (max: 50)** |
| pageNumber  | int    | Specify pageNumber to show limit number of stickers per page.                                                                   |
| countryCode | string | Specify default country for local stickers. Use a 2-letter ISO 3166-1 country code. **Default Value: US**                       |

<Tabs>
<Tab title="JavaScript">
```js
const qs = `?lang=${lang}&limit=${limit}&pageNumber=${pageNumber}&countryCode=${contryCode}`;

CometChat.callExtension('stickers-stipop', 'GET', 'v1/trending' + qs, null)
  .then(response => {
		// Stickers in response
	})
	.catch(error => {
		// Error occured
	});
```

</Tab>

<Tab title="Java">
```java
String URL = "/v1/trending?lang="+language+"&limit="+limit+"&pageNumber="+pageNumber+"&countryCode="+countryCode;

CometChat.callExtension("stickers-stipop", "GET", URL, null,
	new CometChat.CallbackListener < JSONObject > () {
    @Override
    public void onSuccess(JSONObject jsonObject) {
        // Stickers
    }
    @Override
    public void onError(CometChatException e) {
        // Some error occured
    }
  });
```

</Tab>

```swift

        // Stickers

        // Some error occured
      }
    }
```

</Tab>

</Tabs>

### Search for stickers

The API call requires the following Query Parameters:

|            |        |                                                                                                                                 |
| ---------- | ------ | ------------------------------------------------------------------------------------------------------------------------------- |
| lang       | string | Specify default language for regional stickers. Use a 2-letter ISO 639-1 language code. **Default Value: en**                   |
| limit      | int    | The maximum number of stickers per page. Use pageNumber accordingly for optimized sticker view. **Default Value: 20 (max: 50)** |
| pageNumber | int    | Specify pageNumber to show limit number of stickers per page.                                                                   |
| query      | string | The search term for finding stickers.                                                                                           |
