---
title: "TinyURL"
---

Use TinyURL to shorten long links and keep messages clean and readable.

## Before you begin

<Steps>
  <Step title="Create a TinyURL account">
    Sign up with [TinyURL](https://tinyurl.com/app/login).
  </Step>
  <Step title="Generate an API token">
    In TinyURL, open **Account** → **API** and create a token with permission to create TinyURL links.
  </Step>
  <Step title="Save the token">
    Keep the API token handy for the extension settings.
  </Step>
</Steps>

## Extension settings

<Steps>
  <Step title="Open your CometChat app">
    Login to [CometChat](https://app.cometchat.com/login) and select your app.
  </Step>
  <Step title="Enable TinyURL">
    Go to **Chat & Messaging --> Features**, under **Extentions** and enable **TinyURL**. 
  </Step>
  <Step title="Add credentials">
    Open the settings and enter the TinyURL API Token.
  </Step>
  <Step title="Configure BYO domain (optional)">
    If you have a paid plan, add your custom domain or subdomain. The default is `tinyurl.com`.
  </Step>
  <Step title="Save settings">
    Save your configuration to activate the extension.
  </Step>
</Steps>

<Note>
If you don't plan on using a custom domain, keep `tinyurl.com` as the default value.
</Note>

## How does it work?

This extension uses the `callExtension` method provided by CometChat SDK. You can call the extension as follows:

<Tabs>
<Tab title="JavaScript">
```js
CometChat.callExtension("url-shortener-tinyurl", "POST", "v1/shorten", {
  text: "Your message with URL https://yourdomain.com/very/very/long/url",
})
  .then((response) => {
    // minifiedText in response
  })
  .catch((error) => {
    // Error occured
  });
```

</Tab>

<Tab title="Java">
```java
String URL = "/v1/shorten";
JSONObject body=new JSONObject();

body.put("text", "Your message with URL https://yourdomain.com/very/very/long/url");

CometChat.callExtension("url-shortener-tinyurl", "POST", URL, body,
new CometChat.CallbackListener < JSONObject > () {
    @Override
    public void onSuccess(JSONObject jsonObject) {
        // minifiedText from the extension
    }
    @Override
    public void onError(CometChatException e) {
        // Some error occured
    }
});
```

</Tab>

<Tab title="Swift">
```swift
CometChat.callExtension(slug: "url-shortener-tinyurl", type: .post, endPoint: "v1/shorten", body: ["text": "Your message with URL https://yourdomain.com/very/very/long/url"], onSuccess: { (response) in
        // minifiedText from the extension
      }) { (error) in
        // Some error occured
      }
    }
```

</Tab>

</Tabs>
