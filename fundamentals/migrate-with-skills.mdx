If you're moving to CometChat from another chat provider, your AI coding agent can do the migration for you. With [CometChat Agent Skills](/agent-skills) installed, one prompt migrates your app's code, and the same run prepares and imports your users, groups and message history.

You can migrate from:

- **Sendbird** (Chat SDK, UIKit and Calls)
- **Stream (GetStream)** (Chat SDK and UI components)
- **Twilio Conversations** (and the older Programmable Chat)

The skills work on every platform they support: React, Angular, React Native, iOS, Android and Flutter.

## Before you start

1. **Install the skills.** Follow [Install](/agent-skills#install) on the Agent Skills page.
2. **Create a CometChat app** at [app.cometchat.com](https://app.cometchat.com). The migration never creates one for you.
3. **Get your keys ready.** For the data import you need your current provider's API credentials and a **full-access REST API key** from your CometChat app. The agent asks for these when it runs the import. It passes them as environment variables and never writes them into your repo.
4. **Node.js 18 or newer**, which the data-import script runs on.

## Migrate your app and data

Open your project in your coding agent and say:

```
Migrate my app to CometChat.
```

The agent detects which provider you're on and migrates your app in one run. It replaces the provider's SDK or UI components with CometChat's, removes any feature CometChat has no equivalent for (and lists each one), moves your token server and webhooks, and checks that the app builds. It works on a new `cometchat-migration` git branch and never commits, so you can review the whole diff before you merge.

When the code is done, the agent tells you the data-import script is ready and asks for your keys. It then imports your data for you, with a dry run first. See [Import your data](#import-your-data) for what that covers.

For everything the app migration changes, and how to prepare your repo, see [Migrate from another chat provider](/agent-skills#migrate-from-another-chat-provider).

## Migrate only your data

If you only need your history moved, for example because you're rebuilding the UI yourself or your app already runs on CometChat, ask for the data import on its own:

```
Migrate only my data from Sendbird to CometChat. Don't change my app code.
```

Replace `Sendbird` with `Stream` or `Twilio` as needed. The agent writes the same data-import script the full migration uses, in `scripts/cometchat-migration/`, then asks for your keys and runs it.

<Note>
Your app has to log users in to CometChat with the same user IDs the import creates. The script converts each provider user ID into a valid CometChat UID with a `toCometChatId()` helper. Use the same conversion wherever your app or server logs users in, or users will sign in to empty inboxes.
</Note>

## Import your data

Whichever option you pick, the import works the same way:

- **What moves:** users, groups, group members and messages, including attachments. One-to-one channels become one-to-one conversations, not two-person groups.
- **Dry run first:** the agent shows how many users, groups, members and messages it will import, then runs the real import and reports what landed and what failed.
- **Message history window:** CometChat keeps messages for the last **6 months** by default, so the import brings over history from that window. To import older messages, [contact CometChat](https://www.cometchat.com/contact-sales).
- **Attachments:** CometChat stores attachment URLs by reference. Move your files to storage you control before you shut down your old provider, or images and files in old messages will break.
- **Limits:** the script stays within the [Data Import API](/rest-api/data-import) batch size and rate limits.

## Choose a cut-over strategy

- **Hard switch (default):** import your data, then release the migrated app. Do it in a maintenance window so no messages are sent during the copy.
- **Zero-downtime live migration:** keep both systems in sync while users update gradually. This is set up with CometChat's team; [contact sales](https://www.cometchat.com/contact-sales).

See [Data Import and Migration](/fundamentals/data-import-and-migration) for how the two approaches compare.
