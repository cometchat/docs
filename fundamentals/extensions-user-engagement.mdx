## Giphy

GIFs are a great way to change the tone or convey emotions in your conversations.

<Note>
**Available via:** [UI Kit Builder](/chat-builder/react/overview) ✅ | [Widget Builder](/widget/html/overview) ✅ | [UI Kits](/ui-kit/react/overview) ✅ | [SDK](/sdk/javascript/overview) ✅
</Note>

### Before you begin

<Steps>
  <Step title="Create a Giphy app">
    Sign up at [Giphy](https://developers.giphy.com/dashboard/) and create a new app.
  </Step>
  <Step title="Select API access">
    Select **API** and click **Next**.
  </Step>
  <Step title="Save your API key">
    Enter your app name and description, create the app, then copy the API key.
  </Step>
</Steps>

### Extension settings

<Steps>
  <Step title="Open your CometChat app">
    Login to [CometChat](https://app.cometchat.com/login) and select your app.
  </Step>
  <Step title="Enable Giphy">
    Go to **Chat & Messaging --> Features**, under **Extentions** and enable **Giphy**. 
  </Step>
  <Step title="Add your API key">
    Open the extension settings, paste your Giphy API key, and save.
  </Step>
</Steps>

### Code

#### Get Trending GIFs

<Tabs>
<Tab title="JavaScript">
```js
const URL = "v1/trending?offset=1&limit=15";
CometChat.callExtension("gifs-giphy", "GET", URL, null)
  .then((response) => {
    // GIFs data from Giphy
  })
  .catch((error) => {
    // Error occured
  });
```
</Tab>
<Tab title="Java">
```java
String URL = "/v1/trending?offset=1&limit=15";

CometChat.callExtension("gifs-giphy", "GET", URL, null,
new CometChat.CallbackListener < JSONObject > () {
    @Override
    public void onSuccess(JSONObject jsonObject) {
        // GIFs data from Giphy
    }
    @Override
    public void onError(CometChatException e) {
        // Some error occured
    }
});
```
</Tab>
<Tab title="Swift">
```swift
CometChat.callExtension(slug: "gifs-giphy", type: .get, endPoint: "v1/trending?offset=10&limit=15", body: nil, onSuccess: { (response) in
        // GIFs data from Giphy
      }) { (error) in
        // Some error occured
      }
    }
```
</Tab>
</Tabs>

#### Search for GIFs

<Tabs>
<Tab title="JavaScript">
```js
const URL = "v1/search?offset=1&limit=15&query=awesome";
CometChat.callExtension("gifs-giphy", "GET", URL, null)
  .then((response) => {
    // GIFs data from Giphy
  })
  .catch((error) => {
    // Error occured
  });
```
</Tab>
</Tabs>

## Message Translation

The Message Translation extension helps you translate messages into multiple languages.

<Note>
**Available via:** [UI Kit Builder](/chat-builder/react/overview) ✅ | [Widget Builder](/widget/html/overview) ✅ | [UI Kits](/ui-kit/react/overview) ✅ | [SDK](/sdk/javascript/overview) ✅
</Note>

### Extension settings

<Steps>
  <Step title="Open your CometChat app">
    Login to [CometChat](https://app.cometchat.com/login) and select your app.
  </Step>
  <Step title="Enable Message Translation">
    Go to **Chat & Messaging --> Features**, under **Extentions** and enable **Message Translation**. 
  </Step>
</Steps>

### Supported Languages

We support translations in 70+ languages including: English (en), Spanish (es), French (fr), German (de), Chinese Simplified (zh), Japanese (ja), Korean (ko), Hindi (hi), Arabic (ar), Russian (ru), Portuguese (pt), and many more.

<Note>
Language codes follow [RFC 5646](https://en.wikipedia.org/wiki/List_of_ISO_639-2_codes). Use ISO 639-1 codes where available.
</Note>

### Code

<Tabs>
<Tab title="JavaScript">
```js
CometChat.callExtension('message-translation', 'POST', 'v2/translate', {
  "msgId": 12,
  "text": "Hey there! How are you?",
  "languages": [ "ru", "hi", "mr" ]
}).then( result => {
  // Result of translations
})
.catch(error => {
  // Some error occured
});
```
</Tab>
<Tab title="Java">
```java
JSONObject body=new JSONObject();
JSONArray languages = new JSONArray();

languages.add("ru");
languages.add("hi");

body.put("msgId", 12);
body.put("languages", languages);
body.put("text", "Hey there! How are you?");

CometChat.callExtension("message-translation", "POST", "/v2/translate", body,
 new CometChat.CallbackListener < JSONObject > () {
    @Override
    public void onSuccess(JSONObject jsonObject) {
        // Result of translations
    }
    @Override
    public void onError(CometChatException e) {
        // Some error occured
    }
});
```
</Tab>
<Tab title="Swift">
```swift
CometChat.callExtension(slug: "message-translation", type: .post, endPoint: "v2/translate", body: ["msgId": 12 ,"languages": ["hi", "ru"], "text": "Hey there! How are you?"] as [String : Any], onSuccess: { (response) in
         // Result of translations
      }) { (error) in
         // Some error occured
      }
```
</Tab>
</Tabs>

## Polls

Polls let you quickly record opinions directly in conversations and view the results.

<Note>
**Available via:** [UI Kit Builder](/chat-builder/react/overview) ✅ | [Widget Builder](/widget/html/overview) ✅ | [UI Kits](/ui-kit/react/overview) ✅ | [SDK](/sdk/javascript/overview) ✅
</Note>

### Extension settings

<Steps>
  <Step title="Open your CometChat app">
    Login to [CometChat](https://app.cometchat.com/login) and select your app.
  </Step>
  <Step title="Enable Polls">
    Go to **Chat & Messaging --> Features**, under **Extentions** and enable **Polls**. 
  </Step>
</Steps>

### Code

#### Creating a Poll

<Tabs>
<Tab title="JavaScript">
```js
CometChat.callExtension('polls', 'POST', 'v2/create', {
    "question": "Which OS do you use?",
    "options": ["Windows", "Ubuntu", "MacOS", "Other"],
    "receiver": "cometchat-uid-1",
    "receiverType": "user"
}).then(response => {
    // Details about the created poll
})
.catch(error => {
    // Error occured
});
```
</Tab>
<Tab title="Java">
```java
JSONObject body=new JSONObject();
JSONArray options = new JSONArray();

options.add("Milk");
options.add("Cereal");

body.put("question", "Milk goes first or the cereal?");
body.put("options", options);
body.put("receiver", "cometchat-guid-1");
body.put("receiverType", "group");

CometChat.callExtension("polls", "POST", "/v2/create", body,
 new CometChat.CallbackListener < JSONObject > () {
    @Override
    public void onSuccess(JSONObject jsonObject) {
        //On Success
    }
    @Override
    public void onError(CometChatException e) {
        //On Failure
    }
});
```
</Tab>
<Tab title="Swift">
```swift
CometChat.callExtension(slug: "polls", type: .post, endPoint: "v2/create", body: ["question": "Which OS do you use?" ,"options":["Windows", "Ubuntu", "MacOS", "Other"],"receiver":"cometchat-uid-1","receiverType":"user"] as [String : Any], onSuccess: { (response) in
         // Details about the created poll
      }) { (error) in
         // Error occured
      }
```
</Tab>
</Tabs>

#### Voting in a Poll

<Tabs>
<Tab title="JavaScript">
```js
CometChat.callExtension('polls', 'POST', 'v2/vote', {
    vote: "3",
    id: "d5441d53-c191-4696-9e92-e4d79da7463",
}).then(response => {
    // Successfully voted
})
.catch(error => {
    // Error Occured
});
```
</Tab>
</Tabs>

#### Getting Results

<Tabs>
<Tab title="JavaScript">
```js
CometChat.callExtension('polls', 'GET', 'v2/results?id='+POLL_ID, null)
.then(results => {
  // Poll results
})
.catch(error => {
  // Some error occured
});
```
</Tab>
</Tabs>

<Note>
Polls are custom messages. Use the `incrementUnreadCount` flag in `metadata` to update unread counters when a poll is received.
</Note>

## Reminders

Create reminders for messages or anything else.

<Note>
**Available via:** [UI Kit Builder](/chat-builder/react/overview) ✅ | [Widget Builder](/widget/html/overview) ✅ | [UI Kits](/ui-kit/react/overview) ✅ | [SDK](/sdk/javascript/overview) ✅
</Note>

### Extension Settings

<Steps>
  <Step title="Open your CometChat app">
    Login to [CometChat](https://app.cometchat.com/login) and select your app.
  </Step>
  <Step title="Enable Reminders">
    Go to **Chat & Messaging --> Features**, under **Extentions** and enable **Reminders**.
  </Step>
  <Step title="Create the reminder bot user">
    In **Users**, create a user with UID `cc_reminder_bot`. The name and avatar can be of your choice.
  </Step>
</Steps>

<Note>
The `cc_reminder_bot` user must exist for your app. Ensure no existing user uses the same UID.
</Note>

### Code

#### Set Message Reminders

<Tabs>
<Tab title="JavaScript">
```js
CometChat.callExtension('reminders', 'POST', 'v1/reminder', {
  about: 1,
  isCustom: false,
  timeInMS: 1638351344989
}).then(response => {
  // Reminder created successfully
}).catch(error => {
  // Some error occured
});
```
</Tab>
</Tabs>

#### Set Personal Reminders

<Tabs>
<Tab title="JavaScript">
```js
CometChat.callExtension('reminders', 'POST', 'v1/reminder', {
  about: "Drinking water",
  isCustom: true,
  timeInMS: 1638351344989
}).then(response => {
  // Reminder created successfully
}).catch(error => {
  // Some error occured
});
```
</Tab>
</Tabs>

#### List Reminders

<Tabs>
<Tab title="JavaScript">
```js
CometChat.callExtension('reminders', 'GET', 'v1/fetch', null).then(response => {
  // reminders array
}).catch(error => {
  // Some error occured
});
```
</Tab>
</Tabs>

#### Delete Reminders

<Tabs>
<Tab title="JavaScript">
```js
CometChat.callExtension('reminders', 'DELETE', 'v1/reminder', {
  reminderId: "e9cda52a-3839-4fd5-a010-b70db136f0f1"
}).then(response => {
  // Reminder deleted successfully
}).catch(error => {
  // Some error occured
});
```
</Tab>

## Stickers

The Stickers Extension is an image manager which allows you to quickly add/remove stickers directly from the dashboard.

<Note>
**Available via:** [UI Kit Builder](/chat-builder/react/overview) ✅ | [Widget Builder](/widget/html/overview) ✅ | [UI Kits](/ui-kit/react/overview) ✅ | [SDK](/sdk/javascript/overview) ✅
</Note>

### Extension settings

<Steps>
  <Step title="Open your CometChat app">
    Login to [CometChat](https://app.cometchat.com/login) and select your app.
  </Step>
  <Step title="Enable Stickers">
    Go to **Chat & Messaging --> Features**, under **Extentions** and enable **Stickers**. 
  </Step>
</Steps>

<Note>
CometChat provides 14 default sticker sets. You can also create your own sets and enable only the stickers you want to use.
</Note>

### Code

#### Loading Stickers

<Tabs>
<Tab title="JavaScript">
```js
CometChat.callExtension('stickers', 'GET', 'v1/fetch', null)
.then(stickers => {
  // Stickers received
})
.catch(error => {
  // Some error occured
});
```
</Tab>
<Tab title="Java">
```java
CometChat.callExtension("stickers", "GET", "/v1/fetch", null,
    new CometChat.CallbackListener<JSONObject>() {
    @Override
    public void onSuccess(JSONObject responseObject) {
        // Stickers received here.
    }
    @Override
    public void onError(CometChatException e) {
        // Some error occured.
    }
});
```
</Tab>
<Tab title="Swift">
```swift
CometChat.callExtension(slug: "stickers", type: .get, endPoint: "v1/fetch", body: nil, onSuccess: { (response) in
  print("Success",response)
}) { (error) in
  print("Error",error?.errorCode, error?.errorDescription)
}
```
</Tab>
</Tabs>

## Stipop

Stipop is the world's trendiest sticker platform and creator community.

<Note>
**Available via:** [UI Kit Builder](/chat-builder/react/overview) ✅ | [Widget Builder](/widget/html/overview) ✅ | [UI Kits](/ui-kit/react/overview) ✅ | [SDK](/sdk/javascript/overview) ✅
</Note>

### Before you begin

<Steps>
  <Step title="Create a Stipop account">
    Sign up at [Stipop](https://stipop.io/).
  </Step>
  <Step title="Complete your app details">
    Provide your application name, website, category, sub-category, region, and app MAU.
  </Step>
  <Step title="Get your credentials">
    Click **Get Started**, then copy the API Key from the dashboard. In **Settings** → **Application**, copy the Application ID.
  </Step>
</Steps>

### Extension settings

<Steps>
  <Step title="Open your CometChat app">
    Login to [CometChat](https://app.cometchat.com/login) and select your app.
  </Step>
  <Step title="Enable Stipop">
    Go to **Chat & Messaging --> Features**, under **Extentions** and enable **Stipop**. 
  </Step>
  <Step title="Add credentials">
    Open the settings and enter your Stipop Application ID and API Key.
  </Step>
</Steps>

### Code
