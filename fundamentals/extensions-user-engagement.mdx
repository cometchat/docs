## Giphy

Access the world's largest GIF library directly in your chat. Giphy offers extensive content moderation controls and supports multiple platforms.

**When to use:** You want the widest GIF selection with strong content filtering options.

<Note>
**Out-of-the-box in:** [UI Kit Builder](/chat-builder/react/features) <Tooltip tip="Not available out of the box in the UI Kit — supported via the SDK and requires custom implementation.">🔨</Tooltip> | [Widget Builder](/widget/html/features) ❌ | [UI Kits](/ui-kit/react/core-features) <Tooltip tip="Not available out of the box in the UI Kit — supported via the SDK and requires custom implementation.">🔨</Tooltip> | [SDK](/sdk/javascript/overview) ✅
</Note>

<Frame>
  <img src="/images/extension-save-message.png" />
</Frame>

### Before you begin

<Steps>
  <Step title="Create a Giphy app">
    Sign up at [Giphy](https://developers.giphy.com/dashboard/) and create a new app.
  </Step>
  <Step title="Select API access">
    Select **API** and click **Next**.
  </Step>
  <Step title="Save your API key">
    Enter your app name and description, create the app, then copy the API key.
  </Step>
</Steps>

### Extension settings

<Steps>
  <Step title="Open your CometChat app">
    Login to [CometChat](https://app.cometchat.com/login) and select your app.
  </Step>
  <Step title="Enable Giphy">
    Go to **Chat & Messaging --> Features**, under **Extentions** and enable **Giphy**. 
  </Step>
  <Step title="Add your API key">
    Open the extension settings, paste your Giphy API key, and save.
  </Step>
</Steps>

## Stickers

The Stickers Extension is an image manager which allows you to quickly add/remove stickers directly from the dashboard. Full control over your sticker library.

**When to use:** You want to curate your own sticker sets or use custom branded stickers.

<Note>
**Out-of-the-box in:** [UI Kit Builder](/chat-builder/react/features) ✅ | [Widget Builder](/widget/html/features) ✅ | [UI Kits](/ui-kit/react/extensions#stickers) ✅ | [SDK](/sdk/javascript/overview) ✅
</Note>

<Frame>
  <img src="/images/extension-stickers.png" />
</Frame>

### Extension settings

<Steps>
  <Step title="Open your CometChat app">
    Login to [CometChat](https://app.cometchat.com/login) and select your app.
  </Step>
  <Step title="Enable Stickers">
    Go to **Chat & Messaging --> Features**, under **Extentions** and enable **Stickers**. 
  </Step>
</Steps>

<Note>
CometChat provides 14 default sticker sets. You can also create your own sets and enable only the stickers you want to use.
</Note>

## Message Translation

Translate messages in real-time to break language barriers. Supports multiple languages and integrates with Google Translate.

**When to use:** International teams, global communities, customer support across regions.

<Note>
**Out-of-the-box in:** [UI Kit Builder](/chat-builder/react/features) <Tooltip tip="Not available out of the box in the UI Kit — supported via the SDK and requires custom implementation.">🔨</Tooltip> | [Widget Builder](/widget/html/features) ❌ | [UI Kits](/ui-kit/react/core-features) <Tooltip tip="Not available out of the box in the UI Kit — supported via the SDK and requires custom implementation.">🔨</Tooltip> | [SDK](/sdk/javascript/overview) ✅
</Note>

### Before you begin

<Steps>
  <Step title="Create a Google Cloud project">
    Sign up at [Google Cloud Console](https://console.cloud.google.com/) and create a new project.
  </Step>
  <Step title="Enable Cloud Translation API">
    In your project, go to **APIs & Services** → **Library** and enable the **Cloud Translation API**.
  </Step>
  <Step title="Create API credentials">
    Go to **APIs & Services** → **Credentials** and create an API key.
  </Step>
</Steps>

### Extension settings

<Steps>
  <Step title="Open your CometChat app">
    Login to [CometChat](https://app.cometchat.com/login) and select your app.
  </Step>
  <Step title="Enable Message Translation">
    Go to **Chat & Messaging --> Features**, under **Extentions** and enable **Message Translation**. 
  </Step>
  <Step title="Add your API key">
    Open the extension settings, paste your Google Cloud API key, and save.
  </Step>
</Steps>
