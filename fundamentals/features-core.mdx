CometChat's Core features are the essentials you need to deliver a complete, real-time chat experience. Use these features as the foundation for reliable one-to-one and group conversations.

<Note>
**Available via:**  [UI Kit Builder](/chat-builder/react/overview) ✅ | [Widget Builder](/widget/html/overview) ✅ | [UI Kits](/ui-kit/react/overview) ✅ | [SDK](/sdk/javascript/overview) ✅
</Note>

## Core Features

### **Instant Messaging**
- Enable real-time one-to-one and group chat so users can send and receive messages instantly.

  <img src="/images/94312eb7-intro_web_screens-7ee27b256c54ea069273e198ec2aad4e.png" />
</Frame>

### **Media Sharing**
- Let users share images, videos, documents, and other files directly within conversations.

<Frame>
  <img src="/images/56d32794-feature_media_sharing_web_screens-85d19aa1d4efea1f5bfec8a718e67d1c.png" />
</Frame>

### **Read Receipts**
- Show when messages are delivered and when they are read, so users know message status at a glance.

<Frame>
  <img src="/images/bf16bef1-feature_read_receipt_web_screens-68fddd4e39d86dfcb7d41b5e945dcdc3.png" />

### **Mark as Unread**
- Allow users to mark messages as unread so they can revisit important conversations later.

<Frame>
  <img src="/images/mark-as-unread-react-uikit-overview.png" />
</Frame>

### **Typing Indicators**
- Display when another user is typing to make conversations feel more responsive and natural.

<Frame>
  <img src="/images/5de16f7b-feature_typing_indicator_web_screens-da2f83292de9815655d0b5b0ff6fef6f.png" />

### **User Presence**
- Show online, offline, and last-seen states to help users understand availability.

<Frame>
  <img src="/images/dc91a3ce-feature_status_indicator_web_screens-b7e131fd1b9b8b61db986a037c711e06.png" />

### **Reactions**
- Let users react to messages with emojis for quick feedback without sending a new message.

  <img src="/images/a1c1501b-reactions_web_screens-f04b4e202fdd5d9fd9c86056eed31247.png" />

### **Mentions**
- Tag specific users (or everyone in a group) to draw attention inside busy conversations.

  <img src="/images/a4778ade-mentions_web_screens-554df9099f110c592be8b32b750d64d2.png" />

### **Threaded Conversations**
- Create message threads inside group chats to keep context organized.

  <img src="/images/c61ec9db-threaded_conversations-3aa9e480dfcc47159d393052f19f313f.png" />

### **Quoted Replies**
- Reply to a specific message with a quote to maintain clarity and context.

<Frame>
  <img src="/images/f42ad8d3-swipe-to-reply_web_screens-c9204e4c244ca55a7ffe6c9498299625.png" />

### **Group Chats**
- Support conversations with multiple participants for teams, communities, or events.

<Frame>
  <img src="/images/f42ad8d3-group_chat_web_screens-c9204e4c244ca55a7ffe6c9498299625.png" />
</Frame>

### **Report Message**
- Allow users to report inappropriate or harmful messages directly from chat.

<Frame>
  <img src="/images/react-uikit-report-message-overview.png" />
</Frame>

### **Conversation and Advanced Search**
- Search conversations by user or group name, apply advanced message filters such as links, attachments, reactions, mentions, or specinc mentioned UIDs, and search across all conversations. 
<Note>
**Note:** Conversation search and advanced message search requires enabling the feature in the CometChat dashboard under "Chat and Messaging" > "Features" > "Conversation and Advanced Search".
</Note>
