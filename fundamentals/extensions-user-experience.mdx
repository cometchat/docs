## Bitly

Use Bitly to shorten long URLs in messages and keep links clean and consistent. Bitly provides click tracking and analytics for shared links.

**When to use:** You need link analytics, branded short domains, or enterprise-grade URL management.

<Note>
**Out-of-the-box in:** [UI Kit Builder](/chat-builder/react/overview) <Tooltip tip="Can be built using SDK">🔨</Tooltip> | [Widget Builder](/widget/html/overview) ❌ | [UI Kits](/ui-kit/react/overview) <Tooltip tip="Can be built using SDK">🔨</Tooltip> | [SDK](/sdk/javascript/overview) ✅
</Note>

<Note>
**SDK Implementation:** [JavaScript](/sdk/javascript/extensions/user-experience#bitly) ✅ | [Android](/sdk/android/extensions/user-experience#bitly) ✅ | [iOS](/sdk/ios/extensions/user-experience#bitly) ✅ | [Flutter](/sdk/flutter/extensions/user-experience) ❌
</Note>

<Note>
You need a Bitly Access Token and your Bitly Group GUID to enable this extension.
</Note>

### Before you begin

<Steps>
  <Step title="Create a Bitly account">
    Sign up at [Bitly](https://bitly.com/).
  </Step>
  <Step title="Generate an access token">
    In Bitly, open **Settings** → **API** and generate a new Access Token.
  </Step>
  <Step title="Get your Group GUID">
    Use Bitly's [Get Groups API](https://dev.bitly.com/api-reference#getGroups) with the token to fetch your Group GUID.
  </Step>
</Steps>

### Extension settings

<Steps>
  <Step title="Enable Bitly in your CometChat app">
    Login to [Dashboard](https://app.cometchat.com/login), select your app, then go to **Chat & Messaging --> Features**, under **Extentions** and enable **Bitly**.
  </Step>
  <Step title="Add credentials">
    Open the extension settings and enter your Bitly Access Token and Group GUID.
  </Step>
  <Step title="Save settings">
    Save your configuration to activate the extension.
  </Step>
</Steps>

## Link Preview

The Link Preview extension shows a preview of the web page for every link in your message. Returns raw metadata that you can style however you want.

**When to use:** You want full control over how link previews look in your app.

<Note>
**Out-of-the-box in:** [UI Kit Builder](/chat-builder/react/overview) ✅ | [Widget Builder](/widget/html/overview) ✅ | [UI Kits](/ui-kit/react/extensions#link-preview) ✅ | [SDK](/sdk/javascript/overview) ✅
</Note>

<Note>
**SDK Implementation:** [JavaScript](/sdk/javascript/extensions/user-experience#link-preview) ✅ | [Android](/sdk/android/extensions/user-experience#link-preview) ✅ | [iOS](/sdk/ios/extensions/user-experience#link-preview) ✅ | [Flutter](/sdk/flutter/extensions/user-experience) ❌
</Note>

<Note>
If you want a ready-to-render preview card, use [Rich Media Preview](#rich-media-preview).
</Note>

</Frame>

### Extension settings

<Steps>
  <Step title="Open your CometChat app">
    Login to [CometChat](https://app.cometchat.com/login) and select your app.
  </Step>
  <Step title="Enable Link Preview">
    Go to **Chat & Messaging --> Features**, under **Extentions** and enable **Link Preview**.
  </Step>
</Steps>

### How does it work?

We provide a few details about the URL that is in your message:

- **Description**: Summary text pulled from the page.
- **Favicon**: The site's icon for display.
- **Image**: Preview image for the link.
- **Title**: Page title resolved from the URL.
- **URL**: The final resolved link.

These details are provided as part of metadata:

```json
"@injected": {
  "extensions": {
    "link-preview": {
      "links": [
        {
          "description": "Create an account or log into Facebook...",
          "favicon": "https://static.xx.fbcdn.net/rsrc.php/yz/r/KFyVIAWzntM.ico",
          "image": "https://www.facebook.com/images/fb/icon/325x325.png",
          "title": "Facebook - Log In or Sign Up",
          "url": "https://www.facebook.com"
        }
      ]
    }
  }
}
```

<Warning>
Links that take more than a second to resolve will be automatically skipped to keep in-flight transit time to a minimum.
</Warning>

## Message shortcuts

The Message shortcuts extension enables your users to send predefined messages. For example, **!hb** can be automatically expanded to **Happy birthday!**

**When to use:** Support teams with canned responses, communities with common greetings, or any app where users send repetitive messages.

**Out-of-the-box in:** [UI Kit Builder](/chat-builder/react/overview) <Tooltip tip="Can be built using SDK">🔨</Tooltip> | [Widget Builder](/widget/html/overview) ❌ | [UI Kits](/ui-kit/react/overview) <Tooltip tip="Can be built using SDK">🔨</Tooltip> | [SDK](/sdk/javascript/overview) ✅

</Note>

Global shortcuts are available to all users. User-created shortcuts are private to the creator.
