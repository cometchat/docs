Use Bitly to shorten long URLs in messages and keep links clean and consistent.

<Note>
**Available via:**  
| Platform | Setup |
|----------|:-------:|
| [UI Kit Builder](/chat-builder/react/overview) | <Tooltip headline="Setup" tip="Needs to be enabled in the dashboard and UI Kit Builder"><Icon icon="info" size={12} /></Tooltip> |
| [Widget Builder](/widget/html/overview) | <Tooltip headline="Setup" tip="Needs to be enabled in the dashboard and Widget Builder"><Icon icon="info" size={12} /></Tooltip> |
| [UI Kits](/ui-kit/react/overview) | <Tooltip headline="Setup" tip="Needs to be enabled in the dashboard"><Icon icon="info" size={12} /></Tooltip> |
| [SDK](/sdk/javascript/overview) | <Tooltip headline="Setup" tip="Needs to be enabled in the dashboard"><Icon icon="info" size={12} /></Tooltip> |

</Note>

<Note>
You need a Bitly Access Token and your Bitly Group GUID to enable this extension.
</Note>

## Before you begin

<Steps>
  <Step title="Create a Bitly account">
    Sign up at [Bitly](https://bitly.com/).
  </Step>
  <Step title="Generate an access token">
    In Bitly, open **Settings** → **API** and generate a new Access Token.
  </Step>
  <Step title="Get your Group GUID">
    Use Bitly's [Get Groups API](https://dev.bitly.com/api-reference#getGroups) with the token to fetch your Group GUID.
  </Step>
</Steps>

## Extension settings

<Steps>
  <Step title="Enable Bitly in your CometChat app">
    Login to [CometChat](https://app.cometchat.com/login), select your app, then go to **Extensions** and enable **Bitly**.
  </Step>
  <Step title="Add credentials">
    Open the extension settings and enter your Bitly Access Token and Group GUID.
  </Step>
  <Step title="Save settings">
    Save your configuration to activate the extension.
  </Step>
</Steps>

## How does it work (If you are using SDK)?

This extension uses the `callExtension` method provided by the CometChat SDK. You can call the extension as follows:

<Tabs>
<Tab title="JavaScript">
```js
CometChat.callExtension("url-shortener-bitly", "POST", "v1/shorten", {
  text: "Your message with URL https://yourdomain.com/very/very/long/url",
})
  .then((response) => {
    // minifiedText in response
  })
  .catch((error) => {
    // Error occured
  });
```

</Tab>

<Tab title="Java">
```java
String URL = "/v1/shorten";
JSONObject body=new JSONObject();

body.put("text", "Your message with URL https://yourdomain.com/very/very/long/url");

CometChat.callExtension("url-shortener-bitly", "POST", URL, body,
new CometChat.CallbackListener < JSONObject > () {
    @Override
    public void onSuccess(JSONObject jsonObject) {
        // minifiedText from the extension
    }
    @Override
    public void onError(CometChatException e) {
        // Some error occured
    }
});
```

</Tab>

<Tab title="Swift">
```swift
CometChat.callExtension(slug: "url-shortener-bitly", type: .post, endPoint: "v1/shorten", body: ["text": "Your message with URL https://yourdomain.com/very/very/long/url"], onSuccess: { (response) in
        // minifiedText from the extension
      }) { (error) in
        // Some error occured
      }
    }
```

</Tab>

</Tabs>
