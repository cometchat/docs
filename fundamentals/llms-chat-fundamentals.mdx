# Chat Fundamentals & Extensions — LLM docs index

> A **Chat Fundamentals-scoped** routing index for AI coding agents — a smaller alternative to the
> site-wide `/docs/llms.txt`. See the full directory at [/docs/llms-index](/llms-index).

## How to use this index
Each link points to a docs page; **append `.md`** to its URL to fetch the clean Markdown twin
(verbatim code + an "AI Integration Quick Reference" block where present). Convention: any docs page
URL + `.md` → raw Markdown. Fallback: if a `.md` twin 404s, fetch the same URL **without** `.md`
(HTML). Never answer props/APIs from memory.
