**Resources** is a menu of links that open in a new tab.

**Where:** left navigation → **Account** → **Resources**.

| Link | Opens | Use it to |
| --- | --- | --- |
| **Create support ticket** | [help.cometchat.com](https://help.cometchat.com/hc/en-us/requests/new) | Contact CometChat support. |
| **Developer docs** | [cometchat.com/docs](https://www.cometchat.com/docs/) | Read these docs. |
| **API docs** | [REST API reference](https://api-explorer.cometchat.com/reference/chat-apis) | Look up REST endpoints. |
| **Sample apps** | [github.com/cometchat](https://github.com/cometchat) | Start from working sample apps. |
| **Help center** | [Help Center](https://help.cometchat.com/hc/en-us) | Find troubleshooting articles. |
| **Slack support** | Shared Slack channel | Chat with CometChat engineers (on plans that include it). |
| **Community** | [community.cometchat.com](https://community.cometchat.com/) | Ask other developers. |
| **Product updates** | [CometChat blog](https://www.cometchat.com/blog) | Read announcements. |
| **Product feedback** | [feedback.cometchat.com](https://feedback.cometchat.com/) | Request features and vote. |
| **Status page** | [status.cometchat.com](https://status.cometchat.com/) | Check service status and maintenance. |

The same links appear under **Quick Links** on [Overview](/dashboard/overview).
