**What's New** opens the [CometChat blog](https://www.cometchat.com/blog) in a new tab, where CometChat announces new features and releases.

**Where:** left navigation → **Account** → **Profile** → **What's New**.

For release notes of each SDK and UI Kit, see the changelog pages in their docs.
