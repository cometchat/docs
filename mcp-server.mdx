The **CometChat MCP server** lets Claude, Claude Code, Cursor, VS Code, Codex,
Windsurf, and any other Model Context Protocol–compatible agent integrate
CometChat into your app from natural-language prompts. Ask the agent to
*"add a chat tab where users can DM each other"* and it uses the MCP to read
CometChat's docs, pick the right components for your stack, and write the
integration code.

The server is **read-only** and **needs no account or API key** — it surfaces
CometChat's public documentation and curated implementation recipes.

## Connector URL

```
https://mcp.cometchat.com/mcp
```

Transport: Streamable HTTP. No authentication required. The server does not
offer the older SSE-only transport, so if your client asks for a transport
type, choose **HTTP** (Streamable HTTP).

## Connect from your agent

<Note>
If you installed [CometChat Agent Skills](/agent-skills), the installer already
connected this server to your agent as `cometchat-docs`. You don't need to add
it again — skip to [Example prompts](#example-prompts).
</Note>

### Claude (claude.ai and Claude Desktop)

CometChat is listed in Claude's connector directory.

1. Open [CometChat in the connector directory](https://claude.com/connectors/cometchat)
   and click **Add to Claude**. Or, in Claude, go to **Customize → Connectors**,
   click **+**, choose **Browse connectors**, find **CometChat**, and click
   **Connect**.
2. In a conversation, click **+** in the lower left, hover over **Connectors**,
   and turn on **CometChat**.

On Team and Enterprise plans, an Owner first adds the connector from
**Organization settings → Connectors → Browse connectors**.

**Fallback: add it as a custom connector.** If the directory isn't available
to you, go to **Customize → Connectors**, click **+**, choose
**Add custom connector**, paste `https://mcp.cometchat.com/mcp` as the remote
MCP server URL, and click **Add**. Free plans allow one custom connector. See
Anthropic's [custom connector guide](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp).

### Claude Code

Run:

```bash
claude mcp add --transport http cometchat-docs https://mcp.cometchat.com/mcp
```

The server is added for the current project. Add `--scope user` to make it
available in every project. Check the connection with `claude mcp list`, or
run `/mcp` inside Claude Code.

### Cursor

1. Use the [one-click install link](https://cursor.com/en/install-mcp?name=cometchat-docs&config=eyJ1cmwiOiJodHRwczovL21jcC5jb21ldGNoYXQuY29tL21jcCJ9),
   or add this to `~/.cursor/mcp.json` (every project) or `.cursor/mcp.json`
   (one project):

```json
{
  "mcpServers": {
    "cometchat-docs": {
      "url": "https://mcp.cometchat.com/mcp"
    }
  }
}
```

2. Turn the server on or off from **Customize** in the sidebar.

### Visual Studio Code (Copilot Agent)

1. Use the [one-click install link](https://insiders.vscode.dev/redirect/mcp/install?name=cometchat-docs&config=%7B%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Fmcp.cometchat.com%2Fmcp%22%7D)
   ([VS Code Insiders](https://insiders.vscode.dev/redirect/mcp/install?name=cometchat-docs&config=%7B%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Fmcp.cometchat.com%2Fmcp%22%7D&quality=insiders)),
   or search for `@mcp cometchat` in the Extensions view and click **Install**.
2. To add it by hand instead, run **MCP: Add Server** from the Command Palette
   (`Cmd+Shift+P` / `Ctrl+Shift+P`), choose **HTTP**, and enter
   `https://mcp.cometchat.com/mcp`. Or add this to `.vscode/mcp.json`:

```json
{
  "servers": {
    "cometchat-docs": {
      "type": "http",
      "url": "https://mcp.cometchat.com/mcp"
    }
  }
}
```

3. When VS Code asks, confirm that you trust the server.

### Codex

Run:

```bash
codex mcp add cometchat-docs --url https://mcp.cometchat.com/mcp
```

Or add this to `~/.codex/config.toml`:

```toml
[mcp_servers.cometchat-docs]
url = "https://mcp.cometchat.com/mcp"
```

The Codex CLI, the IDE extension, and the ChatGPT desktop app share this
configuration. Check the connection with `codex mcp list`, or run `/mcp` in
the Codex TUI.

### Windsurf (Devin Desktop)

Windsurf is now Devin Desktop.

1. Open your MCP config file. With the Cascade agent, click the `...` (Actions)
   menu at the top right of the Cascade panel, then **Open MCP config file**.
   With the Devin Local agent, edit the config file described in
   [Devin's MCP configuration docs](https://docs.devin.ai/cli/extensibility/mcp/configuration).
2. Add CometChat under `mcpServers`:

```json
{
  "mcpServers": {
    "cometchat-docs": {
      "url": "https://mcp.cometchat.com/mcp"
    }
  }
}
```

3. Save the file.

## Example prompts

Once connected, try these in a fresh agent conversation:

- *"Add a chat tab where users can DM each other in my React app."*
- *"Let project members talk in a group chat with file sharing."*
- *"Add video calling between two users with a click-to-call button."*
- *"Set up content moderation so banned words are blocked before delivery."*
- *"Build a multi-tenant SaaS chat where each workspace's users are isolated."*
- *"Add presence indicators and typing dots to my conversation list."*

The agent will search the docs, pull the matching implementation bundle,
and write the code into your project.

## What the connector exposes

### Four tools (all read-only)

<CardGroup cols={2}>
  <Card title="search_cometchat_docs" icon="magnifying-glass">
    Search SDK guides, UI Kit references, REST API docs, integration
    tutorials, and OpenAPI specs. Returns ranked snippets with titles and
    direct links. Pages for the current version of each SDK and UI Kit are
    preferred, and each result says whether it is current. Pass `version`
    (for example `v5`) to search older docs.
  </Card>
  <Card title="fetch_cometchat_doc_page" icon="file-lines">
    Fetch one documentation page as markdown, with its title and section,
    by full URL or relative path such as `/sdk/javascript/overview`. Moved
    pages are followed to their new location.
  </Card>
  <Card title="get_cometchat_implementation_bundle" icon="box-open">
    Return a curated implementation recipe by name — prerequisites, install
    commands, configuration, working code, and common pitfalls — with the
    date it was last verified.
  </Card>
  <Card title="list_cometchat_bundles" icon="list">
    List every available implementation bundle with its identifier, title,
    target framework, and last-verified date.
  </Card>
</CardGroup>

Every tool returns structured results that match a declared output schema.

### Ten curated implementation bundles

| Bundle | What it covers |
| --- | --- |
| `react-uikit-quickstart` | React UI Kit install, init, login, conversations list, chat window |
| `react-native-uikit-quickstart` | React Native UI Kit install, navigation, basic chat screen |
| `flutter-uikit-quickstart` | Flutter UI Kit install, init, login, basic chat |
| `ios-uikit-quickstart` | iOS UI Kit (SwiftUI) install, init, login, chat view |
| `android-uikit-quickstart` | Android UI Kit (Compose) install, init, login, chat screen |
| `js-sdk-messaging-basics` | Vanilla JS SDK install, send/receive text and media messages |
| `widget-embed` | No-code widget embed for an existing site |
| `moderation-setup` | AI moderation, profanity filter, image moderation, webhooks |
| `multi-tenant-chat` | Multi-tenant SaaS chat — auth, isolation, tenant-scoped users |
| `presence-and-typing` | Online presence, typing indicators, read receipts |

Each bundle is also available as an MCP resource at
`cometchat://bundles/<bundle-name>`.

### Orientation skill resource

The MCP also exposes a `cometchat://skills/overview` resource — a structured
markdown document the agent reads once to orient itself on CometChat's
products, decision tree, and common pitfalls.

## Source

The MCP server is open source (Apache-2.0) at
[`github.com/cometchat/docs-mcp`](https://github.com/cometchat/docs-mcp).

Search runs on an index built from the
[CometChat docs repository](https://github.com/cometchat/docs). The server
rebuilds the index when the docs change, so a new or edited page can take a
few minutes to show up in search results. `fetch_cometchat_doc_page` reads
pages directly from this site. The implementation bundles are curated
separately, and each one records the date it was last verified.
