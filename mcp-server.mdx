The **CometChat MCP server** lets Claude, Cursor, Windsurf, VS Code, and any
other Model Context Protocol–compatible agent integrate CometChat into your
app from natural-language prompts. Ask the agent to *"add a chat tab where
users can DM each other"* and it uses the MCP to read CometChat's docs,
pick the right components for your stack, and write the integration code.

One server has two kinds of tools:

- **Docs tools** search CometChat's documentation and return implementation
  bundles. They're read-only and need **no account, sign-in or API key**.
- **Account tools** work with your CometChat account: fetch an app's
  credentials, turn features on, create test users and groups, manage API keys
  and webhooks, check usage and more. The first time your agent uses one, your
  AI tool asks you to **sign in to CometChat** in the browser.

You can use the docs tools alone and never sign in. Without a sign-in, the
agent asks you to paste your App ID, Region and Auth Key from the
[dashboard](https://app.cometchat.com) when it needs them.

## Connector URL

```
https://mcp.cometchat.com/mcp
```

Transport: Streamable HTTP. The docs tools need no authentication. The account
tools use the MCP sign-in flow (OAuth): your AI tool opens a CometChat sign-in
page the first time you use one.

## Connect from your agent

### Claude (Desktop or claude.ai)

1. Open **Settings → Connectors**.
2. Click **Add custom connector**.
3. Name it `CometChat`, paste the URL `https://mcp.cometchat.com/mcp`, and click **Add**.
4. To use the account tools, click **Connect** on the connector and sign in to CometChat.
5. In a new conversation, attach **CometChat** from the connectors picker and prompt away.

### Claude Code

```bash
claude mcp add --transport http cometchat https://mcp.cometchat.com/mcp
```

The docs tools work right away. To sign in for the account tools, run `/mcp`,
pick `cometchat`, and choose **Authenticate**. Claude Code also tells you to do
this the first time the agent calls an account tool.

### Cursor

1. `Cmd+Shift+P` (macOS) / `Ctrl+Shift+P` (Windows) → **Open MCP settings**.
2. Click **Add custom MCP** and paste:

```json
{
  "mcpServers": {
    "cometchat": {
      "url": "https://mcp.cometchat.com/mcp"
    }
  }
}
```

3. The first time the agent uses an account tool, Cursor asks you to sign in to CometChat.

### Windsurf

1. Click the **Plugins** (hammer) icon → **Manage plugins** → **View raw config**.
2. Paste:

```json
{
  "mcpServers": {
    "cometchat": {
      "serverUrl": "https://mcp.cometchat.com/mcp"
    }
  }
}
```

3. Save and click **Refresh**.

### Visual Studio Code (Copilot Agent)

1. `Cmd+Shift+P` / `Ctrl+Shift+P` → **MCP: Add Server**.
2. Choose **HTTP**, enter the URL `https://mcp.cometchat.com/mcp`, and name it `cometchat`.

Or add it to `.vscode/mcp.json` in your project:

```json
{
  "servers": {
    "cometchat": {
      "type": "http",
      "url": "https://mcp.cometchat.com/mcp"
    }
  }
}
```

Any other MCP client that supports sign-in (OAuth) opens the CometChat sign-in
page the first time the agent uses an account tool.

### Lovable

Add it as a custom MCP chat connector with **No authentication**, which gives
Lovable the docs tools. See [Build CometChat Apps with Lovable](/lovable) for
the steps.

### With the CometChat Agent Skills

`npx @cometchat/skills add` installs the [Agent Skills](/agent-skills) and adds
this server to your agent's MCP config for you.

## Example prompts

Once connected, try these in a fresh agent conversation:

- *"Add a chat tab where users can DM each other in my React app."*
- *"Let project members talk in a group chat with file sharing."*
- *"Add video calling between two users with a click-to-call button."*
- *"Set up content moderation so banned words are blocked before delivery."*
- *"Build a multi-tenant SaaS chat where each workspace's users are isolated."*
- *"Add presence indicators and typing dots to my conversation list."*

With the account tools, after you sign in:

- *"Use my CometChat app 'Support Chat' and put its credentials in `.env`."*
- *"Turn on reactions and polls for my app."*
- *"Create five test users and a group with all of them in it."*
- *"How many monthly active users did my app have in the last 30 days?"*

## Signing in for the account tools

The first time your agent calls an account tool, your AI tool opens a
CometChat sign-in page in your browser. Sign in with your CometChat dashboard
account. The page lists what your AI tool will be able to do before you
continue.

- **Full or read-only access.** A known AI tool can read and, with your OK,
  change your account. Known tools are ones running on your machine, Claude's
  connector, ChatGPT, Grok, Antigravity, Mistral Le Chat and Perplexity. Any
  other app is marked **Unverified** and gets **read-only** access. Anyone can
  register an app under any name, so check the name and the address it returns
  to, and only sign in from a link your own AI tool opened.
- **ChatGPT shows as Unverified?** Remove the CometChat connector in ChatGPT
  and add it again.
- **A read-only connection** can't change your account. It can still read app
  credentials, including the Auth Key. Other API key values stay hidden.
- **Your sign-in stays in your AI tool.** The server stores nothing. Access
  tokens last one hour, and a sign-in lasts at most seven days.

If your AI tool doesn't support MCP sign-in, the docs tools keep working and
the agent asks you for your credentials instead.

## Confirmations and approvals

Account tools never change anything on their own. How much they ask first
depends on the change:

| Kind of call | What happens |
| --- | --- |
| **Reads** (list apps, read credentials, list users, check usage…) | Run straight away. |
| **New items** (create an app, users, a group, a role, a moderation list) | Run when the agent calls them. Agents following CometChat's guidance create an app only when you ask for one. |
| **Changes to existing data** (turn a feature on or off, update or deactivate users, change group members, turn a moderation rule on or off, revoke login tokens) | The tool returns a summary instead of acting. The agent shows it to you and only goes ahead after you say yes in the chat. |
| **High-risk changes** (create an API key, login token or webhook, change app settings, set the OpenAI key, invite a team member, and **every delete**) | The tool returns a link. Open it in the browser where you signed in, check the exact change, and approve it. You get a short code to give back to your agent. The code works once, for that exact change, for up to 10 minutes. |

The browser approval guards against text inside your app (a message, a user
name) talking your agent into a risky change. Only approve changes you asked
for.

<Warning>
If your AI tool can control your browser, it could press **Approve** itself, so
don't rely on the approval step in that setup.
</Warning>

The account tools **can't** delete apps, change billing, transfer ownership or
ban users.

## Tools

### Docs tools (no sign-in)

| Tool | What it does |
| --- | --- |
| `search_cometchat_docs` | Searches the SDK, UI Kit, Calls, REST API, AI agent, notification and moderation docs. Returns ranked snippets with page links, current versions first |
| `fetch_cometchat_doc_page` | Fetches one documentation page in full as markdown by URL or path, following moved pages |
| `list_cometchat_bundles` | Lists every implementation bundle with its identifier, title and target framework, so the agent can pick the right one |
| `get_cometchat_implementation_bundle` | Returns a scenario's current docs pages (for a UI Kit: its integration guide, then the platform's AI reference page) compiled into one document |

### Account tools (sign-in)

In the **Asks first** column, *chat* means the agent needs your OK in the chat,
and *browser* means you approve the change in your browser.

| --- | --- | --- |

### Orientation skill resource

The MCP also exposes a `cometchat://skills/overview` resource — a structured

## Disconnecting

Remove the CometChat connection in your AI tool to stop it using your account
(Claude Code: `/mcp`, pick `cometchat`, **Clear authentication**). A sign-in
copied off your device keeps working until it expires; changing your CometChat
password cuts off every copy within an hour. Step-by-step help:
[mcp.cometchat.com/oauth/cometchat/disconnect](https://mcp.cometchat.com/oauth/cometchat/disconnect).

## Privacy

- **Docs tools** serve CometChat's public documentation. They don't request,
  store or send your code, prompts or personal data.
- **Account tools** pass your requests to your CometChat account and return the
  results to your AI tool. Results can include your users' names, emails and
  message text. The server stores nothing; for security it logs one audit line
  per account action (a pseudonymous id for you, the tool, the app and the ids
  it acted on, never message text, names or secrets).
