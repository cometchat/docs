---
title: "Template Metrics"
description: "Delivery and engagement drilldown for a specific template."
---

Returns delivery and engagement metrics across all sends that used a specific template.

### Endpoint

```
GET /analytics/templates/{templateId}
```

### Path parameters

| Parameter    | Type   | Required | Description                         |
| ------------ | ------ | -------- | ----------------------------------- |
| `templateId` | string | Yes      | Template CUID or `templateId` slug. |

For the complete error reference, see [Error Guide](/articles/error-guide).
