---
title: "Campaign Metrics"
description: "Delivery and engagement drilldown for a specific campaign."
---

Returns delivery and engagement metrics scoped to a single campaign.

### Endpoint

```
GET /analytics/campaigns/{campaignId}
```

### Path parameters

| Parameter    | Type   | Required | Description          |
| ------------ | ------ | -------- | -------------------- |
| `campaignId` | string | Yes      | The campaign's CUID. |

For the complete error reference, see [Error Guide](/articles/error-guide).
