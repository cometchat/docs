Usage is tracked per **monthly billing cycle**. To see where your app stands against its plan, use the CometChat Dashboard. Use this endpoint when you need usage data programmatically, for example in automated reports or alerts.

## Check Usage in the Dashboard

Open your app in the [CometChat Dashboard](https://app.cometchat.com) and go to its **Overview** page. It shows the current billing cycle's MAUs (monthly active users) and PCC (peak concurrent connections) against your plan limits.

For a [multi-tenant](/fundamentals/multi-tenancy) account, open the Parent App's **Overview** page and click **Request complete billing report** to get usage across all apps. To get the same data programmatically, use the [Fetch Usage](/rest-api/management-apis/app/fetch-usage) Management API.

For the complete error reference, see [Error Guide](/articles/error-guide).
