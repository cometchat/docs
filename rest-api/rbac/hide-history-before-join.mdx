title: "Hide Group Messages Sent Before a Member Joined"
sidebarTitle: "Hide History Before Join"

---

To stop newly added members from seeing a group's earlier messages, use the SBAC **Message History** permission `listMessages.historyBeforeJoin`. It is set per member scope (`admin`, `moderator`, `participant`) on a group, takes `allow` or `deny`, and defaults to `allow`. When it is `deny` for a scope, members with that scope cannot list messages sent before they joined the group.

## Hide pre-join history for a scope

<Steps>
  <Step title="Set the permission">
    Call [Set Scope Permissions](/rest-api/rbac/set-scope-permissions) for the group and scope. The request body is a `permissions` object keyed by permission key.

    ```bash
    curl -X PUT "https://<appId>.api-<region>.cometchat.io/v3/groups/cometchat-guid-1/scopes/participant/permissions" \
      -H "apikey: YOUR_REST_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"permissions": {"listMessages.historyBeforeJoin": "deny"}}'
    ```
  </Step>
  <Step title="Check the current value">
    Call [List Scope Permissions](/rest-api/rbac/list-scope-permissions) for the same group and scope to confirm `listMessages.historyBeforeJoin` is `deny`.
  </Step>
</Steps>

## Values

- `deny`: members with this scope cannot list messages sent before they joined the group.
- `allow` (default): members with this scope can list the full group history. Set it with the same request, or call [Unset Scope Permissions](/rest-api/rbac/unset-scope-permissions) to return to the default.

The permission applies per scope, not per member or per date. To apply it to every member of a group, set it for each scope.
