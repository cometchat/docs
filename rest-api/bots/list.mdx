---
openapi: get /bots
description: "Retrieve a paginated list of the bots in a CometChat app using the REST API, with search and AI bot filtering."
---

`searchKey` matches the start of a bot's UID, not its name. Results are ordered by UID.

`perPage` defaults to 100 and is capped at 1000. Page through the results rather than assuming one response holds every bot.

### Listing AI bots

`isAIBot` defaults to `false`, so this endpoint returns standard bots only. Pass `isAIBot=true` to list bots flagged as AI bots instead — there is no call that returns both at once.

Agents created through [AI Agents](/ai-agents) are not returned either way.

A `GET /bots?isAIBot=true` response looks like this:

```json
{
  "data": [
    {
      "uid": "faq-bot",
      "webhookURL": "https://example.com/webhooks/faq-bot",
      "groupChatSetting": "mentionedMessages",
      "enabled": true,
      "isAIBot": true,
      "createdAt": 1763472000
    }
  ],
  "meta": {
    "pagination": {
      "total": 1,
      "count": 1,
      "per_page": 100,
      "current_page": 1,
      "total_pages": 1
    }
  }
}
```

`isAIBot` appears only when it is `true`, because responses omit every property whose value is empty or `false`. That is also why `order-bot` in the response example has no `useBasicAuth`, `username` or `password`.

<Warning>
Every bot with a stored `password` returns it in this response, including bots whose `useBasicAuth` was later set to `false`. A single call can therefore expose the basic auth credentials of every bot in the app. The examples mask the value as `********`.
</Warning>
