---
openapi: delete /bots/{uid}
description: "Delete a CometChat bot by UID with the REST API and confirm the removal from the response."
---

Deleting a bot removes the bot and its webhook configuration. **The underlying user is not deleted** — the UID stays in your app as an ordinary [User](/rest-api/users), and its messages remain. To remove the user as well, call the [Delete User API](/rest-api/users/delete) afterwards.

A later [Get Bot](/rest-api/bots/get) call for the same UID returns `ERR_BOT_NOT_FOUND`.

To stop a bot temporarily without deleting it, set `enabled` to `false` with the [Update Bot API](/rest-api/bots/update).

For the complete error reference, see [Error Guide](/articles/error-guide).
