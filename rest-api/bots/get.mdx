---
openapi: get /bots/{uid}
description: "Retrieve the details of a single CometChat bot by UID using the REST API."
---

Returns `ERR_BOT_NOT_FOUND` when no bot exists with this UID. That includes a UID that belongs to a user who is not a bot, and an agent created through [AI Agents](/ai-agents).

Responses omit every property whose value is empty or `false`, so a standard bot has no `isAIBot`, and a bot that has never had basic auth has no `useBasicAuth`, `username` or `password`. A bot whose `useBasicAuth` was set to `false` after it was saved still returns its stored `username` and `password`.

For a bot flagged as an AI bot, the response includes the flag:

```json
{
  "data": {
    "uid": "faq-bot",
    "webhookURL": "https://example.com/webhooks/faq-bot",
    "groupChatSetting": "mentionedMessages",
    "enabled": true,
    "isAIBot": true,
    "createdAt": 1763472000
  }
}
```

<Warning>
The API returns the stored `password` value as it was saved, including after `useBasicAuth` is set to `false`. The example masks it as `********`.
</Warning>

For the complete error reference, see [Error Guide](/articles/error-guide).
