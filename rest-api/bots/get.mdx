---
openapi: get /bots/{uid}
description: "Retrieve the details of a single CometChat bot by UID using the REST API."
---

Returns `ERR_BOT_NOT_FOUND` when no bot exists with this UID, including when the UID belongs to a user who is not a bot.

Responses omit every property whose value is empty or `false`, so a bot with basic auth turned off has no `useBasicAuth`, `username` or `password`, and a standard bot has no `isAIBot`.

For an AI bot, the response includes the flag:

```json
{
  "data": {
    "uid": "research-agent",
    "webhookURL": "https://example.com/webhooks/research-agent",
    "groupChatSetting": "mentionedMessages",
    "enabled": true,
    "isAIBot": true,
    "createdAt": 1763472000
  }
}
```

<Warning>
When `useBasicAuth` is `true`, the API returns the stored `password` value as it was saved. The example masks it as `********`.
</Warning>

For the complete error reference, see [Error Guide](/articles/error-guide).
