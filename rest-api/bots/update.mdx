---
openapi: put /bots/{uid}
description: "Update a CometChat bot's webhook, group chat setting, basic auth credentials or enabled state with the REST API."
---

Every field is optional — send only the ones you want to change. The bot's `uid` cannot be changed; delete the bot and create a new one instead.

`groupChatSetting` accepts the same four values as the [Create Bot API](/rest-api/bots/create): `allMessages`, `slashedMessages`, `mentionedMessages` and `none`.

Unlike the Create Bot API, Update stores `username` and `password` as sent, whatever `useBasicAuth` is set to. Setting `useBasicAuth` to `false` stops credentials being sent with webhook calls, but does not clear the stored `username` and `password`. They stay in responses.

Setting `enabled` to `false` stops the bot relaying messages without deleting it.

A bot's name and avatar belong to its user — change them with the [Update User API](/rest-api/users/update).

`updatedAt` appears in the response once a bot has been updated.

<Warning>
The API returns the stored `password` value as it was saved, including after `useBasicAuth` is set to `false`. The example masks it as `********`.
</Warning>

For the complete error reference, see [Error Guide](/articles/error-guide).
