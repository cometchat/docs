---
openapi: post /groups
description: "Create a group and check its limits, such as fewer than 300 members with every feature, or up to 100,000 once receipts and typing indicators switch off."
---

## Constraints

| Item                                         | Constraint                        | Notes                                                                                                                                 |
| -------------------------------------------- | --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| GUID character limit                         | 100 characters                    | Alphanumeric with dashes only; spaces not allowed                                                                                     |
| Group name                                   | 100 characters (UTF8mb4)          | Supports all languages and emojis                                                                                                     |
| Maximum users in a group (with all features) | Fewer than 300                    | Groups with fewer than 300 members support all features including delivery/read receipts, typing indicators and unread message counts |
| Maximum users in a group (without receipts)  | 100,000 (up to 10,000 concurrent) | Large groups disable delivery/read receipts and typing indicators for performance                                                     |
| Group password                               | 100 characters max                | Only applicable for password-protected groups                                                                                         |
| Group description                            | 255 characters (UTF8mb4)          | Brief summary of the group's purpose                                                                                                  |
| Maximum groups                               | No limit                          | Create as many groups as needed; billing based on active users                                                                        |
| Typing indicators for groups                 | Fewer than 300 members            | Counts all members, online or not. Disabled for larger groups to optimize performance                                                 |
| Unread message counts for groups             | Fewer than 300 members            | Not updated for groups with 300 or more members                                                                                       |
| Delivery and read receipts for groups        | Fewer than 300 members            | Counts all members, online or not. Not sent in real time in larger groups to reduce server load                                       |
| Active presence subscriptions                | Up to 1,000 active connections    | All-user and role-based presence is not sent beyond this limit. Friends presence is not limited                                       |

For the complete error reference, see [Error Guide](/articles/error-guide).
