---
openapi: post /groups
description: "Create a group and check its limits, such as 300 members with every feature, or up to 100,000 once receipts and typing indicators switch off."
---

## Constraints

| Item                                         | Constraint                     | Notes                                                                                                         |
| -------------------------------------------- | ------------------------------ | ------------------------------------------------------------------------------------------------------------- |
| GUID character limit                         | 100 characters                 | Alphanumeric with dashes only; spaces not allowed                                                             |
| Group name                                   | 100 characters (UTF8mb4)       | Supports all languages and emojis                                                                             |
| Maximum users in a group (with all features) | 300                            | Delivery/read receipts, typing indicators and unread message counts turn off once a group reaches 300 members |
| Maximum users in a group (without receipts)  | 100,000                        | Large groups disable delivery/read receipts and typing indicators for performance                             |
| Group password                               | 100 characters max             | Only applicable for password-protected groups                                                                 |
| Group description                            | 255 characters (UTF8mb4)       | Brief summary of the group's purpose                                                                          |
| Maximum groups                               | No limit                       | Create as many groups as needed; billing based on active users                                                |
| Typing indicators for groups                 | 300 members                    | Turn off at 300 members to optimize performance                                                               |
| Unread message counts for groups             | 300 members                    | Not updated once a group reaches 300 members                                                                  |
| Delivery and read receipts for groups        | 300 members                    | Not sent in real time once a group reaches 300 members                                                        |
| Active presence subscriptions                | Up to 1,000 active connections | All-user and role-based presence is not sent beyond this limit. Friends presence is not limited               |

For the complete error reference, see [Error Guide](/articles/error-guide).
