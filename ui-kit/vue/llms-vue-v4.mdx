# Vue UI Kit v4 — LLM docs index

> A **Vue UI Kit-scoped**, current-version routing index for AI coding agents — a smaller alternative to
> the site-wide `/docs/llms.txt`. Full directory: [/docs/llms-index](/llms-index).

## How to use this index
Each link points to a docs page; **append `.md`** to its URL for the clean Markdown twin. Convention:
any docs page URL + `.md` → raw Markdown. Fallback: if a `.md` twin 404s, fetch the same URL without
`.md` (HTML). Never answer props/APIs from memory.
