<Warning>
**Deprecated.** Incoming calls now ring through the CometChat Push Notifications SDK, which draws its own incoming-call screen in every app state, including when the app is not running. `CometChatIncomingCall` is kept only for apps that opt into drawing the ring screen themselves with `PNConfiguration.setIncomingCallActivity`. New integrations need no incoming-call component: see [Calling Integration](/ui-kit/android/calling-integration).
</Warning>

`CometChatIncomingCall` shows the caller's avatar, name and call type with accept and decline controls. It is a view only: it does not ring, and the UI Kit has no dependency on the Push SDK. If you use it as your ring screen, your activity connects its Accept and Decline to the Push SDK.

## When to use it

| You want | Do this |
| --- | --- |
| The default incoming-call screen | Nothing. The Push SDK's screen is themed by the `cometchat_pn_call_*` colour resources; the UI Kit already matches them to its palette. See [Styling the incoming-call screen](/ui-kit/android/calling-integration#styling-the-incoming-call-screen) |
| This component as the ring screen | Host it in your own activity registered with `PNConfiguration.setIncomingCallActivity` (below) |
| A fully custom ring screen | Your own activity with the Push SDK's `CometChatCallNotifications` API; see [Your own incoming-call screen](/calls/android/voip-calling#your-own-incoming-call-screen) |

## Quick Start: the component as the ring screen

Register your ring activity alongside your [answer activity](/ui-kit/android/calling-integration#step-3-configure-push-ringing):

```kotlin lines
PNConfiguration.Builder(APP_ID, REGION)
    .setProviderId(PROVIDER_ID)
    .setAnswerActivity(CallAnswerActivity::class.java)
    .setIncomingCallActivity(RingActivity::class.java)
    .build()
```

The activity reads the ringing call from its intent, tells the Push SDK when it opens and closes (so the SDK can close it when the caller cancels or the ring times out), and sends Accept and Decline to the Push SDK. On Accept the Push SDK opens your answer activity.

```kotlin lines
class RingActivity : AppCompatActivity() {
    private var sessionId: String? = null

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setShowWhenLocked(true); setTurnScreenOn(true)
        setContentView(R.layout.activity_ring)

        val incoming = CallBundles.getCall(intent) ?: return finish()
        sessionId = incoming.sessionId
        CometChatCallNotifications.onIncomingCallScreenOpened(incoming.sessionId) { finish() }

        val call = CallRingingUtils.buildIncomingCall(
            sessionId = incoming.sessionId,
            callType = if (incoming.isVideo) CometChatConstants.CALL_TYPE_VIDEO else CometChatConstants.CALL_TYPE_AUDIO,
            receiverType = incoming.receiverType,
            receiverUid = incoming.receiverUid,
            callerUid = incoming.callerUid,
            callerName = incoming.callerName,
            callerAvatarUrl = incoming.callerAvatarUrl,
            initiatedAtMs = incoming.initiatedAtMs,
            conversationId = incoming.conversationId
        )
        findViewById<CometChatIncomingCall>(R.id.incoming_call).apply {
            setCall(call)
            setOnAcceptClickListener {
                // Ask for RECORD_AUDIO (+ CAMERA for video) first: answer() skips the SDK prompt.
                CometChatCallNotifications.answer(this@RingActivity, incoming.sessionId)
            }
            setOnRejectClickListener {
                CometChatCallNotifications.decline(this@RingActivity, incoming.sessionId)
                finish()
            }
        }
    }

    override fun onDestroy() {
        sessionId?.let { CometChatCallNotifications.onIncomingCallScreenClosed(it) }
        super.onDestroy()
    }
}
```

In Compose, pass the same calls as `onAcceptClick` and `onRejectClick` to `CometChatIncomingCall(call = call, ...)` inside `setContent`.

Prerequisites: `CometChatUIKit.init()` with `setEnableCalling(true)`, the Push SDK initialised with an answer activity, and a user logged in.

## Actions and Events

### Callback Methods

#### `onAcceptClick`

Fires when the user taps Accept. By default the component opens `CometChatOngoingCallActivity` itself. On a Push SDK ring screen, set it to call `CometChatCallNotifications.answer(context, sessionId)` instead, so the Push SDK stops the ring and opens your answer activity. Ask for the microphone (and camera) before answering: the Push SDK only prompts for its notification's Answer action.

<Tabs>
<Tab title="Kotlin (XML Views)">

```kotlin lines
incomingCall.setOnAcceptClickListener {
    // Custom accept logic
}
```

</Tab>
<Tab title="Jetpack Compose">

```kotlin lines
CometChatIncomingCall(
    call = call,
    onAcceptClick = { /* custom accept logic */ },
    // Runs before the default answer; call proceed() once permissions are granted
    onAcceptRequested = { proceed -> requestMicAndCamera { proceed() } }
)
```

</Tab>
</Tabs>

#### `onRejectClick`

Fires when the user taps Decline. By default the component declines through the Calls SDK as `rejected`. On a Push SDK ring screen, set it to call `CometChatCallNotifications.decline(context, sessionId)` instead, so the Push SDK stops the ring and sends `rejected` or `busy`.

<Tabs>
<Tab title="Kotlin (XML Views)">

```kotlin lines
incomingCall.setOnRejectClickListener {
    // Custom reject logic
    finish()
}
```

</Tab>
<Tab title="Jetpack Compose">

```kotlin lines
CometChatIncomingCall(
    call = call,
    onRejectClick = { /* custom reject logic */ }
)
```

</Tab>
</Tabs>

#### `onError`

Fires on internal errors (network failure, call failure, SDK exception).

<Tabs>
<Tab title="Kotlin (XML Views)">

```kotlin lines
incomingCall.setOnError { exception ->
    Log.e("IncomingCall", "Error: ${exception.message}")
}
```

</Tab>
<Tab title="Jetpack Compose">

```kotlin lines
CometChatIncomingCall(
    call = call,
    onError = { exception ->
        Log.e("IncomingCall", "Error: ${exception.message}")
    }
)
```

</Tab>
</Tabs>

### Global UI Events (`CometChatEvents.callEvents`)

| Event | Fires when | Payload |
| --- | --- | --- |
| `CometChatCallEvent.CallAccepted` | Accept tapped on this screen | `Call` |
| `CometChatCallEvent.CallRejected` | Decline tapped on this screen | `Call` |

### SDK Events (Real-Time, Automatic)

| Calls SDK listener | Internal behavior |
| --- | --- |
| `IncomingCallListener.onIncomingCallEnded` for this session | The ring ended elsewhere (caller cancelled, answered on another device, timed out): `rejectedCall` is emitted so the screen closes |

The component does not open itself on an incoming call. The Push SDK launches the activity registered with `setIncomingCallActivity`; the Chat SDK's `CallListener` is superseded and not used.

## Functionality

| Method (Kotlin XML) | Compose Parameter | Description |
| --- | --- | --- |
| `setCall(call)` | `call = call` | Set the Call object (required) |
| `setOnAcceptClickListener { }` | `onAcceptClick = { }` | Override accept button behavior |
| `setOnRejectClickListener { }` | `onRejectClick = { }` | Override reject button behavior |
| `setOnError { }` | `onError = { }` | Error callback |
| — | `onAcceptRequested = { proceed -> }` | Compose only: gate the answer (e.g. a permission prompt), then call `proceed()` |
| `setDisableSoundForCalls(true)` | `disableSoundForCalls = true` | No effect when the Push SDK is present: the Push SDK plays the ringtone and the component stays silent to avoid two ringtones |
| `setCustomSoundForCalls(R.raw.tone)` | `customSoundForCalls = R.raw.tone` | Only used without the Push SDK calls module |

Replace the avatar / left section.

  <img src="/images/d6565a37-incoming_call_leading_view-1a7b3012972e5f6e17f433a02a49d8c5.png" />

<Tabs>
<Tab title="Kotlin (XML Views)">

```kotlin lines
val leadingView = LayoutInflater.from(this).inflate(R.layout.leading_view, null)
val avatar = leadingView.findViewById<CometChatAvatar>(R.id.avatar)
val callUser = call.callInitiator as User
avatar.setAvatar(callUser.name, callUser.avatar)
leadingView.layoutParams = LinearLayout.LayoutParams(
    Utils.convertDpToPx(this, 45),
    Utils.convertDpToPx(this, 45)
)
incomingCall.setLeadingView(leadingView)
```

</Tab>
<Tab title="Jetpack Compose">

```kotlin lines
CometChatIncomingCall(
    call = call,
    leadingView = { c ->
        val caller = c.callInitiator as? User
        CometChatAvatar(
            imageUrl = caller?.avatar,
            name = caller?.name
        )
    }
)
```

</Tab>

## Style

<Tabs>
<Tab title="Kotlin (XML Views)">

Define a custom style in `themes.xml`:

```xml themes.xml lines
<style name="CustomIncomingCallStyle" parent="CometChatIncomingCallStyle">
    <item name="cometchatIncomingCallBackgroundColor">#AA9EE8</item>
    <item name="cometchatIncomingCallIconTint">?attr/cometchatPrimaryColor</item>
    <item name="cometchatIncomingCallRejectButtonBackgroundColor">?attr/cometchatColorWhite</item>
    <item name="cometchatIncomingCallAcceptButtonBackgroundColor">?attr/cometchatPrimaryColor</item>
    <item name="cometchatIncomingCallRejectButtonTextColor">?attr/cometchatErrorColor</item>
    <item name="cometchatIncomingCallAcceptButtonTextColor">?attr/cometchatColorWhite</item>
</style>
```

```kotlin lines
incomingCall.setStyle(R.style.CustomIncomingCallStyle)
```

</Tab>
<Tab title="Jetpack Compose">

```kotlin lines
CometChatIncomingCall(
    call = call,
    style = CometChatIncomingCallStyle.default().copy(
        backgroundColor = Color(0xFFAA9EE8),
        acceptButtonBackgroundColor = CometChatTheme.colors.primary,
        rejectButtonBackgroundColor = Color.White,
        rejectButtonTextColor = CometChatTheme.colors.error,
        acceptButtonTextColor = Color.White

)
```
