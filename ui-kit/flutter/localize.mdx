## Overview

CometChat V6 UI Kit provides language localization to adapt to the language of a specific country or region. The `CometChatLocalize` class allows you to detect the language of your users based on their device settings and set the language accordingly.

The UI Kit supports 19 languages:

* Arabic (ar), German (de), English (en, en-GB), Spanish (es), French (fr), Hindi (hi), Hungarian (hu), Japanese (ja), Korean (ko), Lithuanian (lt), Malay (ms), Dutch (nl), Portuguese (pt), Russian (ru), Swedish (sv), Turkish (tr), Chinese (zh, zh-TW)

## Usage

### Integration

Add the following dependency in `pubspec.yaml`:

<Tabs>
<Tab title="Dart">
```yaml
flutter_localizations:
  sdk: flutter
```
</Tab>
</Tabs>

***

Update MaterialApp Localizations Delegates:

<Tabs>
<Tab title="Dart">
```dart
import 'package:cometchat_chat_uikit/cometchat_chat_uikit.dart' as cc;
import 'package:flutter/material.dart';

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      supportedLocales: cc.CometChatLocalize.supportedLocales,
      localizationsDelegates: cc.CometChatLocalize.localizationsDelegates,
      theme: ThemeData(
        appBarTheme: AppBarTheme(scrolledUnderElevation: 0.0),
      ),
      title: 'CometChat Flutter App',
      home: YourHomeScreen(),
      debugShowCheckedModeBanner: false,
    );
  }
}
```
</Tab>
</Tabs>

***

You can also translate specific strings:

<Tabs>
<Tab title="Dart">
```dart
String translatedString = cc.CometChatLocalize.of(context).users;
Text(translatedString);
```
</Tab>
</Tabs>

`cc.CometChatLocalize.localizationsDelegates` holds the UI Kit's delegate together with the Material, Cupertino and widgets delegates. If you list delegates yourself, add `cc.CometChatLocalize.delegate`.

<Note>
`CometChatLocalize` and `CometChatLocalizations` (available since v6.3.0) replace `Translations`, which is deprecated but keeps working for the rest of the v6 line. `CometChatLocalizations` is the same type as `Translations`, so the two can be mixed while you migrate.
</Note>

### Customizing UI Kit Translations for a Specific Language

Override strings of a language the UI Kit ships by extending its built-in class and registering it before the app builds:

<Tabs>
<Tab title="Dart">
```dart
import 'package:cometchat_chat_uikit/cometchat_chat_uikit.dart' as cc;

class CustomEN extends cc.TranslationsEn {
  @override
  String get chats => "Overridden Chat";

  @override
  String get calls => "Overridden Call";
}

void main() {
  cc.CometChatLocalize.registerTranslations(CustomEN());
  runApp(const MyApp());
}
```
</Tab>
</Tabs>

The registered strings are served by `cc.CometChatLocalize.delegate`, so keep it in your `localizationsDelegates`. A translation registered for `en` is also used for regional locales such as `en_US`.

### Adding New Language Support

Extend the UI Kit with a new language by creating a custom translation class:

<Tabs>
<Tab title="Dart">
```dart
class TeluguLocalization extends cc.CometChatLocalizations {
  TeluguLocalization([super.locale = "te"]);
  static const delegate = _TeluguLocalizationsDelegate();

  @override
  String get chats => "సందేశాలు";

  @override
  String get calls => "ఫోన్ కాల్స్";
  // Override all relevant strings for full localization
}

class _TeluguLocalizationsDelegate
    extends LocalizationsDelegate<cc.CometChatLocalizations> {
  const _TeluguLocalizationsDelegate();

  @override
  bool isSupported(Locale locale) => locale.languageCode == 'te';

  @override
  Future<cc.CometChatLocalizations> load(Locale locale) =>
      SynchronousFuture(TeluguLocalization());

  @override
  bool shouldReload(_TeluguLocalizationsDelegate old) => false;
}
```
</Tab>
</Tabs>

Then add the delegate and the locale to your `MaterialApp`:

```dart
localizationsDelegates: [
  TeluguLocalization.delegate,
  ...cc.CometChatLocalize.localizationsDelegates,
],
supportedLocales: [
  ...cc.CometChatLocalize.supportedLocales,
  const Locale('te'),
],
```

### Offline Strings

UI Kit 6.4.0 adds 22 strings for [offline support](/ui-kit/flutter/offline-support#offline-states-and-texts), translated in every built-in language. They appear only while offline support is running. Override them like any other getter. `messagesNotSent(int n)` and `unsentMessagesLost(int n)` take the count and return the singular or plural text.

| Getter | English text |
| --- | --- |
| `messageNotSentYet` | Not sent yet |
| `messageNotSentTapToRetry` | Not sent. Tap to retry |
| `unsentMessageRemoved` | Unsent message removed |
| `messagesNotSent(int n)` | 1 message wasn't sent / \{n\} messages weren't sent |
| `unsentMessagesLost(int n)` | 1 unsent message couldn't be recovered / \{n\} unsent messages couldn't be recovered |
| `unsentMessagesMaybeLost` | Some unsent messages may not have been sent |
| `queueFull` | Too many messages waiting to send |
| `fileTooLargeOffline` | File too large to send offline |
| `connectToLoadMore` | Connect to load more |
| `connectToSearch` | Connect to search |
| `connectToSearchSubtitle` | Search needs an internet connection. |
| `connectToLoadUsers` | Connect to load users |
| `connectToLoadGroups` | Connect to load groups |
| `connectToLoadMembers` | Connect to load members |
| `connectToLoadChats` | Connect to load chats |
| `connectToLoadMessages` | Connect to load messages |
| `connectToLoadReactions` | Connect to load reactions |
| `connectToLoadNotifications` | Connect to load notifications |
| `mediaAvailableWhenOnline` | Available when online |
| `jumpToLatest` | Jump to latest |
| `sendingTryAgain` | Sending… try again in a moment |
| `fileNotSaved` | File not saved. Add it again |

<Warning>
An app whose class `implements Translations` (or `CometChatLocalizations`) must add all 22 getters to compile with 6.4.0. A class that `extends` a translations class inherits the new strings and needs no change.
</Warning>

### DateTimeFormatter

By providing a custom `DateTimeFormatterCallback`, you can globally configure how time and date values are displayed across all UI components. For details, refer to the [CometChatUIKit class](/ui-kit/flutter/methods#dateformatter).
