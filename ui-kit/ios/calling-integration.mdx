## Overview

This guide walks you through adding voice and video calling capabilities to your iOS application using the CometChat UI Kit.

<Info>
Make sure you've completed the [Getting Started](/ui-kit/ios/getting-started) guide before proceeding.
</Info>

## Add the Calls SDK

Add the Calls SDK with Swift Package Manager:

1. Go to **File → Add Package Dependencies** in Xcode
2. Enter the CometChat Calls SDK repository URL:

```
https://github.com/cometchat/calls-sdk-ios
```

3. Select **Up to Next Major Version**, enter `5.0.4`, and add the **CometChatCallsSDK** product to your app target.

<Note>
- Your app target needs iOS 15.1 or later, the UI Kit's minimum deployment target.
- Keep the UI Kit on **Up to Next Major Version** from `5.2.3`, as set up in [Getting Started](/ui-kit/ios/getting-started).
</Note>

<Warning>
**CocoaPods:** the latest UI Kit on CocoaPods is 5.1.18, and new releases ship through Swift Package Manager only. Move CocoaPods projects to Swift Package Manager to get current releases and fixes.
</Warning>

<Info>
Make sure you have completed the Chat UI Kit integration before adding the Calls SDK.
</Info>

## Verify Integration

After adding the dependency, the iOS UI Kit will automatically detect it and activate calling features. You will see [CallButtons](/ui-kit/ios/call-buttons) rendered in the [MessageHeader](/ui-kit/ios/message-header) component.
