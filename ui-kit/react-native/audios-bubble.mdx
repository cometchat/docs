## Overview

`CometChatAudiosBubble` renders a message's audio **file** attachments as stacked playback cards. It is **self-extracting**: pass the SDK `message` and the bubble derives the audio attachments and caption itself.

<Note>
**Audio files vs voice notes.** Audio messages are routed by the `audioType` metadata key, set automatically by the composer:
- **Recorded voice notes** (`audioType: "voice_note"`) → [Voice Note Bubble](/ui-kit/react-native/voice-note-bubble) (waveform player)
- **Attached audio files** (no `audioType`) → **this bubble** (file-style playback cards)
- Classic single-audio messages continue to render the existing Audio Bubble

The routing is automatic — you don't configure it.
</Note>

Key capabilities:

- **Stacked audio cards** — one card per attachment with filename, play/pause, a draggable seek bar, and elapsed/total time
- **Inline playback** — plays directly in the bubble; starting one card pauses any other audio that's playing
- **Download** — download each audio file from its card
- **Show more / Show less** — messages with more than **3** audio attachments collapse behind a "Show *N* more" toggle
- **Caption support** — an optional caption renders below the cards with rich-text formatting, editable after sending
- **Theming** — styled through `theme.audiosBubbleStyles`, overridable per instance

## Usage

The bubble renders automatically inside [`CometChatMessageList`](/ui-kit/react-native/message-list) for multi-attachment audio messages. To use it standalone:

```tsx
import { CometChat } from "@cometchat/chat-sdk-react-native";
import { CometChatAudiosBubble, useTheme } from "@cometchat/chat-uikit-react-native";

function AudioFilesMessage({ message }: { message: CometChat.MediaMessage }) {
  const theme = useTheme();
  return <CometChatAudiosBubble message={message} theme={theme} />;
}
```

## Audio Card Anatomy

| Element | Description |
| --- | --- |
| Play/Pause button | Toggles playback for that audio file |
| Filename | Display name of the audio file |
| Seek bar | Draggable progress bar — drag the thumb to scrub |
| Time display | Elapsed / total duration |
| Download button | Downloads the audio file |

When a message has multiple audio attachments, cards stack vertically. Past **3** attachments the rest collapse behind a **Show *N* more** toggle ("Show less" collapses them again).

## Props

### message

The audio message. The bubble extracts its attachments and caption from it. **Required.**

| | |
| --- | --- |
| Type | `CometChat.MediaMessage` |
| Required | Yes |

---

### theme

The active UI Kit theme. Pass the value from `useTheme()`. **Required.**

| | |
| --- | --- |
| Type | `CometChatTheme` |
| Required | Yes |

---

### style

Per-instance style overrides. Deep-merged over `theme.audiosBubbleStyles`, so you only supply the keys you want to change.

| | |
| --- | --- |
| Type | `CometChatTheme["audiosBubbleStyles"]` |
| Default | `undefined` |

---

## Styling

Style the bubble globally through the theme (`audiosBubbleStyles`), or per instance through the `style` prop. Available keys:

| Key | Type | Styles |
| --- | --- | --- |
| `containerStyle` | `ViewStyle` | The bubble container |
| `cardStyle` | `ViewStyle` | Each audio card |
| `playButtonStyle` | `ViewStyle` | Play/pause button |
| `playIconStyle` | `ImageStyle` | Play/pause icon |
| `fileNameStyle` | `TextStyle` | Filename text |
| `seekTrackStyle` | `ViewStyle` | Seek bar track |
| `seekProgressStyle` | `ViewStyle` | Seek bar filled portion |
| `seekThumbStyle` | `ViewStyle` | Seek bar thumb |
| `timeTextStyle` | `TextStyle` | Elapsed/total time text |
| `downloadIconStyle` | `ImageStyle` | Download icon |
| `captionStyle` | `TextStyle` | Caption text below the cards |

```tsx
import { CometChatThemeProvider } from "@cometchat/chat-uikit-react-native";

<CometChatThemeProvider
  theme={{
    light: {
      audiosBubbleStyles: {
        seekProgressStyle: { backgroundColor: "#6852D6" },
        fileNameStyle: { fontWeight: "600" },
      },
    },
  }}
>
  {/* your app */}
</CometChatThemeProvider>
```
