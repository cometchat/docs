`CometChatMessageTemplate` is a model class, not a rendered component. Each instance maps a message `type` + `category` pair to a set of view functions that control how that message renders inside `CometChatMessageList`. Pass an array of templates to the `templates` prop on `CometChatMessageList`.

```tsx
import React, { useState, useEffect } from 'react';
import { View, Text } from 'react-native';
import {
  CometChatMessageList,
  CometChatMessageTemplate,
  CometChatUIKit,
  CometChatUIKitConstants,
} from '@cometchat/chat-uikit-react-native';
import { CometChat } from '@cometchat/chat-sdk-react-native';

export default function CustomTemplateDemo() {
  const [chatGroup, setChatGroup] = useState<CometChat.Group>();
  const [templates, setTemplates] = useState<CometChatMessageTemplate[]>([]);

  useEffect(() => {
    CometChat.getGroup('guid').then(setChatGroup);

    const allTemplates = CometChatUIKit.getDataSource().getAllMessageTemplates();
    const modified = allTemplates.map((t) => {
      if (
        t.type === CometChatUIKitConstants.MessageTypes.text &&
        t.category === CometChatUIKitConstants.MessageCategory.message
      ) {
        t.HeaderView = (message) => (
          <Text style={{ fontSize: 11, color: '#888' }}>
            {message.getSender().getName()} · In meeting
          </Text>
        );
      }
      return t;
    });
    setTemplates(modified);
  }, []);

  if (!chatGroup) return null;

  return <CometChatMessageList group={chatGroup} templates={templates} />;
}
```

## Template Structure

A message bubble is composed of these view slots, each overridable per template:

| View | Default rendering | Signature |
| --- | --- | --- |
| `HeaderView` | Sender name | `(message: CometChat.BaseMessage, alignment: MessageBubbleAlignmentType) => JSX.Element \| null` |
| `ContentView` | Text / image / video / audio / file bubble | `(message: CometChat.BaseMessage, alignment: MessageBubbleAlignmentType) => JSX.Element \| null` |
| `FooterView` | Reactions | `(message: CometChat.BaseMessage, alignment: MessageBubbleAlignmentType) => JSX.Element \| null` |
| `BottomView` | Additional content below reactions | `(message: CometChat.BaseMessage, alignment: MessageBubbleAlignmentType) => JSX.Element \| null` |
| `StatusInfoView` | Receipt + timestamp | `(message: CometChat.BaseMessage, alignment: MessageBubbleAlignmentType) => JSX.Element \| null` |
| `ReplyView` | Quoted reply preview | `(message: CometChat.BaseMessage, alignment: MessageBubbleAlignmentType) => JSX.Element \| null` |
| `LeadingView` | Avatar / left-side area | `(message: CometChat.BaseMessage, alignment: MessageBubbleAlignmentType) => JSX.Element \| null` |
| `BubbleView` | Entire bubble (overrides all above) | `(message: CometChat.BaseMessage) => JSX.Element \| null` |
| `options` | Long-press action sheet | `(loggedInUser: CometChat.User, message: CometChat.BaseMessage, theme: CometChatTheme, group?: CometChat.Group) => CometChatMessageOption[]` |

## Fetching Existing Templates

Retrieve the built-in templates and modify specific ones:

```tsx
import {
  CometChatUIKit,
  CometChatUIKitConstants,
} from '@cometchat/chat-uikit-react-native';

const allTemplates = CometChatUIKit.getDataSource().getAllMessageTemplates();

for (const t of allTemplates) {
  if (t.type === CometChatUIKitConstants.MessageTypes.text) {
    // customize t here
  }
}
```

## Common Patterns

### Custom header view

Add a custom header above every text message bubble — useful for status badges, labels, or metadata.

```tsx
import React, { useState, useEffect } from 'react';
import { View, Text, StyleSheet } from 'react-native';
import {
  CometChatMessageList,
  CometChatUIKit,
  CometChatUIKitConstants,
  CometChatMessageTemplate,
} from '@cometchat/chat-uikit-react-native';
import { CometChat } from '@cometchat/chat-sdk-react-native';

export default function HeaderViewDemo() {
  const [chatGroup, setChatGroup] = useState<CometChat.Group>();
  const [templates, setTemplates] = useState<CometChatMessageTemplate[]>([]);

  useEffect(() => {
    CometChat.getGroup('guid').then(setChatGroup);

    const allTemplates = CometChatUIKit.getDataSource().getAllMessageTemplates();
    const modified = allTemplates.map((t) => {
      if (
        t.type === CometChatUIKitConstants.MessageTypes.text &&
        t.category === CometChatUIKitConstants.MessageCategory.message
      ) {
        t.HeaderView = (message) => (
          <Text style={styles.header}>
            {message.getSender().getName()} · In meeting
          </Text>
        );
      }
      return t;
    });
    setTemplates(modified);
  }, []);

  if (!chatGroup) return null;

  return <CometChatMessageList group={chatGroup} templates={templates} />;
}

const styles = StyleSheet.create({
  header: { fontSize: 11, color: '#888', marginBottom: 2 },
});
```

### Custom content view for a custom message type

Define a template for a new message category, then push it into the existing templates array.

```tsx
import React, { useState, useEffect } from 'react';
import { View, Text, TouchableOpacity, StyleSheet } from 'react-native';
import {
  CometChatMessageList,
  CometChatUIKit,
  CometChatUIKitConstants,
  CometChatMessageTemplate,
} from '@cometchat/chat-uikit-react-native';
import { CometChat } from '@cometchat/chat-sdk-react-native';

const CUSTOM_TYPE = 'productCard';

export default function ContentViewDemo() {
  const [chatGroup, setChatGroup] = useState<CometChat.Group>();
  const [templates, setTemplates] = useState<CometChatMessageTemplate[]>([]);

  useEffect(() => {
    CometChat.getGroup('guid').then(setChatGroup);

    const allTemplates = CometChatUIKit.getDataSource().getAllMessageTemplates();
    const customTemplate = new CometChatMessageTemplate({
      type: CUSTOM_TYPE,
      category: CometChatUIKitConstants.MessageCategory.custom,
      ContentView: (message) => {
        const data = (message as CometChat.CustomMessage).getCustomData() as any;
        return (
          <View style={styles.card}>
            <Text style={styles.title}>{data?.name}</Text>
            <Text style={styles.price}>{data?.price}</Text>
            <TouchableOpacity style={styles.button}>
              <Text style={styles.buttonText}>Buy now</Text>
            </TouchableOpacity>
          </View>
        );
      },
    });
    allTemplates.push(customTemplate);
    setTemplates(allTemplates);
  }, []);

  const getRequestBuilder = () => {
    const categories = CometChatUIKit.getDataSource().getAllMessageCategories();
    categories.push(CometChatUIKitConstants.MessageCategory.custom);
    const types = CometChatUIKit.getDataSource().getAllMessageTypes();
    types.push(CUSTOM_TYPE);
    return new CometChat.MessagesRequestBuilder()
      .setCategories(categories)
      .setTypes(types)
      .hideReplies(true)
      .setLimit(30);
  };

  if (!chatGroup) return null;

  return (
    <CometChatMessageList
      group={chatGroup}
      templates={templates}
      messageRequestBuilder={getRequestBuilder()}
    />
  );
}

const styles = StyleSheet.create({
  card: { padding: 12, gap: 8 },
  title: { fontSize: 16, fontWeight: '700', color: '#141414' },
  price: { fontSize: 16, fontWeight: '700', color: '#6852D6' },
  button: {
    paddingVertical: 8,
    paddingHorizontal: 20,
    backgroundColor: '#6852D6',
    borderRadius: 8,
    alignItems: 'center',
  },
  buttonText: { color: '#fff', fontWeight: '500' },
});
```

### Custom bottom view

Render a warning or extra info strip below the message bubble content.

```tsx
import React, { useState, useEffect } from 'react';
import { View, Text, StyleSheet } from 'react-native';
import {
  CometChatMessageList,
  CometChatUIKit,
  CometChatUIKitConstants,
  CometChatMessageTemplate,
} from '@cometchat/chat-uikit-react-native';
import { CometChat } from '@cometchat/chat-sdk-react-native';

export default function BottomViewDemo() {
  const [chatGroup, setChatGroup] = useState<CometChat.Group>();
  const [templates, setTemplates] = useState<CometChatMessageTemplate[]>([]);

  useEffect(() => {
    CometChat.getGroup('guid').then(setChatGroup);

    const allTemplates = CometChatUIKit.getDataSource().getAllMessageTemplates();
    const modified = allTemplates.map((t) => {
      if (
        t.type === CometChatUIKitConstants.MessageTypes.text &&
        t.category === CometChatUIKitConstants.MessageCategory.message
      ) {
        t.BottomView = () => (
          <View style={styles.warning}>
            <Text style={styles.warningText}>
              ⚠ Cannot share contacts per guidelines
            </Text>
          </View>
        );
      }
      return t;
    });
    setTemplates(modified);
  }, []);

  if (!chatGroup) return null;

  return <CometChatMessageList group={chatGroup} templates={templates} />;
}

const styles = StyleSheet.create({
  warning: {
    paddingHorizontal: 8,
    paddingVertical: 4,
    backgroundColor: 'rgba(244,70,73,0.1)',
    borderBottomLeftRadius: 12,
    borderBottomRightRadius: 12,
  },
  warningText: { fontSize: 12, color: '#F44649' },
});
```

### Replace entire bubble

Use `BubbleView` to take full control of the bubble's rendering, bypassing all other view slots.

```tsx
import React, { useState, useEffect } from 'react';
import { View, Text, StyleSheet } from 'react-native';
import {
  CometChatMessageList,
  CometChatUIKit,
  CometChatUIKitConstants,
  CometChatMessageTemplate,
} from '@cometchat/chat-uikit-react-native';
import { CometChat } from '@cometchat/chat-sdk-react-native';

export default function BubbleViewDemo() {
  const [chatGroup, setChatGroup] = useState<CometChat.Group>();
  const [templates, setTemplates] = useState<CometChatMessageTemplate[]>([]);
  const [loggedInUser, setLoggedInUser] = useState<CometChat.User | null>(null);

  useEffect(() => {
    CometChat.getGroup('guid').then(setChatGroup);
    CometChat.getLoggedinUser().then(setLoggedInUser);

    const allTemplates = CometChatUIKit.getDataSource().getAllMessageTemplates();
    const modified = allTemplates.map((t) => {
      if (
        t.type === CometChatUIKitConstants.MessageTypes.text &&
        t.category === CometChatUIKitConstants.MessageCategory.message
      ) {
        t.BubbleView = (message) => {
          const isMine =
            message.getSender().getUid() === loggedInUser?.getUid();
          const text =
            message instanceof CometChat.TextMessage
              ? message.getText()
              : '';
          return (
            <View
              style={[
                styles.bubble,
                isMine ? styles.outgoing : styles.incoming,
              ]}
            >
              <Text style={isMine ? styles.textOut : styles.textIn}>
                {text}
              </Text>
            </View>
          );
        };
      }
      return t;
    });
    setTemplates(modified);
  }, [loggedInUser]);

  if (!chatGroup) return null;

  return <CometChatMessageList group={chatGroup} templates={templates} />;
}

const styles = StyleSheet.create({
  bubble: { padding: 10, borderRadius: 12, maxWidth: '70%' },
  outgoing: { backgroundColor: '#6852D6', alignSelf: 'flex-end' },
  incoming: { backgroundColor: '#E8E8E8', alignSelf: 'flex-start' },
  textOut: { color: '#fff' },
  textIn: { color: '#141414' },
});
```

### Custom long-press options

Override the action sheet for a specific message type.

```tsx
import React, { useState, useEffect } from 'react';
import {
  CometChatMessageList,
  CometChatUIKit,
  CometChatUIKitConstants,
  CometChatMessageTemplate,
} from '@cometchat/chat-uikit-react-native';
import { CometChat } from '@cometchat/chat-sdk-react-native';

export default function OptionsDemo() {
  const [chatGroup, setChatGroup] = useState<CometChat.Group>();
  const [templates, setTemplates] = useState<CometChatMessageTemplate[]>([]);

  useEffect(() => {
    CometChat.getGroup('guid').then(setChatGroup);

    const allTemplates = CometChatUIKit.getDataSource().getAllMessageTemplates();
    const modified = allTemplates.map((t) => {
      if (
        t.type === CometChatUIKitConstants.MessageTypes.text &&
        t.category === CometChatUIKitConstants.MessageCategory.message
      ) {
        t.options = (loggedInUser, message, theme, group) => {
          const defaults = CometChatUIKit.getDataSource().getMessageOptions(
            loggedInUser,
            message,
            theme,
            group
          );
          defaults.splice(1, 0, {
            id: 'bookmark',
            title: 'Bookmark',
            onPress: () => { /* custom logic */ },
          });
          return defaults;
        };
      }
      return t;
    });
    setTemplates(modified);
  }, []);

  if (!chatGroup) return null;

  return <CometChatMessageList group={chatGroup} templates={templates} />;
}
```

## Properties

### BubbleView

| Key | Value |
| --- | --- |
| Type | `(message: CometChat.BaseMessage) => JSX.Element \| null` |
| Default | `undefined` |

Replaces the entire message bubble. When set, all other view slots (`HeaderView`, `ContentView`, `FooterView`, `BottomView`, `StatusInfoView`, `ReplyView`, `LeadingView`) are ignored for that template.

---

### BottomView

| Key | Value |
| --- | --- |
| Type | `(message: CometChat.BaseMessage, alignment: MessageBubbleAlignmentType) => JSX.Element \| null` |
| Default | `undefined` |

Custom strip below the footer (reactions area). Use for warnings, disclaimers, or supplementary info.

---

### category

| Key | Value |
| --- | --- |
| Type | `string` |
| Default | `"MESSAGE"` |

Maps the template to a CometChat message category (e.g., `CometChatUIKitConstants.MessageCategory.message`, `CometChatUIKitConstants.MessageCategory.custom`).

---

### ContentView

| Key | Value |
| --- | --- |
| Type | `(message: CometChat.BaseMessage, alignment: MessageBubbleAlignmentType) => JSX.Element \| null` |
| Default | `undefined` |

Custom content area of the bubble. Default renders text, image, video, audio, or file depending on message type.

---

### FooterView

| Key | Value |
| --- | --- |
| Type | `(message: CometChat.BaseMessage, alignment: MessageBubbleAlignmentType) => JSX.Element \| null` |
| Default | `undefined` |

Custom footer below the content area. Default renders reactions.

---

### HeaderView

| Key | Value |
| --- | --- |
| Type | `(message: CometChat.BaseMessage, alignment: MessageBubbleAlignmentType) => JSX.Element \| null` |
| Default | `undefined` |

Custom header above the content area. Default renders the sender's name.

---

### LeadingView

| Key | Value |
| --- | --- |
| Type | `(message: CometChat.BaseMessage, alignment: MessageBubbleAlignmentType) => JSX.Element \| null` |
| Default | `undefined` |

Custom left-side area (avatar zone) of the bubble row.

---

### options

| Key | Value |
| --- | --- |
| Type | `(loggedInUser: CometChat.User, message: CometChat.BaseMessage, theme: CometChatTheme, group?: CometChat.Group) => CometChatMessageOption[]` |
| Default | SDK default options |

Returns the list of action items shown in the long-press action sheet for a message bubble.

---

### ReplyView

| Key | Value |
| --- | --- |
| Type | `(message: CometChat.BaseMessage, alignment: MessageBubbleAlignmentType) => JSX.Element \| null` |
| Default | `undefined` |

Custom quoted-reply preview rendered above the content area.

---

### StatusInfoView

| Key | Value |
| --- | --- |
| Type | `(message: CometChat.BaseMessage, alignment: MessageBubbleAlignmentType) => JSX.Element \| null` |
| Default | `undefined` |

Custom status area. Default renders the read-receipt icon and timestamp.

---

### type

| Key | Value |
| --- | --- |
| Type | `string` |
| Default | — (required) |

Maps the template to a CometChat message type (e.g., `CometChatUIKitConstants.MessageTypes.text`, `CometChatUIKitConstants.MessageTypes.image`).
