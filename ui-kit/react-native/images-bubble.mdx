## Overview

`CometChatImagesBubble` renders a message's image attachments as a grid inside a single bubble. It is **self-extracting**: pass the SDK `message` and the bubble derives the image attachments and caption itself.

It is the multi-attachment renderer for image messages sent from the [composer's staging tray](/ui-kit/react-native/message-composer#multi-attachment-staging-tray). Classic single-image messages continue to render with the existing [Image Bubble](/ui-kit/react-native/message-bubble-styling); multi-attachment image messages render this grid automatically — no configuration needed.

<Note>
`CometChatImagesBubble` and [`CometChatVideosBubble`](/ui-kit/react-native/videos-bubble) are the **same underlying renderer** (`CometChatMediaGridBubble`). A multi-attachment send fans out into one message per media kind, so each message is single-kind by the time it reaches the bubble.
</Note>

Key capabilities:

- **Grid layout** — image attachments arranged in a grid within one bubble
- **Overflow count** — when there are more images than visible cells, the last cell shows a **`+N`** overlay
- **Full-screen viewing** — tapping any cell opens [`CometChatMediaViewer`](/ui-kit/react-native/message-list), a swipeable full-screen pager over the message's media
- **Caption support** — an optional caption renders below the grid with the same rich-text formatting (mentions, links, markdown) as text messages, and can be edited after sending
- **Theming** — styled through `theme.mediaGridBubbleStyles`, overridable per instance

## Usage

The bubble renders automatically inside [`CometChatMessageList`](/ui-kit/react-native/message-list) for multi-attachment image messages. To use it standalone:

```tsx
import { CometChat } from "@cometchat/chat-sdk-react-native";
import { CometChatImagesBubble, useTheme } from "@cometchat/chat-uikit-react-native";

function ImagesMessage({ message }: { message: CometChat.MediaMessage }) {
  const theme = useTheme();
  return <CometChatImagesBubble message={message} theme={theme} />;
}
```

## Grid Behavior

| Situation | Rendering |
| --- | --- |
| One image | Single full-width cell |
| Several images | Grid of cells inside the bubble |
| More images than visible cells | Last visible cell shows a `+N` overlay with the remaining count |
| Tap on any cell | Opens the full-screen media viewer at that item |

The full-screen viewer pages through **all** of the message's media with swipe, previous/next arrows, page dots, and a download action.

## Props

### message

The image message. The bubble extracts its attachments and caption from it. **Required.**

| | |
| --- | --- |
| Type | `CometChat.MediaMessage` |
| Required | Yes |

---

### theme

The active UI Kit theme. Pass the value from `useTheme()`. **Required.**

| | |
| --- | --- |
| Type | `CometChatTheme` |
| Required | Yes |

---

### style

Per-instance style overrides. Deep-merged over `theme.mediaGridBubbleStyles`, so you only supply the keys you want to change.

| | |
| --- | --- |
| Type | `CometChatTheme["mediaGridBubbleStyles"]` |
| Default | `undefined` |

---

## Styling

Style the bubble globally through the theme (`mediaGridBubbleStyles`), or per instance through the `style` prop. Available keys:

| Key | Type | Styles |
| --- | --- | --- |
| `containerStyle` | `ViewStyle` | The bubble's grid container |
| `cellStyle` | `ViewStyle` | Each grid cell |
| `playButtonStyle` | `ViewStyle` | Play button overlay (video cells) |
| `playIconStyle` | `ImageStyle` | Play icon inside the button |
| `durationChipStyle` | `ViewStyle` | Duration chip (video cells) |
| `durationTextStyle` | `TextStyle` | Duration text |
| `overflowOverlayStyle` | `ViewStyle` | The `+N` overflow overlay |
| `overflowTextStyle` | `TextStyle` | The `+N` overflow text |

```tsx
import { CometChatThemeProvider } from "@cometchat/chat-uikit-react-native";

<CometChatThemeProvider
  theme={{
    light: {
      mediaGridBubbleStyles: {
        cellStyle: { borderRadius: 12 },
        overflowTextStyle: { fontSize: 28 },
      },
    },
  }}
>
  {/* your app */}
</CometChatThemeProvider>
```
