## Overview

`CometChatVoiceNoteBubble` renders a **recorded voice note** as a waveform player — play/pause control, animated waveform, and playback progress — with an optional caption below. It is **self-extracting**: pass the SDK `message` and the bubble derives the voice-note attachment and caption itself.

<Note>
**Voice notes vs audio files.** When a user records audio with the composer's voice recorder, the message is tagged with `audioType: "voice_note"` in its metadata and renders with this bubble. Audio **files** picked as attachments carry no `audioType` and render as [Audios Bubble](/ui-kit/react-native/audios-bubble) playback cards instead. The routing is automatic.
</Note>

Key capabilities:

- **Waveform player** — the familiar voice-message presentation with play/pause and progress
- **Caption support** — an optional caption renders below the player with rich-text formatting, editable after sending
- **Theming** — styled through `theme.voiceNoteBubbleStyles`, overridable per instance

---

## Usage

The bubble renders automatically inside [`CometChatMessageList`](/ui-kit/react-native/message-list) for voice-note messages. To use it standalone:

```tsx
import { CometChat } from "@cometchat/chat-sdk-react-native";
import { CometChatVoiceNoteBubble, useTheme } from "@cometchat/chat-uikit-react-native";

function VoiceNoteMessage({ message }: { message: CometChat.MediaMessage }) {
  const theme = useTheme();
  return <CometChatVoiceNoteBubble message={message} theme={theme} />;
}
```

---

## Props

### message

The voice-note message. The bubble extracts the recording and caption from it. **Required.**

| | |
| --- | --- |
| Type | `CometChat.MediaMessage` |
| Required | Yes |

---

### theme

The active UI Kit theme. Pass the value from `useTheme()`. **Required.**

| | |
| --- | --- |
| Type | `CometChatTheme` |
| Required | Yes |

---

### style

Per-instance style overrides. Deep-merged over `theme.voiceNoteBubbleStyles`, so you only supply the keys you want to change.

| | |
| --- | --- |
| Type | `CometChatTheme["voiceNoteBubbleStyles"]` |
| Default | `undefined` |

---

## Styling

Style the bubble globally through the theme (`voiceNoteBubbleStyles`), or per instance through the `style` prop. Available keys:

| Key | Type | Styles |
| --- | --- | --- |
| `containerStyle` | `ViewStyle` | The bubble container |
| `playViewContainerStyle` | `ViewStyle` | The player row |
| `playIconContainerStyle` | `ViewStyle` | Play/pause button container |
| `playIconStyle` | `ImageStyle` | Play/pause icon |
| `waveContainerStyle` | `ViewStyle` | Waveform container |
| `waveStyle` | `ViewStyle` | Individual waveform bars |
| `playProgressTextStyle` | `TextStyle` | Playback progress text |
| `captionStyle` | `TextStyle` | Caption text below the player |

```tsx
import { CometChatThemeProvider } from "@cometchat/chat-uikit-react-native";

<CometChatThemeProvider
  theme={{
    light: {
      voiceNoteBubbleStyles: {
        waveStyle: { backgroundColor: "#6852D6" },
        playProgressTextStyle: { fontVariant: ["tabular-nums"] },
      },
    },
  }}
>
  {/* your app */}
</CometChatThemeProvider>
```
