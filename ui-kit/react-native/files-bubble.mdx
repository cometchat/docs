## Overview

`CometChatFilesBubble` renders a message's document attachments as a vertical list of downloadable file cards. It is **self-extracting**: pass the SDK `message` and the bubble derives the file attachments and caption itself.

It is the multi-attachment renderer for file messages sent from the [composer's staging tray](/ui-kit/react-native/message-composer#multi-attachment-staging-tray). Classic single-file messages continue to render with the existing File Bubble; multi-attachment file messages render this list automatically — no configuration needed.

Key capabilities:

- **File cards** — one card per attachment with a file-type icon (PDF, spreadsheet, presentation, archive, and more), file name, and size
- **Download** — download each file from its card
- **Show more / Show less** — messages with more than **3** files collapse behind a "Show *N* more" toggle
- **Caption support** — an optional caption renders below the cards with rich-text formatting, editable after sending
- **Theming** — styled through `theme.filesBubbleStyles`, overridable per instance

## Usage

The bubble renders automatically inside [`CometChatMessageList`](/ui-kit/react-native/message-list) for multi-attachment file messages. To use it standalone:

```tsx
import { CometChat } from "@cometchat/chat-sdk-react-native";
import { CometChatFilesBubble, useTheme } from "@cometchat/chat-uikit-react-native";

function FilesMessage({ message }: { message: CometChat.MediaMessage }) {
  const theme = useTheme();
  return <CometChatFilesBubble message={message} theme={theme} />;
}
```

## File Card Anatomy

| Element | Description |
| --- | --- |
| Type icon | Icon matched to the file type (PDF, document, spreadsheet, presentation, archive, …) |
| File name | Display name of the file |
| File size | Human-readable size |
| Download button | Downloads the file |

A message with one file renders a single plain row; two or more render one card per file. Past **3** files the rest collapse behind a **Show *N* more** toggle ("Show less" collapses them again).

## Props

### message

The file message. The bubble extracts its attachments and caption from it. **Required.**

| | |
| --- | --- |
| Type | `CometChat.MediaMessage` |
| Required | Yes |

---

### theme

The active UI Kit theme. Pass the value from `useTheme()`. **Required.**

| | |
| --- | --- |
| Type | `CometChatTheme` |
| Required | Yes |

---

### style

Per-instance style overrides. Deep-merged over `theme.filesBubbleStyles`, so you only supply the keys you want to change.

| | |
| --- | --- |
| Type | `CometChatTheme["filesBubbleStyles"]` |
| Default | `undefined` |

---

## Styling

Style the bubble globally through the theme (`filesBubbleStyles`), or per instance through the `style` prop. Available keys:

| Key | Type | Styles |
| --- | --- | --- |
| `containerStyle` | `ViewStyle` | The bubble container |
| `cardStyle` | `ViewStyle` | Each file card |
| `fileNameStyle` | `TextStyle` | File name text |
| `fileSizeTextStyle` | `TextStyle` | File size text |
| `downloadIconStyle` | `ImageStyle` | Download icon |
| `expandButtonTextStyle` | `TextStyle` | "Show N more" / "Show less" toggle text |
| `captionStyle` | `TextStyle` | Caption text below the cards |

```tsx
import { CometChatThemeProvider } from "@cometchat/chat-uikit-react-native";

<CometChatThemeProvider
  theme={{
    light: {
      filesBubbleStyles: {
        cardStyle: { borderRadius: 12 },
        expandButtonTextStyle: { fontWeight: "600" },
      },
    },
  }}
>
  {/* your app */}
</CometChatThemeProvider>
```
