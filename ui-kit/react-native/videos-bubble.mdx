## Overview

`CometChatVideosBubble` renders a message's video attachments as a thumbnail grid inside a single bubble. It is **self-extracting**: pass the SDK `message` and the bubble derives the video attachments and caption itself.

It is the multi-attachment renderer for video messages sent from the [composer's staging tray](/ui-kit/react-native/message-composer#multi-attachment-staging-tray). Classic single-video messages continue to render with the existing Video Bubble; multi-attachment video messages render this grid automatically — no configuration needed.

<Note>
`CometChatVideosBubble` and [`CometChatImagesBubble`](/ui-kit/react-native/images-bubble) are the **same underlying renderer** (`CometChatMediaGridBubble`). A multi-attachment send fans out into one message per media kind, so each message is single-kind by the time it reaches the bubble.
</Note>

Key capabilities:

- **Thumbnail grid** — video attachments arranged in a grid, each cell showing a poster/thumbnail with a centered play overlay
- **Duration chip** — each cell shows the video's duration when it is known (captured at send time or provided by the thumbnail service)
- **Overflow count** — when there are more videos than visible cells, the last cell shows a **`+N`** overlay
- **Full-screen playback** — tapping a cell opens `CometChatMediaViewer`, where the video plays with native controls
- **Caption support** — an optional caption renders below the grid with rich-text formatting, editable after sending
- **Theming** — styled through `theme.mediaGridBubbleStyles`, overridable per instance

## Usage

The bubble renders automatically inside [`CometChatMessageList`](/ui-kit/react-native/message-list) for multi-attachment video messages. To use it standalone:

```tsx
import { CometChat } from "@cometchat/chat-sdk-react-native";
import { CometChatVideosBubble, useTheme } from "@cometchat/chat-uikit-react-native";

function VideosMessage({ message }: { message: CometChat.MediaMessage }) {
  const theme = useTheme();
  return <CometChatVideosBubble message={message} theme={theme} />;
}
```

## Cell Anatomy

| Element | Description |
| --- | --- |
| Thumbnail | Video poster from the thumbnail service, with a dark scrim for contrast |
| Play overlay | Centered play button indicating the cell is a video |
| Duration chip | Bottom-corner chip with the video length (when known) |
| `+N` overlay | Remaining-count overlay on the last visible cell when the message has more videos |

Tapping any cell opens the full-screen viewer at that item; playback there uses the platform's native video controls (play/pause, scrubbing).

## Props

### message

The video message. The bubble extracts its attachments and caption from it. **Required.**

| | |
| --- | --- |
| Type | `CometChat.MediaMessage` |
| Required | Yes |

---

### theme

The active UI Kit theme. Pass the value from `useTheme()`. **Required.**

| | |
| --- | --- |
| Type | `CometChatTheme` |
| Required | Yes |

---

### style

Per-instance style overrides. Deep-merged over `theme.mediaGridBubbleStyles`, so you only supply the keys you want to change.

| | |
| --- | --- |
| Type | `CometChatTheme["mediaGridBubbleStyles"]` |
| Default | `undefined` |

---

## Styling

Style the bubble globally through the theme (`mediaGridBubbleStyles`), or per instance through the `style` prop. Available keys:

| Key | Type | Styles |
| --- | --- | --- |
| `containerStyle` | `ViewStyle` | The bubble's grid container |
| `cellStyle` | `ViewStyle` | Each grid cell |
| `playButtonStyle` | `ViewStyle` | Play button overlay |
| `playIconStyle` | `ImageStyle` | Play icon inside the button |
| `durationChipStyle` | `ViewStyle` | Duration chip |
| `durationTextStyle` | `TextStyle` | Duration text |
| `overflowOverlayStyle` | `ViewStyle` | The `+N` overflow overlay |
| `overflowTextStyle` | `TextStyle` | The `+N` overflow text |

```tsx
import { CometChatThemeProvider } from "@cometchat/chat-uikit-react-native";

<CometChatThemeProvider
  theme={{
    light: {
      mediaGridBubbleStyles: {
        durationChipStyle: { borderRadius: 6 },
        playButtonStyle: { opacity: 0.9 },
      },
    },
  }}
>
  {/* your app */}
</CometChatThemeProvider>
```
