The CometChat Angular UI Kit provides prebuilt, customizable standalone components for adding chat, voice, and video calling to any Angular app. Each component handles its own data fetching, real-time listeners, and state — you just drop them into your layout.

## Integrate with AI Coding Agents

Use [CometChat Agent Skills](/agent-skills) to add chat to any Angular project through your AI coding agent. The skills take an AI-first approach — your agent has a short conversation with you to understand your project and chat requirements, then writes production-grade integration code tailored to the files you already have. The Angular skills target **Angular UI Kit v5** and cover both Angular CLI and Nx workspaces.

Works with Claude Code, Cursor, Codex, GitHub Copilot, Kiro, Replit Agent, Gemini, Windsurf, Cline, Continue, and Aider — see the [full list](/agent-skills#supported-agents).

```bash
npx @cometchat/skills add
```

Use `--ide <name>` to target a specific agent (e.g. `--ide cursor`), or `--ide all` to install for every supported agent.

Then in your agent:

```
/cometchat add chat to my app
```

The skills detect your workspace layout, routing, and existing auth system. They onboard you to CometChat directly in the terminal — signup, login, and app creation all via the CLI. They read your routes, nav, and standalone components before proposing a placement, show the plan (which files they will create, modify, and leave untouched), and wait for your approval before writing code. Credentials land in `src/environments/environment.ts`.

After the first integration, re-run `/cometchat` anytime to pick from the iteration menu:

- **Customize look & feel** — theme presets (slack / whatsapp / imessage / discord / notion) or your own brand color
- **Add a feature** — 40+ features including calls, reactions, polls, AI smart replies, file sharing, presence
- **Customize a component** — custom message bubbles, headers, composer actions, empty/loading states
- **Set up production auth** — replace the dev Auth Key with a server-side token endpoint
- **Set up user management** — server endpoints for creating/updating/deleting CometChat users
- **Set up push notifications** — Web Push end-to-end
- **Run diagnostics** — verify, drift detection, symptom-to-cause lookup

<Accordion title="Recommended: CometChat Docs MCP">

For deeper component customization (custom views, SDK events, request builders), connect the **CometChat Docs MCP** so your agent reads the current docs instead of guessing at APIs:

**Claude Code:**
```bash
claude mcp add --transport http cometchat-docs https://mcp.cometchat.com/mcp
```

**Cursor** (`.cursor/mcp.json`):
```json
{ "mcpServers": { "cometchat-docs": { "url": "https://mcp.cometchat.com/mcp" } } }
```

**Windsurf (Devin Desktop):**
```json
{ "mcpServers": { "cometchat-docs": { "url": "https://mcp.cometchat.com/mcp" } } }
```

No authentication required. `npx @cometchat/skills add` wires this up automatically for Claude Code, Cursor, Gemini, and Codex (pass `--no-mcp` to skip it) — add it by hand only for the other agents. For Claude Desktop, VS Code, and Codex, see [MCP Integration](/mcp-server).

</Accordion>
