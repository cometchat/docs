## Overview

The CometChatCallHost component draws the screens of a call: the outgoing call screen while a 1:1 call rings, and the ongoing call screen once it is answered or a group call starts. It draws them for calls placed from [cometchat-call-buttons](/ui-kit/angular/components/cometchat-call-buttons) (including the buttons in [cometchat-message-header](/ui-kit/angular/components/cometchat-message-header)) and [cometchat-call-logs](/ui-kit/angular/components/cometchat-call-logs), and for calls answered from [cometchat-incoming-call](/ui-kit/angular/components/cometchat-incoming-call).

Put one `<cometchat-call-host>` at the root of your app. While it is mounted, the call buttons leave the screens to it, so a call carries on when the user opens another chat or leaves the page the call was placed from.

Without a call host, each call buttons component draws the screens itself, inside the component. When the last call buttons component that draws them is destroyed, the call ends with them: a call that is still ringing is cancelled, and an answered call is left. That way the other person is never left ringing, or talking to nobody, while this user sees no call.

### Key Features

- **Screens that outlive the buttons**: A call goes on when the call buttons that placed it are destroyed
- **One place for every call**: Draws the screens of calls from the call buttons, the message header, the call logs and the incoming call card
- **Ringing status**: The outgoing call screen says "Ringing..." once the callee's device rings
- **Settings from the call buttons**: Uses the `callSettingsBuilder`, sound settings and `onError` of the call buttons that placed the call, then the [GlobalConfig](/ui-kit/angular/customization/global-config)

## Basic Usage

Add it next to your router outlet, in the root component:

```typescript expandable
import { Component } from '@angular/core';
import { RouterOutlet } from '@angular/router';
import {
  CometChatCallHostComponent,
  CometChatIncomingCallComponent,
} from '@cometchat/chat-uikit-angular';

@Component({
  selector: 'app-root',
  standalone: true,
  imports: [RouterOutlet, CometChatCallHostComponent, CometChatIncomingCallComponent],
  template: `
    <router-outlet />
    <cometchat-incoming-call></cometchat-incoming-call>
    <cometchat-call-host></cometchat-call-host>
  `,
})
export class App {}
```

<Note>
Mount only one call host. It has no inputs or outputs: the screens it draws take their settings from the call buttons that placed the call.
</Note>
