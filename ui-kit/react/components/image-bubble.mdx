## Overview

`CometChatImageBubble` renders the image attachment of a media message. It is **self-extracting**: pass the SDK `message` and the bubble derives its attachment and alignment itself, so it works standalone.

It opens a fullscreen viewer when the image is clicked.

## Usage

```tsx
import { CometChat } from "@cometchat/chat-sdk-javascript";
import { CometChatImageBubble } from "@cometchat/chat-uikit-react";

function ImageMessage({ message }: { message: CometChat.MediaMessage }) {
  return <CometChatImageBubble message={message} />;
}
```

---

## Props

### message

The image message. The bubble extracts its attachment. **Required.**

| | |
| --- | --- |
| Type | `CometChat.MediaMessage` |
| Required | Yes |

---

### alignment

Override incoming/outgoing alignment. Defaults to sender-vs-logged-in-user.

| | |
| --- | --- |
| Type | `"left" \| "right"` |
| Default | derived |

---

### placeholderImage

Custom placeholder image URL shown while the image loads. Falls back to a default photo icon.

| | |
| --- | --- |
| Type | `string` |
| Default | `undefined` |

---

### onImageClicked

Fires when an image is clicked (in addition to opening the fullscreen viewer).

| | |
| --- | --- |
| Type | `(attachment: CometChatImageBubbleAttachment, index: number) => void` |
| Default | `undefined` |

---

### className

Additional CSS class applied to the root element.

| | |
| --- | --- |
| Type | `string` |
| Default | `undefined` |
