## Overview

`CometChatAudioBubble` renders an audio attachment with inline playback. It is **self-extracting**: pass the SDK `message` and the bubble derives the audio attachment itself, reading alignment and localization from hooks, so it works standalone. It shows play/pause controls, a seekable progress bar, elapsed/total time, and a download control.

## Usage

```tsx
import { CometChat } from "@cometchat/chat-sdk-javascript";
import { CometChatAudioBubble } from "@cometchat/chat-uikit-react";

function AudioMessage({ message }: { message: CometChat.MediaMessage }) {
  return <CometChatAudioBubble message={message} />;
}
```

---

## Props

### message

The audio message. The bubble extracts the attachment from it. **Required.**

| | |
| --- | --- |
| Type | `CometChat.MediaMessage` |
| Required | Yes |

---

### alignment

Override incoming/outgoing alignment. Defaults to sender-vs-logged-in-user.

| | |
| --- | --- |
| Type | `"left" \| "right"` |
| Default | derived |

---

### className

Additional CSS class applied to the root element.

| | |
| --- | --- |
| Type | `string` |
| Default | `undefined` |
