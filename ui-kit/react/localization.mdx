## Overview

The UI Kit ships with translations for 20 languages. All user-facing text (button labels, status messages, timestamps, error messages) is resolved through translation keys. Set the `locale` prop on `CometChatProvider` to switch languages.

---

## Setting the Language

```tsx
<CometChatProvider locale="fr">
  <MyChatApp />
</CometChatProvider>
```

## Accessing Translations in Components

Use the `useLocale` hook:

```tsx
import { useLocale } from "@cometchat/chat-uikit-react";

function MyComponent() {
  const { getLocalizedString, language } = useLocale();

  return <p>{getLocalizedString("message_deleted")}</p>;
  // Renders: "This message was deleted" (en-us)
  // Renders: "Ce message a été supprimé" (fr)
}
```

## Adding Custom Translations

Override or add translation keys for a language:

```tsx
import { CometChatLocalize } from "@cometchat/chat-uikit-react";

const localize = CometChatLocalize.getSharedInstance();
localize?.addTranslation({
  "en-us": {
    "custom_greeting": "Welcome to our chat!",
    "message_deleted": "Message removed",  // Override built-in key
  },
});
```

`addTranslation()` takes one object keyed by language code, so you can add several languages in one call.

### Offline Support Texts

With [offline support](/ui-kit/react/offline-support) turned on, the UI Kit shows these texts. Every built-in language has them, and you override them like any other key. For where each one appears, see [Offline States and Texts](/ui-kit/react/offline-support#offline-states-and-texts).

| Key | en-us |
| --- | --- |
| `conversations_connect_to_load` | Connect to load chats |
| `users_connect_to_load` | Connect to load users |
| `groups_connect_to_load` | Connect to load groups |
| `group_members_connect_to_load` | Connect to load members |
| `message_list_connect_to_load` | Connect to load messages |
| `reaction_list_connect_to_load` | Connect to load reactions |
| `notifications_connect_to_load` | Connect to load notifications |
| `search_connect_to_search` | Connect to search |
| `search_connect_to_search_messages` | Connect to search |
| `search_connect_to_search_subtitle` | Search needs an internet connection. |
| `message_list_connect_to_load_more` | Connect to load more |
| `message_list_connect_to_load_newer` | Connect to load more |
| `message_list_jump_to_latest` | Jump to latest |
| `message_list_not_sent_yet` | Not sent yet |
| `message_list_not_sent_tap_to_retry` | Not sent. Tap to retry |
| `message_bubble_media_available_when_online` | Available when online |
| `message_list_queue_full` | Too many messages waiting to send |
| `message_list_file_too_large_offline` | File too large to send offline |
| `message_list_send_in_flight` | Sending… try again in a moment |
| `message_list_option_delete_failed` | Couldn't remove the message |
| `message_list_unsent_message_removed` | 1 unsent message was removed |
| `message_list_messages_not_sent_one` / `_other` | `{{count}}` message wasn't sent / `{{count}}` messages weren't sent |
| `message_list_unsent_messages_lost_one` / `_other` | `{{count}}` unsent message couldn't be recovered / `{{count}}` unsent messages couldn't be recovered |
| `message_list_unsent_messages_maybe_lost` | Some unsent messages may not have been sent |

The count texts are plural keys: the UI Kit picks `<key>_one`, `<key>_other`, and `<key>_few` or `<key>_many` where a language has them, for the current language, and replaces `{{count}}` with the number. Override every plural form your language uses.

## Fallback Language

If a key is not found in the current language, the system falls back to the fallback language (default: `en-us`). Configure via `CometChatLocalize`:

```tsx
const localize = new CometChatLocalize({
  language: "fr",
  fallbackLanguage: "en-us",
});
```

## Date & Time Localization

Date formatting respects the locale. The `CometChatDate` component and all timestamp displays use locale-aware formatting:

- Relative time: "2 minutes ago", "il y a 2 minutes"
- Day names: "Monday", "Lundi"
- Date formats: "12/25/2024" (en-us), "25/12/2024" (en-gb)

## Static Access (Non-React Code)

For plugins and utilities that run outside React components:

```tsx
import { CometChatLocalize } from "@cometchat/chat-uikit-react";

const t = CometChatLocalize.getSharedInstance()?.t;
const text = t?.("message_deleted") ?? "This message was deleted";
```
