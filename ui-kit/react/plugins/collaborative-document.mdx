## Overview

The Collaborative Document plugin handles messages of type `extension_document` in category `custom`. It renders a card with a document banner image, title, subtitle, and an "Open Document" button that launches the collaborative editor in a new window. The plugin routes document messages to [`CometChatCollaborativeDocumentBubble`](/ui-kit/react/components/collaborative-document-bubble).
