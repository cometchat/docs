## Overview

The Stickers plugin handles messages of type `extension_sticker` in category `custom`. It renders a sticker image extracted from the message's custom data. The plugin routes sticker messages to [`CometChatStickerBubble`](/ui-kit/react/components/sticker-bubble).

---

## Context Menu Options

Standard media options: React, Reply, Reply in Thread, Info, Delete, Report, Mark Unread, Message Privately.

---

## Conversation Preview

Returns: `Sticker` (localized via `conversation_subtitle_sticker` key)
