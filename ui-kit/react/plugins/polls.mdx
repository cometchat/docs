## Overview

The Polls plugin handles messages of type `extension_poll` in category `custom`. It renders an interactive poll bubble where users can vote on options and see real-time results. The plugin routes poll messages to [`CometChatPollBubble`](/ui-kit/react/components/poll-bubble).

---

## Context Menu Options

Standard media options: React, Reply, Reply in Thread, Info, Delete, Report, Mark Unread, Message Privately.

---

## Conversation Preview

Returns the poll question text (truncated to 80 characters). Falls back to `Poll` if no question is found.
