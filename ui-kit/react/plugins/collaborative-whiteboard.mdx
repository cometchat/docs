## Overview

The Collaborative Whiteboard plugin handles messages of type `extension_whiteboard` in category `custom`. It renders a card with a whiteboard banner image, title, subtitle, and an "Open Whiteboard" button that launches the whiteboard in a new window. The plugin routes whiteboard messages to [`CometChatCollaborativeWhiteboardBubble`](/ui-kit/react/components/collaborative-whiteboard-bubble).
