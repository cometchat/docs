## Overview

The Audio plugin handles messages of type `audio` in category `message`. It renders an audio player with waveform visualization (via WaveSurfer.js), play/pause controls, duration display, and a download button. The plugin routes audio messages to [`CometChatAudioBubble`](/ui-kit/react/components/audio-bubble).
