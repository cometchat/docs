## Overview

The File plugin handles messages of type `file` in category `message`. It renders a file card showing the file name, size, extension icon, and a download button with progress indicator. The plugin routes file messages to [`CometChatFileBubble`](/ui-kit/react/components/file-bubble).

---

## Context Menu Options

Same as [Image Plugin](/ui-kit/react/plugins/image) — standard media options (React, Reply, Reply in Thread, Info, Delete, Report, Mark Unread, Message Privately).
