This page shows all features available when using UI Kit Builder. Features marked with ✅ work out-of-the-box. Features marked with <Tooltip tip="Not available out of the box in the UI Kit — supported via the SDK and requires custom implementation.">🔨</Tooltip> require custom code implementation using the SDK.
