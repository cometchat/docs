Your choices in the UI Kit Builder are exported as a JSON file. Editing that file is the supported way to change features after export: no component code changes.

## Where the settings live

| File | Role |
| --- | --- |
| `src/builder/cometchat-builder-settings.json` | **Your settings.** Written by the dashboard at export, and safe to edit by hand afterwards |
| `src/builder/builderSettings.ts` | Loads the JSON and exports `builderSettings` |
| `src/CometChat/config/settings.types.ts` | The TypeScript types, including `CometChatSettingsInterface` |
| `src/CometChat/config/defaultSettings.ts` | The default for every key |

The file has this shape:

```json
{
  "builderId": "…",
  "settings": {
    "chatFeatures": { },
    "callFeatures": { },
    "layout": { },
    "style": { }
  }
}
```

`src/index.tsx` passes `builderSettings` to `<SettingsProvider>`, which merges it over the defaults.

<Note>
  **Every key is optional.** Anything the file leaves out uses its default, so a
  partial file — or one exported before a newer setting existed — still works.
  Arrays such as `layout.tabs` replace the default rather than merging with it.
</Note>

Inside the app, components read the resolved settings with `useSettings()` from `src/CometChat/config/SettingsContext`.

<Warning>
  In [v6](/ui-kit/react/v6/overview) these settings lived in a TypeScript file, `src/CometChat/CometChatSettings.ts`, and layout choices were props on `CometChatApp`. Both are gone in [React UI Kit v7](/ui-kit/react/overview): settings are JSON in `src/builder/`, and there is no `CometChatApp`. See [Integration](/chat-builder/react-router/integration).
</Warning>

## 1. Chat Features (`chatFeatures`)

### 1.1 Core messaging experience (`coreMessagingExperience`)

| Property | Type | Description |
| --- | --- | --- |
| `typingIndicator` | boolean | Displays when a user is typing |
| `threadConversationAndReplies` | boolean | Enables threaded conversations and replies |
| `photosSharing` | boolean | Allows sharing of images |
| `videoSharing` | boolean | Supports video file sharing |
| `audioSharing` | boolean | Enables sharing of audio recordings |
| `fileSharing` | boolean | Allows file sharing |
| `editMessage` | boolean | Enables editing sent messages |
| `deleteMessage` | boolean | Allows users to delete their sent messages |
| `messageDeliveryAndReadReceipts` | boolean | Shows message delivery and read receipts |
| `userAndFriendsPresence` | boolean | Displays users' online/offline status |
| `conversationAndAdvancedSearch` | boolean | Enables conversation and advanced search |
| `moderation` | boolean | Shows the notice when a message is blocked by moderation |
| `quotedReplies` | boolean | Allows quoting messages in replies |
| `markAsUnread` | boolean | Enables marking messages as unread |
| `richTextFormatting` | boolean | Shows the rich text formatting options (bold, italic, lists, code…) in the composer |
| `multipleAttachments` | boolean | Lets users attach several files to one message before sending. Defaults to `true`; when `false`, each attachment sends immediately |

### 1.2 Deeper user engagement (`deeperUserEngagement`)

| Property | Type | Description |
| --- | --- | --- |
| `mentions` | boolean | Enables @mentions in chat |
| `mentionAll` | boolean | Allows @all to notify every group member |
| `reactions` | boolean | Allows reacting to messages |
| `messageTranslation` | boolean | Provides message translation |
| `polls` | boolean | Enables creating and answering polls |
| `collaborativeWhiteboard` | boolean | Allows real-time whiteboard collaboration |
| `collaborativeDocument` | boolean | Enables document collaboration |
| `voiceNotes` | boolean | Allows sending voice notes |
| `emojis` | boolean | Supports emojis in chat |
| `stickers` | boolean | Allows sending stickers |
| `userInfo` | boolean | Displays the user details panel |
| `groupInfo` | boolean | Displays the group details panel |

### 1.3 AI user copilot (`aiUserCopilot`)

| Property | Type | Description |
| --- | --- | --- |
| `conversationStarter` | boolean | Suggests AI-generated conversation starters |
| `conversationSummary` | boolean | Offers a summary of the conversation |
| `smartReply` | boolean | Suggests replies based on context |

### 1.4 User management (`userManagement`)

| Property | Type | Description |
| --- | --- | --- |
| `friendsOnly` | boolean | Restricts chat to friends only |

### 1.5 Group management (`groupManagement`)

| Property | Type | Description |
| --- | --- | --- |
| `createGroup` | boolean | Allows creating new groups |
| `addMembersToGroups` | boolean | Enables adding members to groups |
| `joinLeaveGroup` | boolean | Allows joining and leaving groups |
| `deleteGroup` | boolean | Enables "Delete and exit" for group owners |
| `viewGroupMembers` | boolean | Shows the group member list |

### 1.6 Moderator controls (`moderatorControls`)

| Property | Type | Description |
| --- | --- | --- |
| `kickUsers` | boolean | Offers "Kick" on a group member |
| `banUsers` | boolean | Offers "Ban" on a group member |
| `promoteDemoteMembers` | boolean | Offers "Change Scope" on a group member |
| `reportMessage` | boolean | Offers "Report" on a received message |

### 1.7 Private messaging within groups (`privateMessagingWithinGroups`)

| Property | Type | Description |
| --- | --- | --- |
| `sendPrivateMessageToGroupMembers` | boolean | Offers "Message Privately" on a message in a group |

### 1.8 In-app sounds (`inAppSounds`)

| Property | Type | Description |
| --- | --- | --- |
| `incomingMessageSound` | boolean | Plays a sound when a message arrives |
| `outgoingMessageSound` | boolean | Plays a sound when a message is sent |

## 2. Call Features (`callFeatures`)

### 2.1 Voice and video calling (`voiceAndVideoCalling`)

| Property | Type | Description |
| --- | --- | --- |
| `oneOnOneVoiceCalling` | boolean | Voice call button in one-on-one chats |
| `oneOnOneVideoCalling` | boolean | Video call button in one-on-one chats |
| `groupVoiceConference` | boolean | Voice call button in groups |
| `groupVideoConference` | boolean | Video call button in groups |

<Note>
  Calling also requires `@cometchat/calls-sdk-javascript` to be installed and
  `setCallingEnabled(true)` in your initialization — see
  [Integration](/chat-builder/react-router/integration).
</Note>

---

## 3. Layout (`layout`)

| Property | Type | Description |
| --- | --- | --- |
| `withSideBar` | boolean | When `false`, renders a single chat pane with no conversations list |
| `tabs` | string[] | Which tabs the sidebar offers, in order — `['chats', 'calls', 'users', 'groups']`. A single tab hides the tab bar |
| `chatType` | string | `'user'` or `'group'` — which kind of chat opens when there is no sidebar |
| `compactMessageComposer` | boolean | Uses the compact composer instead of the multi-line one |

---

## 4. Style (`style`)

Applied by `src/builder/useBuilderTheme.ts`.

### 4.1 Theme

| Property | Type | Description |
| --- | --- | --- |
| `theme` | string | `'light'`, `'dark'`, or `'system'`. `'system'` follows the operating system setting |

### 4.2 Color

| Property | Type | Description |
| --- | --- | --- |
| `brandColor` | string | Primary UI color (hex, e.g. `'#6852D6'`). The lighter and darker shades used across the UI are derived from it |
| `primaryTextLight` | string | Text color in light mode |
| `primaryTextDark` | string | Text color in dark mode |
| `secondaryTextLight` | string | Secondary text color in light mode |
| `secondaryTextDark` | string | Secondary text color in dark mode |

### 4.3 Typography

| Property | Type | Description |
| --- | --- | --- |
| `font` | string | The UI font family, e.g. `'roboto'`. The UI Kit Builder's Font dropdown lists the supported values |
| `size` | string | `'compact'`, `'default'`, or `'comfortable'` |

<Note>
  The font name is applied as given. A font the browser cannot resolve falls
  back to the system default, so if you set a font of your own, load it in your
  app with `@font-face` or a stylesheet link.
</Note>

## 5. No Code (`noCode`) — ignored by this app

Used only by the CometChat no-code widget. The dashboard may include this section in your export; this app ignores it.

| Property | Type | Description |
| --- | --- | --- |
| `docked` | boolean | Whether the widget is docked |
| `styles.buttonBackGround` | string | Background color for the docked button |
| `styles.buttonShape` | string | Shape of the docked button, e.g. `'rounded'` |
| `styles.openIcon`, `styles.closeIcon` | string | Icons for the docked button |
| `styles.customJs`, `styles.customCss` | string | Custom code applied to the widget |
| `styles.dockedAlignment` | string | `'left'` or `'right'` |

---

## 6. Agent (`agent`) — ignored by this app

Used only by CometChat's AI agent experiences.

| Property | Type | Description |
| --- | --- | --- |
| `chatHistory` | boolean | Access to previous chat history |
| `newChat` | boolean | Starting new conversations |
| `agentIcon` | string | URL or path to the agent's icon |
| `showAgentIcon` | boolean | Whether to display the agent icon |

---

## Example

A partial file that turns off calling and forces dark mode. Everything else keeps its default:

```json
{
  "builderId": "your-builder-id",
  "settings": {
    "callFeatures": {
      "voiceAndVideoCalling": {
        "oneOnOneVoiceCalling": false,
        "oneOnOneVideoCalling": false,
        "groupVoiceConference": false,
        "groupVideoConference": false
      }
    },
    "style": {
      "theme": "dark",
      "color": { "brandColor": "#6852D6" }
    }
  }
}
```
