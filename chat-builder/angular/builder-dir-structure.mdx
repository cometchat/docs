## Key Files

| File                                 | Purpose                                                                      |
| ------------------------------------ | ---------------------------------------------------------------------------- |
| `src/app/cometchat-app.component.ts` | **The component you render** — `<cometchat-app />`, the whole chat experience |
| `src/app/app.config.ts`              | Application providers, including where Builder settings are applied           |
| `src/main.ts`                        | Bootstraps the app and initializes the UI Kit                                 |
| `src/environments/environment.ts`    | Your App ID, region and Auth Key, written at export time                      |
| `angular.json`                       | Build config — where the UI Kit's stylesheet and assets are registered        |

---

## Key Folders

### `app/config/`

Everything the Builder controls lives here. This is the first place to look when changing behavior.

| File                              | Purpose                                                              |
| --------------------------------- | -------------------------------------------------------------------- |
| `cometchat-builder-settings.json` | **Your Builder choices** — edit this to change features after export |
| `default-settings.ts`             | The shipped defaults your file is merged over                        |
| `settings.types.ts`               | The settings contract (TypeScript interface)                         |
| `settings.service.ts`             | Merges your settings over the defaults                               |
| `feature-flags.ts`                | Exposes one signal per feature, which components read                |
| `theme-styles.service.ts`         | Turns your color and typography choices into CSS variables           |
| `font-scales.ts`                  | The typography scales behind `size` and the font fallback stacks     |
| `credentials.ts`                  | Resolves credentials from storage, then `environment.ts`             |

### `app/pages/`

The application shell — only needed if you run the export as its own app. When you embed `<cometchat-app />`, the `home` page is the layout it renders; `login` and `credentials` are not used.

### `app/services/`

Shared state: which conversation is active, navigation between panels, authentication, and toasts.

### `app/i18n/`

Translation files for multi-language support. Add or modify JSON files here to customize text. See [Localization](/ui-kit/angular/customization/localization).

## Quick Reference: Where to Customize

| What you want to change   | Where to look                              |
| ------------------------- | ------------------------------------------ |
| Enable/disable features   | `app/config/cometchat-builder-settings.json` |
| Theme colors & fonts      | `app/config/cometchat-builder-settings.json` (`style` block) |
| Component-specific CSS    | `app/components/<name>/<name>.component.css` |
| Text & translations       | `app/i18n/<lang>.json`                     |
| Component behavior        | `app/components/<name>/<name>.component.ts` |
| Credentials               | `src/environments/environment.ts`          |
| Build config & assets     | `angular.json`                             |

<Note>
  Prefer using settings and CSS variable overrides. For extensive changes, wrap the UI Kit components in your own rather than modifying these files directly — it keeps a future re-export from overwriting your work.
</Note>
