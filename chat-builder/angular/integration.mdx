The **UI Kit Builder** simplifies integrating CometChat's UI Kit into your Angular application — quickly set up chat, customize UI elements, and add features without extensive coding.

  <img src="/images/uikit-builder-preview.png" />
</Frame>

## **Complete Integration Workflow**

1. **Design Your Chat Experience** - Use the **UI Kit Builder** to customize layouts, features, and styling.
2. **Review and Export** - Review which features will be enabled in your Dashboard, toggle them on/off, and download the generated code package.
3. **Preview Customizations** - Optionally, run the export on its own before integrating it into your project.
4. **Integration** - Integrate into your existing application.
5. **Customize Further** - Explore advanced customization options to tailor the chat experience.

## **Launch the UI Kit Builder**

1. Log in to your [**CometChat Dashboard**](https://app.cometchat.com).
2. Select your application from the list.
3. Navigate to **Chat & Messaging** → **Get Started**.
4. Choose **Angular** and click **Launch UI Kit Builder**.

---

## **Review Your Export**

When you click **Export**, a "Review Your Export" modal appears (Step 1 of 3). This lets you:

- **Review features** — See which features will be enabled in your CometChat Dashboard based on your UI Kit configuration
- **Toggle features** — Turn individual features on/off before export
- **AI User Copilot** — Requires an OpenAI API key (you'll configure this in the next step)

## **Preview Customizations (Optional)**

The export is a complete, standalone Angular application. You can run it before integrating anything — this step is optional and can be skipped if you want to go straight to integration.

> 1. Unzip and open the `cometchat-app-angular` folder.
> 2. Install dependencies:
>
> ```bash
> npm ci
> ```
>
> 3. Run the app:
>
> ```bash
> npm start
> ```
>
> The app starts on `http://localhost:4200`. Sign in with one of the sample users on the login screen, or enter a UID from your own app.
>
> Your app credentials are already prepopulated in the exported code.

<Tip>
  Use `npm ci` rather than `npm install`. The export ships a `package-lock.json`, and `npm ci` installs exactly the dependency tree the app was built and type-checked against.
</Tip>

## **Integrate into Your Project**

If you already have an Angular application, you do not need the export's shell — only the chat. The whole experience is one standalone component, `<cometchat-app />`.

### **Step 1: Install Dependencies**

```bash
npm install @cometchat/chat-uikit-angular@5.1.0 @cometchat/chat-sdk-javascript@^4.1.13 @cometchat/calls-sdk-javascript@^5.0.0 @cometchat/cards-angular@^1.0.0 @cometchat/cards@^1.0.0 dompurify@^3.3.1
```

### **Step 2: Copy the App Code**

Copy these from the export into your project, keeping the paths:

| From the export                     | What it is                                          |
| ----------------------------------- | --------------------------------------------------- |
| `src/app/cometchat-app.component.ts`| The component you render                            |
| `src/app/components/`               | The screens it is built from                        |
| `src/app/pages/home/`               | The layout `<cometchat-app />` renders              |
| `src/app/services/`                 | Shared state                                        |
| `src/app/config/`                   | Your Builder settings and the flags that read them  |
| `src/app/i18n/`                     | Translations                                        |
| `src/assets/`                       | Icons used by these components                      |

### **Step 3: Register the Styles and Assets**

In your `angular.json`, add the UI Kit's CSS variables ahead of your own stylesheet, and copy both asset folders:

```jsonc
"styles": [
  "node_modules/@cometchat/chat-uikit-angular/styles/css-variables.css",
  "src/styles.css"
],
"assets": [
  { "glob": "**/*", "input": "src/assets", "output": "assets" },
  { "glob": "**/*", "input": "node_modules/@cometchat/chat-uikit-angular/src/lib/assets", "output": "assets" }
]
```

<Warning>
  Without the second asset entry the chat renders but every icon is missing.
</Warning>

### **Step 4: Apply Your Builder Settings at Startup**

In your `app.config.ts`:

```typescript app.config.ts
import { ApplicationConfig, inject, provideAppInitializer } from '@angular/core';
import { builderSettings, SettingsService } from './config';

export const appConfig: ApplicationConfig = {
  providers: [
    provideAppInitializer(() => inject(SettingsService).applySettings(builderSettings)),
    // ...your own providers
  ],
};
```

This is synchronous — the settings are bundled rather than fetched, so there is no window in which the first screen renders against defaults.

### **Step 5: Initialize CometChat and Log In**

The UI Kit needs two calls before the component renders. In your `main.ts`:

```typescript main.ts
import { CometChatUIKit, UIKitSettingsBuilder } from '@cometchat/chat-uikit-angular';

const COMETCHAT_CONSTANTS = {
  APP_ID: 'YOUR_APP_ID',     // Replace with your App ID
  REGION: 'YOUR_REGION',     // Replace with your App Region
  AUTH_KEY: 'YOUR_AUTH_KEY', // Replace with your Auth Key
};

const settings = new UIKitSettingsBuilder()
  .setAppId(COMETCHAT_CONSTANTS.APP_ID)
  .setRegion(COMETCHAT_CONSTANTS.REGION)
  .setAuthKey(COMETCHAT_CONSTANTS.AUTH_KEY)
  .subscribePresenceForAllUsers()
  .setCallingEnabled(true)
  .build();

await CometChatUIKit.init(settings);
await CometChatUIKit.login('YOUR_UID');
```

<Info>
  Your app credentials (`APP_ID`, `AUTH_KEY`, `REGION`) are prepopulated in the exported code, in `src/environments/environment.ts`. If you need different credentials, you can find them in the Credentials block of your app's [Overview section](https://app.cometchat.com) on the CometChat Dashboard.
</Info>

CometChat uses a UID (User ID) to identify each user. You can either:

1. **Create new users** on the **[CometChat Dashboard](https://app.cometchat.com)**, via a **[UI Kit method](/ui-kit/angular/methods)**, or **[via the API](https://www.cometchat.com/docs/rest-api/users/create)**.
2. **Use pre-generated test users**: `cometchat-uid-1` through `cometchat-uid-5`

To avoid logging in a user who is already signed in, check first:

```typescript
import { CometChat } from '@cometchat/chat-sdk-javascript';
import { CometChatUIKit } from '@cometchat/chat-uikit-angular';

await CometChatUIKit.init(settings);

const loggedInUser = await CometChatUIKit.getLoggedinUser();
if (!loggedInUser) {
  await CometChatUIKit.login('YOUR_UID');
}
```

<Note>
  **Auth Key vs Auth Token**

  Auth Key is perfect for prototyping. For production apps, switch to Auth Token for secure authentication and call `CometChatUIKit.login(authToken)` instead of `CometChatUIKit.login(uid)`. See [Authentication and User Management](/fundamentals/user-auth) for details.
</Note>

### **Step 6: Render the Component**

```html
<div class="chat-container">
  <cometchat-app />
</div>
```

```css
.chat-container {
  height: 100vh; /* or any definite height */
}
```

<Warning>
  **Give it a container with a definite height.** The component fills what it is given; in a container with `height: auto` it collapses to nothing.
</Warning>

Import it like any other standalone component:

```typescript app.component.ts
import { Component } from '@angular/core';
import { CometChatAppComponent } from './app/cometchat-app.component';

@Component({
  selector: 'app-root',
  standalone: true,
  imports: [CometChatAppComponent],
  template: `
    <div class="chat-container">
      <cometchat-app />
    </div>
  `,
  styles: [`.chat-container { height: 100vh; }`],
})
export class AppComponent {}
```

#### **Open Straight Into a Conversation**

Three optional inputs let you choose what the chat opens on:

| Input              | Type                                     | What it does                                            |
| ------------------ | ---------------------------------------- | ------------------------------------------------------- |
| `user`             | `CometChat.User`                         | Opens a one-to-one conversation with this user on load  |
| `group`            | `CometChat.Group`                        | Opens this group on load                                |
| `defaultActiveTab` | `'chats' \| 'calls' \| 'users' \| 'groups'` | Which tab the sidebar starts on (default: `'chats'`) |

```html
<cometchat-app [defaultActiveTab]="'groups'" />
<cometchat-app [user]="supportAgent" />
<cometchat-app [group]="teamChannel" />
```

Rebinding them switches conversation without remounting, so a host can move the chat between conversations by changing the bound value.

<Note>
  When both `user` and `group` are bound, the Builder's `chatType` setting decides which one wins.
</Note>

#### **Without Sidebar Mode**

When the sidebar is hidden via the **Without Sidebar** option in UI Kit Builder, the component renders a single chat type based on the `chatType` setting:

| `chatType` | Behavior                                                            |
| ---------- | ------------------------------------------------------------------- |
| `"user"`   | Displays one-on-one conversations with the selected or default user |
| `"group"`  | Displays group conversations with the selected or default group     |

Pass the `user` or `group` input to specify which conversation opens by default.

### **Step 7: Run the App**

```bash
npm start
```

## **Troubleshooting**

| Symptom                                    | Cause                                                                              |
| ------------------------------------------ | ---------------------------------------------------------------------------------- |
| The app opens on a credentials screen      | Neither `environment.ts` nor stored credentials are configured                     |
| Chat area is blank or collapsed            | The container has no definite height                                               |
| Icons are missing                          | The UI Kit asset folder is not in `angular.json`'s `assets`                        |
| Login fails with an opaque error           | App ID, region or Auth Key is wrong, or the region does not match the app          |
| A feature you switched off still appears   | `cometchat-builder-settings.json` was not copied, or was replaced after export     |
| Styling looks unthemed                     | `css-variables.css` is missing from `angular.json`'s `styles`, or listed after your own stylesheet |

For issues with the UI Kit itself, see [Angular UI Kit Troubleshooting](/ui-kit/angular/troubleshooting).
